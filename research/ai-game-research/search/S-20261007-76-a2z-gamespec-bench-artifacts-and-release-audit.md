- 將 B0052 從「只可查看 paper／method」更新為「有官方榜單與部分可核 runtime screenshots，但完整 corpus/evaluator 尚未釋出」。arXiv HTML 說 code/data available at project page 與 GitHub README “coming soon” 有矛盾；GitHub main tree、branches/releases 和 HF dataset API 支持「目前沒有完整 data/code release」的判斷。
- 將三個具名 3D extension 輸出記為 [G0283](../records/G0283.md)–[G0285](../records/G0285.md)。Sonic 與 Rocket League 有 gameplay capture；Diablo 只有類型簡述和固定 contract scores。分數為 specification fidelity，不是 art score。三作都缺 raw prompt、完整 GDD、build/source/session，所以不認定一次委託或自主修正流程。
- 此為 B0052 的**顯著證據補強**：正式 3D runtime screenshots、GPT-6 Astra 作者歸因和三軸分數為原紀錄尚未具體入帳的視覺輸出材料。無增益計數從 S76 後重設為 **0**；尚未結案。主資料庫仍需覆查更多近期模型實際 build，且 A2Z 100-GDD corpus 待官方釋出。
