# 搜尋批次 S50：GPT-6.1 Sol light 多題遊戲 build 與原始任務

**日期／範圍：**2026-10-07；沿不同於正式 benchmark repo 的方向，查近期 coding model 公開遊戲作品庫是否同時提供原任務、source 和可重建 build。目標是篩出高系統密度的實際輸出，並核對「任務是原始生成輸入」與「模型自主 QA／無 follow-up」的證據強度。

## 研究問題與先前查重

先讀 [研究索引](../../ai-game-one-shot-index.md)、[候選摘要](../../ai-game-one-shot-candidates.md)、[搜尋索引](index.md)，並查 [S36](S-20261007-36-current-model-game-generation-runs.md)–[S42](S-20261007-42-frontier-model-high-complexity-runs.md)。已知最新模型作品常只有影片，或 prompt/session 不公開；已存在 Muse Spark 題、Sol《Ashen Vigil》《Ridge Run》《Slipstream》及 Sonnet 5.5《Dead Signal》記錄。本次聚焦公開 repo 同時提供多份可複用任務與 source builds 的新 collection，不重做上述作品查找。

## 結論與更新去向

- 新增 [C0024](../records/C0024.md)，收錄七個原任務、source 入口、系統範圍、README 宣稱的自測和限制；候選摘要加入一個需使用者檢閱的近期模型作品集與較值得抽樣重跑的四題。沒有給新作品美術判定，未將 repo 中存在的測試等同於 AI 執行的測試。
- 該集合實質增加近期 GPT-6.1 Sol light 的公開原任務／source-build 證據，因此無增益方向計數重設為 0。one-shot 與模型工具細節仍只有作者說明；若只嚴格採納已核實無介入 run，該部分仍待核實。
- 下一方向：不再按同一作者作品庫追題，改查 2026 年新公開的代理式 browser-game coding competition／benchmark results，尋找完整任務、最終交件 artifact 與自主測試／迭代 trace 是否同時可取得；先交叉核對其規則與既有 benchmark records。
