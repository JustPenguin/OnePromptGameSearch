## 未命中與重查界線

- `Hades Manila` 的本輪查詢沒有取得足以辨認特定公開項目及其 prompt／首版時間線的可靠來源；不建立推測性紀錄。若找到原作者頁或 repo，再以原始來源查重。
- 其餘以 GPT-6.1 Sol／Opus 5.5 加 GitHub 關鍵詞的廣泛查詢，主要返回作品集或現行 repo；無法由 repo 最新狀態倒推首次停止時版本。之後不要原樣重跑相同 query，應改用模型官方展示／作者 session archive，或鎖定新增作品名查版本歷史。
- 本輪沒有新增可直接升格的強一次交付候選；這是有意義的負結果。長風與 Sakura Rally 的人類回饋時間線說明「首 prompt 很短」不能等同最終成品由單一委託產生。

## 研究判斷與下一輪

Turbo Kart Rally 有第三方同版 build 實玩證據，但它與已通過美術的 Kart Blitz 類型重疊、只是一條賽道且 one-shot 證據仍依賴作者陳述；不為了擴充名單而升級推薦。Long Wind、Sakura Rally 都是豐富的視覺／系統參照，卻有明確人類後續介入。OpenRally 是更強的「AI 生成」宣稱，但來源細節缺失，不能以功能清單代替 run provenance。使用者已對 2026-10-07 檢閱頁當時列出的作品給出整體美術驗收，參見 [E0008](../records/E0008.md)；本批新登錄項目不自動套用該驗收。

**下一個不同方向：**追查官方模型／agent 廠商公布的遊戲 build、session export 或 benchmark artifact，優先核對 GPT-6.1 Sol、Claude Sonnet／Opus 5.5、Gemini 當前版本與 2026 年 9–10 月發佈內容。每個新增線索先查是否有凍結 build、任務原文和人類介入紀錄；避免再搜尋本批已查過的 Long Wind、Sakura Rally、Turbo Kart Rally、OpenRally 及同兩個策展清單。
