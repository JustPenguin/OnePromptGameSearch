# G0253 · Astra Attack

**類型：**遊戲／具體題目　**狀態：**多人 FPS 系統／品質參照；已有 v2 與多人次迭代跡象且無 prompt／session，不納入一次委託成績　**最後整理：**2026-10-07

**別名：**GPT-6 Sudden Attack；봄바다 browser FPS

## 遊戲內容與可檢閱證據

作者在 2026-09-08 於 [DCInside 原帖](https://gall.dcinside.com/mgallery/board/view/?id=ai_utilize&no=58556)以「3:3 FPS 正式開放 v2」發布 [可玩 build](https://scar-flame.vercel.app/)，並歸因於 GPT-6 Astra。該 build 可檢視多人倉庫戰、多人房間／配對介面、武器與瞄具、經驗／等級／排名及個人戰績；亦有單人練習場。第三方實地檢查紀錄了 4v4／5v5 模式、計分與留場條件、PWA 行動操作等，但多人伺服器曾因流量承載出現問題。

這是有實際 build 的跨系統 browser FPS 參照，涵蓋射擊操作、多人同步與服務、持久進度、排名、UI、手機支援及服務負載。它能提供高密度 FPS 主題與可查看成品。

## 一次委託證據界線

作者發布版本已明示 v2；相關作者貼文提及只消耗部分月度 Pro 用量、持續伺服器調整，而原 prompt、完整 session／trajectory 與 source repository 未公開。第三方實地檢查 build 及內嵌 credits，發現地圖資產匯入與可重現的上游版本資料。以上支持它是有後續工程的成果，但不能證明一次任務交代後完全由模型無人介入完成。

因此它不作 one-shot 成績。若要測「一則任務後模型自己完成多人射擊遊戲」，可把多人房間、服務端權威、匹配、同步、斷線復原、武器、進度、排行榜和可運作本機練習模式整理成全新重跑 brief；不可將此 build 說成該 brief 的通過案例。美術未由使用者評價。

## 判斷與重查條件

保留為多人系統設計與成品參照，而非一次委託候選。若作者公開原始 prompt、完整 trace 和首版 build，才能重新判斷其是否有可分離的一次交件版本。
