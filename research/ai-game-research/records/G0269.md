**美術：待使用者評價。**本研究沒有代使用者判斷畫面。

## 任務、作品與來源

[Devpost 提交頁](https://devpost.com/software/bolt-tower)目前直接讀取 HTTP 403；透過可讀鏡像可看到完整提交文字。作者把 Bolt Tower 列於 Bolt.new AI Coding Hackathon 的 **1-Shot Prompt Challenge**，自述從一個 prompt interaction 建立「AI-themed tower defense」。提交說明列出 wave-based progressive difficulty、點格佈塔、四類防禦塔及 upgrade paths、四類敵人、health/scoring、menu、victory／game-over、restart、responsive/touch UI。這些是提交者所述功能，不能把宣傳文字當作獨立測試結果。

hackathon [官方規則](https://worldslargesthackathon.devpost.com/rules)明文將 One-Shot Competition 定義為只使用單一 prompt 建立專案；可修正錯誤，但若在初始 prompt 之後增加或編輯功能／UI，即失去資格。這和使用者可讓 AI 自主 debug、而人類不追加功能的條件接近。Devpost 作品頁把該遊戲列在此 track，卻未找到實際獲獎狀態或主辦者對該作品 workflow 的獨立稽核。

[作者 live demo](https://bolt-tower.netlify.app/)現回傳 HTML app shell 及 Vite JS/CSS assets（HTTP 200）；靜態程式 bundle 可查 tower、wave、upgrade、victory、game-over、level、path 等實作字串。可確認有發布的 browser artifact，惟本研究沒有用瀏覽器完成整場遊玩或獨立驗證每項功能，也沒有保存 build hash／freeze date。宣稱完整原始碼的 [Bolt session link](https://bolt.new/~/sb1-czijj5rv)目前將訪客導向 Bolt 登入，無法讀取 prompt 或聊天／修正紀錄。
