# G0285 · Rocket League (A2Z GPT-6 Astra 3D build)

**類型：**遊戲／正式 benchmark 3D 輸出與美術參照　**狀態：**A2Z 論文明載 GPT-6 Astra Three.js build，提供原始 gameplay capture 和固定 contract 三軸分數；尚無 playable URL、source、完整原始 GDD 或生成 session，不能當成一次委託成果。**美術不合格（使用者判定）。**　**最後整理：**2026-10-07

**使用者美術驗收（2026-10-07；[E0008](E0008.md)）：不合格。benchmark 分數不改變使用者對遊戲畫面的評價。**


## 任務與實機畫面

KRAFTON [A2Z GameSpec-Bench 論文 §4.8／Appendix H](https://arxiv.org/html/2609.39564)稱三個額外 3D game builds 由 GPT-6 Astra 在 Three.js 製作。Figure 8 的任務摘要是「Drive, jump, and collect boost in a five-minute match against an opponent bot」，另有賽後 countdown 後恢復比賽的條件；作者稱 task 為 vehicle-based ball play。此為 figure 的 GDD 摘要，不是完整原始 GDD，也不是證明模型只收到一次任務的 prompt transcript。

論文提供[原始 gameplay capture](https://arxiv.org/html/2609.39564v1/assets/appendix/showcase/rocket_league_1.png)：畫面可見足球場、球門、球、藍色玩家車、橘色對手車、觀眾席與計分／時間／boost／球視角 HUD。研究者觀察是簡化的 low-poly 3D 場館和幾何車輛；圖中部分競技場物件較簡單。這是一張 runtime frame，不是封面，適合直接由使用者判定美術完成度，但不代表 3D 資產密度或完整遊玩品質。**美術不合格（使用者判定）。**目前無公開 playable URL 或 source。

## 模型、評分與限制

Appendix H Table S21 報告 Source 83.64、Scenario Replay 57.40、Playtest 77.54（0–100）。分數是 benchmark 的 GDD fidelity 評測，不是 art rating。它保留了規格落實方面的可追查值，但無完整任務和 build 讓本研究複現。

論文沒有公開 model snapshot、原始 GDD、user/agent transcript、工具使用、人工介入、revision 回合、凍結 build 或可玩網址。故一次輸入／AI 自主修正／最後 build 的完整流程尚未核實。資料庫另有舊史料 [G0131](G0131.md)「Rocket League showcase」，其來源是其他待核影片，並無證據說是這個 A2Z GPT-6 Astra build；本紀錄以完整標題區分，不合併兩個作品。

| 面向 | 判斷 |
