# G0274 · Aethel Fold (Konstantin / Claude Code)

**類型：**遊戲／美術參照　**狀態：**公開 HTML5 俯視摺紙書風格遊戲；作者自述 Claude Code 在多個 cloud sessions 實作 art／sound／text，但人類負責 game design 與 art/sound direction；非一次委託結果，模型版本／prompts／session trace 未公開　**最後整理：**2026-10-07

**美術：待使用者評價。**作者說 gameplay art／sound／text 由 Claude Code 建立、方向由人類提供；封面與 itch 頁面圖片另由 Gemini 生成，不把封面當遊戲內成品。

## 遊戲與畫面

[作者頁](https://konstantinsteinmiller.itch.io/aethel-fold)提供可玩的 HTML5 build、五張遊戲截圖和 AI attribution。題材是「pop-up storybook」紙片軍隊；玩家摺疊頁面形成牆、闔上峽谷或拍回投石機。作者描述三冊、18 頁 hand-crafted levels，有 origami dragon、frog、hydra 及紙海章節；頁面把遊戲列為 Released、HTML5，並標示 Made with AI。

本研究檢視了兩張標作 game screenshots 的實際畫面：[ravine 關卡](https://img.itch.zone/aW1hZ2UvNTA3MzYxNS8zMDQzOTg0MS5qcGc=/original/y37f1H.jpg)與[分冊進度／紙頁關卡](https://img.itch.zone/aW1hZ2UvNTA3MzYxNS8zMDQzOTg0NC5qcGc=/original/O7LgZf.jpg)。畫面是暖色紙本背景、手繪外框、低多邊形／折紙樹木、卡通人物和大尺寸手機 UI，呈現一致的圖畫書風格。這是研究者觀察，不是使用者通過評價；它是 2D 風格化作品，不是 3A 3D 寫實參照。

## AI 歸屬與 one-shot 判斷

itch AI disclosure 原文稱：遊戲由 Claude Code 在「several cloud sessions」完整實作；game design 與 art/sound direction 由 Konstantin Steinmiller 提供；Claude Code 製作 art、sounds、texts。cover images 和 itch 頁面上的 artwork 另由 Gemini 生成。頁面最後更新日期顯示為本批整理日之前 5 天；無法把當前版本當作 jam 截止時 frozen artifact。

| 面向 | 判斷 |

## 定位

保留作為近期「人類定美術方向、coding agent 跨多次 sessions 產生遊戲內 assets／audio／text」的視覺校準參照，不列一次委託 shortlist，也不把人類 art direction 或 Gemini 封面混算成 Claude Code 自主美術能力。若公開起始任務和連續 session、或新模型以同一視覺 brief 在單一初始委託內自主完成畫面與遊戲，可重新研究。詳見 [S65](../search/S-20261007-65-recent-ai-game-jam-visual-builds.md)。
