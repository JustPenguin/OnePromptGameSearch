## 遊戲範圍與自我驗收

題目要求瀏覽器城市建造模擬，朝 Cities: Skylines II 級別靠近：地形、水岸、氣候與日夜、道路／車道網、分區、不同等級建物、車流及行人、人口／工作／經濟與市政服務、HUD 及合成音效。Prompt 指定先寫 subsystem 架構與接口，建立 headless Chrome 截圖／效能記錄工具，再讓建置代理與獨立評論代理逐模組迭代；最終以盲測比較截圖。

GitHub README 提供可玩 build、source、PROMPT.md、遊玩操作、測試工具與 critique/status 檔。README 自述：三輪盲測都輸給商業參考，差距縮小；初次體驗評論 5.5/10，缺少教學且有些情況效能未達預算。這種公開失敗紀錄很有價值，說明複雜遊戲能跑不等於畫面／效能過關。

## 限制與重查條件

- 任務內明確要求 multi-agent orchestration、逐模組最長四輪修改及持續 loop，衡量的是 agentic toolchain 的長程自治上限；若用來比較不同模型，必須讓各模型得到相同 agent、工具、時間／token 預算。
- 作者自述「one prompt」和無人介入，公開資料尚非獨立 run 稽核。不要把工具鏈之外的人類設定基礎環境等事實推廣成完全無人看管的實驗。
- 美術與效能仍未通過它自己寫下的 AAA 標準；使用者尚未檢視成品，不能標記美術合格。
- 適合拿來擷取和縮放任務規格，或作為「長時、多代理、自主檢查」題型；不適合與 20–80 分鐘單檔作品直接混在同一排行榜。
- Reddit 作者貼文補充約 14 個代理、24 小時及 token／費用數字；這些仍是作者自述，不是第三方稽核資料。早期第一小時錄影只是三波建置中的第一波，不能單獨當成最終交付畫面。
