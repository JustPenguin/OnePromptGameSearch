## 2026-10-06 公開狀態更新

OpenGame 官方上游 repo 現列出可由單一 prompt 端到端生成的 playable game demos，每個樣例提供 prompt、live demo 和 source archive。headless 啟動可在空白遊戲目錄下使用 `opengame -p <prompt> --yolo`；Game Skill 固定提供 template/skeleton 選取和 Debug Skill 的 browser run、console／互動檢查、修復循環。主 agent 支援以 OpenAI-compatible API 換模型，影像、影片、音訊、reasoning provider 分開設定。若研究問題是「固定 harness 下不同可換模型一次收到同一 brief、可自主 QA 到交件的差距」，這比單看其論文分數更直接可重跑。

此公開狀態有兩個界線：README 將完整 OpenGame-Bench evaluator 說成仍待釋出，論文的 150 prompts／結果不應與 repo gallery 混為一談；gallery 的每一款 build 沒有逐項公布模型版本、日期及 session trace。因而此項是有價值的**固定 agent harness／prompt gallery**，不是現成的最新基礎模型 leaderboard。見 [S23 搜尋批次](../search/S-20261006-23-agent-platforms-opengame-and-world-benchmarks.md)及[官方 repo](https://github.com/leigest519/OpenGame)。
