# G0267 · Bash Fighter — AI-agent-maintained 20-player online platform fighter

**類型：**遊戲／具體作品　**狀態：**高系統 AI-agent product lead；有完整公開 source／線上 playable build，但 README 明言日常持續開發，無原始一次任務、模型版本或 agent session；不作 one-shot candidate　**最後整理：**2026-10-07

**美術：待使用者評價。**本研究沒有代使用者判斷畫面是否合格。

## 目前可核實的作品與技術範圍

[官方 GitHub repo](https://github.com/Bash-Entertainment/bash-fighter)公開 TypeScript monorepo、測試／CI 與[線上遊戲](https://bashfighter.com/)；另有 [itch.io 版](https://bashfighter.itch.io/bash-fighter)。README 描述以 20 人 free-for-all 為目標的 browser platform fighter，Last Fighter Standing、會縮小的 arena、spectator camera、私人邀請 lobby、空位 bot fill、跨瀏覽器 deterministic simulation，以及 authoritative online match server。`docs/ARCHITECTURE.md` 分出 sim/content/render/input/net/app/server，說明 fixed 60 Hz、Q16.16 fixed-point state、seeded PRNG、server-authoritative tick、local prediction、reconciliation、remote snapshot interpolation。repo 有 sim、app、net、render 與 server 測試，並提供 20-player crowd/determinism/load testing scripts。

GitHub repo API 顯示建立於 2026-09-07，最近一次查核時最新更新為 2026-10-03。README 明確寫道：此專案**日常開發**（包括 repo 大部分程式碼和帳號發文）由一個代表 owner 工作的 AI agent 完成，且 AI agent 會審查 PR／issues。這能支持「大型 playable product 有大量 agent 參與」這一來源自述，但本研究沒有可獨立審計的 AI code attribution 或完整 commit-to-agent logs。README 也警告專案尚早期，部分設計文件描述比現況完整；`docs/ROADMAP.md` 表示 Timed Brawl／Stocks 尚非完整 end-to-end wired、anti-cheat 與角色／地圖廣度仍有限。

## 收錄定位與待追線索

此項不進精選候選排名，亦不把長期 AI-assisted development 當一次交辦。因為 playable source 實際涵蓋多人 deterministic simulation、netcode、server/lobby 和測試，較簡單 browser demo 更值得保留為**高系統 one-shot 重跑題材線索**。若作者公開同一初始委託、模型／tool identity、AI／人類 commit 分界、agent transcript、起迄 frozen build 或清楚 no-follow-up evidence，可再判斷有沒有單一高難 run 可拆出來；若一直是多週／多輪產品開發，維持本狀態。

GitHub [公開 commit history](https://github.com/Bash-Entertainment/bash-fighter/commits/main)記錄連續多日的遊戲體驗改動、遙測和依據真實新手遊玩調整控制／首局流程；例如 2026-10-03 修正手機玩家未曾攻擊、2026-10-01 處理新手未重新排隊。repo README 明言日常開發由 AI agent 代表 owner 持續進行。這些資料更支持「持續維護的 agent product」分類，但 commit 仍沒有初始 user brief、底模、agent transcript 或各修改的請求來源，不可從 commit message 推知人類是否發過 follow-up。

2026-10-06 GamesByAI [submission #121](https://github.com/gamesbyai/catalog/issues/121) 由投稿帳號自稱 AI agent 提交，列出 20 人場、server-authoritative netcode、deterministic simulation、bots、手機／桌面支援，並稱以真實玩家 telemetry 和 feedback 持續調校；人類 owner 監督。投稿把模型描述為「Claude-based agent」但明確寫 model version unknown，工具欄空白。這是 creator statement，補強其長期產品／人工監督分類，仍沒有 one-shot run provenance。
