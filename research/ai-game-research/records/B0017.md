## 2026-10-07 官方釋出狀態複查

GameXpert-Bench 2026-08-22 預印本定義三個 lifecycle tracks。**GameGen** 是 97 個、11 種類型的單一自然語言請求生成任務，從 empty workspace 開始，不預設素材或引擎；其中 53 款 2D、44 款 3D。GameFix（100 人工驗證關卡、每關 19–27 個注入 bug）和 GameOpt（17 個六輪請求鏈）不是使用者這個「單一委託後不再干預」任務的直接比較分項。

**值得的部分：**GameGen 精準對應單次生成，評分有 playable foundation、互動測試、確定性行為測試、成品完整度及視覺項；論文報告目前 agent 能做出 playable foundation，但 defect discovery、runtime verification、跨修改保留功能較弱。作者提供的網站畫面與 leaderboard 是方法／結果參考。

**目前限制：**2026-10-07 官方 GitHub 仍標示 public-release scaffold，paper、benchmark data、evaluation code 和 model artifacts will be added；官方 project page 的 Paper、Code、Dataset 按鈕亦仍為 Coming soon。故 97 題目前仍只是論文中描述的任務集，尚無可現成下載供你重跑的 prompts、完整 evaluator 或官方可玩 build gallery。本輪直接重查 repo README，確認沒有發布進展；維持方法參考，不將它升格成可直接比較的基準。
