# G0210 · Elderwood Realms

**類型：**遊戲／具體題目　**狀態：**待核實　**最後整理：**2026-10-06

**別名：**尚無

## 發現與來源

2026-10-06 從更新中的 GPT-6 Astra 遊戲目錄重查到 Elderwood Realms／Lumbridge：一個 RuneScape-inspired 的 browser multiplayer RPG，曾有共用世界、採集、技能、任務、交易和決鬥。作者 Rohan Varma 在 9/06 公開主張 GPT-6 Astra in Codex 依「build RuneScape」方向製作及部署；現存整理來源註明其宣稱 one-shot trailer 不代表整個遊戲只用一次 prompt。社群目錄研究員 9/09 建立 guest 並檢查選角、World 1、背包、skills、採集與戰鬥介面，留存了當時真實 build 截圖來源。

官方專案頁現已變成[關閉公告](https://elderwood-realms.rohannvarma.chatgpt.site/)：作者說網站收到 Jagex 通知後停止營運；頁面回憶它在幾天內成長為共享的探索、技能、任務、交易和決鬥世界，並保留排行榜。

## 證據與限制

這款曾有 multiplayer browser build 和真實遊戲截圖，但現已下線，無法讓使用者檢查成品。作者宣稱 Astra one-shot 只指一段 showcase/demo，而不是後來的完整 multiplayer RPG；全程開發細節與完整 prompt transcript 不公開。官方 closure 說明它在幾天內隨玩家上線而持續擴張，意味着公開版不等同無人工干預首輪成品。原作直接以 RuneScape 為主題也限制其作為原創能力測題的適用性。這裡不沿用新聞媒體將整款遊戲簡化為「GPT 一次生成」的講法。

## 判斷與重查條件

**排除為既有 one-shot 成品評測候選。**概念展示可證明模型能啟動多人 RPG 原型，但沒有可看的現行 build、原始 prompt／完整 run，且後續完整世界由多人遊玩和回饋推進。對本研究只保存為「長程多人 RPG 可能題型」的證據，重跑應改成原創世界／名稱並定義帳號、伺服器、社交互動、技能與可驗收 progression。

重查條件：作者若公開獨立 frozen first-run build、session trace，或發布去除 IP 相似內容的原創版本，再另行評估。批次記錄見[S12](../search/S-20261006-12-high-system-games-from-current-catalogs.md)。
