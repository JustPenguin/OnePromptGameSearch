# B0049 · Brendan Jowett 五題 UE5 生成遊戲對照（GPT-6 Astra × Claude Opus 5.5）

**類型：**近期模型生成實測／比較影片　**狀態：**近期高價值實測與畫面參照；原始 prompts／build 未公開，不是可完整重現的正式基準　**最後整理：**2026-10-07

**別名：**NEW Opus 5.5 vs GPT-6 Astra Building Video Games (NOT Close)、Brendan Jowett five-game Unreal comparison

## 測試內容與公開資訊

2026-09-24，遊戲開發內容創作者 Brendan Jowett 發布 GPT-6 Astra 與 Claude Opus 5.5 對照影片。創作者介紹稱兩模型以相同的單次提示、最高設定，各自製作五款 Unreal Engine 5 遊戲；使用 C++，3D 資產在 Blender 內建立，並稱不用外部下載或人工撰寫程式碼。創作者社群貼文也描述每款由 single prompt 起始、全程不下載資產，並公開每款的建置時間與成本。

影片依序展示：

1. **Rampart：**2D 城堡平台遊戲。
2. **Apex Circuit：**3D 海岸街機賽車，含 AI 對手、漂移與加速。
3. **Void Wing：**六軸太空狗鬥，含砲塔、敵機與小行星。
4. **Dead Signal：**雪地電台塔生存射擊，含無人機蜘蛛敵人。
5. **Colossus：**第三人稱石巨人 Boss 戰，含攻擊預告及弱點。

影片片段呈現兩側實際 build 的短暫操作畫面，並展示逐題的工時、首次可玩時間、API 費用及程式碼行數面板。Secondary video transcript 摘要記載 GPT-6 Astra 五題建置時間為 33.4、72.9、39.1、42.6、44.9 分鐘，費用為 23.02、63.08、28.05、32.98、28.69 美元；Opus 5.5 分別為 70.8、117.6、99.3、75.0、94.6 分鐘及 48.95、67.30、55.65、49.88、47.00 美元。這些數字目前是逐影格／音訊二手摘要轉錄，正式使用前應以原影片畫面核對，不能當成獨立稽核資料。

## 為什麼值得納入

- 它近期直接展示 GPT-6 Astra 及 Opus 5.5 的遊戲 build，任務跨 2D 平台、競速、六自由度射擊、第一人稱生存射擊和 Boss 戰；可供觀察畫面呈現、互動、玩法和題型差異。
- 五種任務比單一複刻作品更能避免把模型表現簡化為單一類型；賽車、FPS 與 Boss 戰也涵蓋玩家常在遊戲生成中關心的即時控制與敵人互動。
- 創作者同時展示短實玩畫面及時間／成本資訊，因而比只有宣傳圖的案例更能供人檢閱。
- 對本研究來說，影片可作近期前沿模型輸出與題型來源；若選其中任務重跑，應另行制定並凍結統一 prompt 和交付規則。

## 證據界線與公平性風險

- 影片及創作者頁沒有找到逐字公開的五份原始 prompt、完整 Codex／Claude Code trajectory、各 run 的乾淨起始專案快照或可下載 source/build。觀眾可看影片中的遊戲畫面，但不能從影片逐項驗證每款遊戲的完整玩法或最終交付版本。
- 「同一 prompt」「最高設定」「無人工寫程式／不用下載資產」來自創作者對影片的描述。沒有逐訊息紀錄，不能獨立確認期間是否有 follow-up、工作區是否一致、是否有人工操作／設定修正，或兩方 tool access 是否等值。故不把它標成已稽核的使用者只輸入一次、AI 自主修正案例。
- 題型逐步增加複雜度是影片編排，不等於每題具有相同難度刻度；也沒有預先註冊的盲評 rubric、多次隨機種子或獨立玩家測試。作者對模型表現的評論屬內容創作者評述。
- 公開標題使用 GPT-6 Astra 與 Claude Opus 5.5。正式引用時應以影片發佈日期的型號名稱為準；勿把影片標題解讀成目前最新的模型 roster。
- 本研究尚未以使用者美術標準檢視這五款作品。影片畫面可作初步畫面檢閱入口；不能繼承舊候選頁的藝術判定，也不能以作者稱讚代替使用者驗收。

## 建議定位與重查條件

**保留為近期前沿輸出與比較畫面參照，並列入值得檢閱的來源；不列正式可重現 benchmark，也不據此宣稱模型勝負。**若要用於你的測試，可選其中最有興趣的一個遊戲類型，從影片畫面與作者描述整理一份新的、模型中立的明確任務；但那份重建 brief 必須另標「研究者重寫」，不能冒充作者原 prompt。更理想的條件是作者公開原 prompt、build/source、完整 session 與各模型工具／預算資料後，再升級證據等級。
