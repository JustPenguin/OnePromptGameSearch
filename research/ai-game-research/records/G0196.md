# G0196 · Descente

**類型：**遊戲／具體題目　**狀態：**排除於嚴格一次委託主候選　**最後整理：**2026-10-06

**別名：**Descente roguelite

## 發現與來源

Claude Opus 5.5、Godot 4.7 的動作 roguelite。作者公開規格文件、六張美術參考圖、Godot MCP 和自主測試方式的描述；原始討論與成品截圖在[作者貼文](https://www.reddit.com/r/ClaudeAI/comments/1wqo6o5/i_gave_claude_a_detailed_game_spec_and_let_it/)。

## 遊戲規模及測試能力

- 一輪約 13 分鐘、畫面最多約 800 名敵人、8 種敵人、2 隻小 Boss、一隻三階段最終 Boss、多種能力／稀有度道具及局外天賦成長。
- 公開描述稱約 5 小時 48 分完成，約 15,000 行 GDScript 與 3,000 行 Python；模型以 Godot MCP 啟動遊戲、讀錯誤、取截圖及模擬按鍵，另寫 bot 自動跑整局。作者稱 bot 加速測試超過 200 場，用來找 bug 和調整難度。
- 程序美術流程有參考價值：Godot 簡單 3D 角色逐格渲染，再以 Python 映射到 64 色調色盤、清孤點並加輪廓；場景、特效和部分 UI 也由腳本建立。作者也明確表示畫面仍有資產、鏡頭與節奏問題。

## 為何不符合使用者條件

作者說自己先提供詳細規格與六張參考圖，啟動後又在開發期間留言三、四次；其中一次要求 bot 變得更像人類，之後調整平衡。雖然沒有手改程式碼且絕大多數工作由模型完成，但中途仍有人類指示，不能算使用者只下達一次任務後完全不干預的成品。

## 判斷與重查條件

作為「高複雜 roguelite + 多輪自動 playtest + 程序美術 pipeline」的能力上界參照，內容很強；嚴格評測時排除。若日後找到完全凍結、沒有這些中途評論的獨立 run，可另建 run 證據或重評，不把本次 build 改標成 one-shot。
