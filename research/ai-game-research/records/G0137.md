### 為何適合這個測法

基準公開一段共同 prompt：「Create a complete 3D horror game in a single HTML file, incorporating RPG and roguelike elements.」另要求 GOTY 品質和單檔可發行。每個公開輸出是 one-shot、one-pass、沒有迭代改良、不能手動調整玩法／系統的原始交件，故 protocol 比「單次起始任務但允許 agent 無限自行迭代」更嚴格。題目只要求單 HTML，是交付限制；真正難點是 agent 一次輸入能否自主選出並做成可玩完整遊戲。

GPT-6 Astra Max 版本名為 THE NINTH BELL；repo 作者截至 2026-09-30 的直接遊玩主觀排序列第 5，Opus 5.5 Max／THE TALLOW DEEP 排第 1。該排序是作者個人評分，並非標準化盲測；它提供可實際玩的輸出，不足以支撐模型普遍排名。此 bench 沒有 run 時間／成本或完整互動逐字稿，模型與 harness 設定亦未完整對齊，故適合拿來挑任務和直接看成品，不應照搬其排名。

**和你的測法有一處差別：**你允許 AI 在沒有使用者介入下自測與修改；這個 benchmark 為了量 first-pass，禁止生成後人工 gameplay/system 修整，且沒有公開自主工具迭代紀錄。它能量一次輸入後的首輪成品，不能單獨量長程自修能力。若你重跑它的 prompt，可讓 agent 自主迭代，並把 benchmark build 當視覺／任務參考，而不必照搬禁止自修的規則。

### 遊戲難點

實際 Astra build 是第一人稱 3D 恐怖 roguelike：修道院探索、多層下降、地圖、日誌、敵人／武器／防禦、角色資源、死亡回響與 roguelike 成長。實際遊戲頁列三段 descent、每次旅程不同。這同時涉及場景視覺、氣氛、操作、戰鬥、導航、HUD 與遊戲循環；明顯比簡單 arcade 題複雜。最終的流程長度與規則覆蓋仍需實玩確認。

**建議順序：**可先開 GPT-6.1 Sol Max 的版本，再與 GPT-6 Astra Max、Kart Blitz 實際畫面對照；如果你判定其中一版的美術過關，它就成為目前符合「近期模型＋一次輸入＋足夠遊戲深度」的強主測參照。若美術未過，仍可保留作系統題，但不列為視覺合格候選。
