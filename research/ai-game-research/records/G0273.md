# G0273 · Cozy Island Farm — GPT Image 2.0 + Codex prototype workflow

**類型：**遊戲／美術管線參照　**狀態：**作者公開生成概念圖／tileset、再由 Codex + GPT-5.5 依自訂 prompt 做成 browser prototype 的流程；屬人工分段交辦，不符合一次使用者委託；只有影片／截圖，未找到可核 playable URL、原始 task 或 session，不列成績候選　**最後整理：**2026-10-07

## 任務流程與可見輸出

Givros 的[流程貼文](https://x.com/givros/status/2055294632766881870)稱以 GPT Image 2.0 先產生 Cozy Island Farm 概念圖與 tileset，將風格整理為技術 assets，再把「my custom prompt」交給 Codex + GPT-5.5 生成可玩的 browser prototype。[完整 guide 貼文](https://x.com/givros/status/2055671601744486587)說明這是一層層安排多個工具／階段；更早的[短版流程貼文](https://x.com/givros/status/2048388647272022093)也明確列出 GPT Image 2.0 → assets → Codex + GPT-5.5。

作者提供 37 秒影片而未提供訪客可操作的遊戲網址或 repo。研究者從影片畫面觀察到明亮的 2D 像素風島嶼、農場建築、橋梁、作物格、海水和小型 UI；圖像素材與遊戲畫面風格一致，但解析度／構圖是俯視 pixel-art 小型 farm prototype，不能當作 3D／3A 美術證據。畫面顯示作物與選單操作，但未能逐項測試其循環或完成度。

## 定位與重查條件

保留此案例是因為它直接示範 AI 生成概念圖／tileset 進入 playable prototype 的視覺資產管線，能提醒後續任務允許 coding agent 自主呼叫影像模型並保存素材來源；但它不是目前可比較的一次委託成績，也未達完整遊戲／3A 候選範圍。若作者公開 playable build、prompt／source 和連續 session，或同一 agent 在單一初始任務內自主生成概念圖、匯入資產、實作並 QA，可重查。詳見 [S64](../search/S-20261007-64-image-asset-game-workflows.md)。
