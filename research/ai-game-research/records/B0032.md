# B0032 · PlaytestArena

**類型：**基準／評測　**狀態：**方法參考；PlaytestArena 任務集未公開，Play2Code 為多輪互動　**最後整理：**2026-10-07

**別名：**continual-game-generation、GUI Agents for Continual Game Generation

## 2026-10-07 任務與程式發布範圍複查

論文描述 PlaytestArena 有 200 個 browser-game generation tasks、八種 genre，每題配自然語言 prompt 和 expected in-play behavior rubric，由 GUI agent 開瀏覽器實際玩後判 rubric；但本次核到的官方 GitHub README 是靜態 **Play2Code demo gallery**，只有八款 browser playable games，並非 200 題完整任務／rubric corpus，不能宣稱該題庫已可批次重跑。

另外要把兩個研究元件分開：PlaytestArena 是生成成品的 GUI 評估環境；Play2Code 則明確讓 coding agent 和 GUI playtester 在共享記憶與 runtime 中多輪對話改版，不符合使用者不在中途介入、只驗收最後產品的嚴格比較 protocol。它的主要價值是可借鏡以可見畫面與真實輸入評遊戲，並為自主 QA 建立可追跡回饋；不是現成的一次生成候選榜。

來源及查核範圍見[搜尋批次 S24](../search/S-20261007-24-academic-generation-benchmarks.md)。

**S44 論文 v2 覆查：**2026-10-02 的更新論文報告 200 款遊戲／1,548 行為 rubric，GUI judge 為 GPT-5.5；其逐 rubric 與人類標註 raw agreement 87.9%、κ=.66，遊戲分數相關係數 Pearson／Spearman 均 .89。這提升其作為真實遊玩式評估方法的證據，但 repo 仍只見八款 demo gallery，完整 200 prompt/rubric corpus 與 evaluator harness 未公開；Play2Code 生成與 GUI playtester 多輪往返也不符合核心的使用者單次交辦協定。詳見 [S44](../search/S-20261007-44-formal-benchmark-artifact-and-roster-audit.md)。
