# M0027 · 自主遊戲代理的長流程任務與可觀測方法

**類型：**方法／鄰接研究　**狀態：**鄰接方法參考；測自主玩既有遊戲，不測遊戲生成，不能納入生成成績　**最後整理：**2026-10-07

## 發現與來源

### Portal Agent：長時視覺遊玩與完整 session trace

GPT-6 Astra 以 Codex 控制 Portal，初始任務是通關至片尾字幕並禁止上網查攻略。作者公開了控制器、修改過的 SourcePauseTool、Windows 設定文件與遮蔽個資後的 session log。模型透過 MCP 接收遊戲截圖、角色位置與鏡頭方向，執行一組輸入後再次暫停並檢查結果。作者記錄模型為 GPT-6 Astra Max；全程約 23 小時 43 分，因容量問題中斷後續跑並切到 Fast 模式。作者也在完成事件後要求讓片尾字幕繼續播放。因此它有極高可觀測性，但不能稱作完全無人類訊息介入或單一固定模式的嚴格 run。

公開 evidence README 說明，遮蔽版匯出保留 6,925 筆記錄（原始 26,460 筆），移除 3,263 個圖片出現及私人資訊；只提供 sanitized log，原始 log 未公開。這仍比只有剪輯影片更能檢視工具調用與行為，但圖像觀察本身遭移除、無法完整第三方重播，且這是既有遊戲通關，不是 AI 開發遊戲。

### agent-wow：文字／封包狀態下的任務規劃

作者文章公開初始指令：`create an orc character and complete all quests in the starting zone`。作者稱 GPT-6 Astra xhigh 約 40 分鐘完成魔獸世界獸人新手區任務，零死亡，並提供完整遊戲錄影及 agent reasoning trace。其 agent-wow 開源 client 以 AzerothCore 私有本機伺服器、WoW network protocol 及自建模組與遊戲互動；這次 run 讀取 server SQL 任務資料、建立 C++/Detour navmesh 尋路程式，整合先決任務、賣垃圾、裝備升級與技能訓練。

此案例是一個短區域自主遊玩任務，不是製作遊戲；也不是純螢幕輸入任務或標準化模型榜。它展示任務終點、遊戲記錄與自主工具生成可如何被一起觀察，但作者仍有待確認其能否擴展為完整升級或多人 raid。

### When Agents Rule：可重播的策略遊戲 agent harness

此開源 browser RTS 可固定地圖 seed、文明與資源配置，提供即時或輪替模式、相同 JSON state、最多每輪三項命令及獨立計畫工具；公開結果包括工具有效率、回合／延遲、對局 transcript 與 JSONL。作者明言這是 hobby testbed、非正式 benchmark；頁面收錄至 2026-10-03 的歷史對局，尚未見 GPT-6 Astra／GPT-6.1 Sol 結果。可參考的是固定條件、揭露 tool errors、同場完整 log，不是該作品的分數或生成案例。

## 評測用途及限制

- 對使用者「一次輸入、之後由 AI 自己完成」的協定有方法借鏡：明確終點、記錄每個決策／工具結果、保留失敗回饋與狀態觀測，事後再由人類核對完成條件。
- Portal 與 WoW 測的是 agent 在既有遊戲中的遊玩能力；遊戲世界由人類開發，不能替代生成遊戲的美術、玩法設計、程式品質、內容完整度或交付評價。
- Portal 過程在容量恢復與模式切換時有額外人工操作，最後另收過一句指示；單 run、無多模型重複，也非 benchmark。應將其定位為長時自主示範及 trace 設計參考。
- WoW 有遊戲錄影但公開頁沒有可逐訊息核對的完整 Codex transcript；低階封包控制、任務資料庫及本地 server 也使它不同於一般玩家可直接用的遊戲生成環境。
- When Agents Rule 自稱 testbed 而不是 benchmark；一次 match 或作者自算 heuristic 不足以支持通用模型排名。

## 判斷與重查條件

保留為自主遊玩／可觀測性鄰接方法，不列為一次生成遊戲候選、基準分數或美術證據。若後續出現同一固定 harness 的多模型重跑、正式任務規格與客觀通關 evaluator，可再單獨評估其作為 AI game-playing benchmark 的價值；即使如此仍須與 game-generation 成績分開。
