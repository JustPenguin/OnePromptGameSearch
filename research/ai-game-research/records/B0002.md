## 2026-10-06 最新發布狀態

2026-09-30 預印本提出 **100 份長篇 GDD**（50 Small、50 Big），主測為 Phaser 2D browser games；Small 平均約 14,085 tokens／54.2 個 outcome requirements，Big 平均約 26,297 tokens／84 個 outcome requirements，含管理模擬、平台／Metroidvania、敘事冒險、策略、Roguelite、RPG、射擊與競速等。方法將每份 GDD 轉成固定依賴契約，結合 source inspection、固定 scenario replay 與 adaptive playtesting；實驗中 requirement-level feedback 在兩輪後比 self-revision 增加 10.9% fidelity。

**對使用者目標的關聯：**其 Big GDD 的跨系統規模和保留模型自主開發空間很適合篩選重跑 brief；但論文 evaluation 有明確評測契約／requirements feedback 和多輪修正，不能把最終 score 當作單一使用者委託、途中零干預的 run。更關鍵的是官方 GitHub 頁目前仍寫明 code and dataset「available soon」，雖列出 MIT 授權，尚未實際公開可直接交付的 GDD／starter／replay bundles。因此此刻只記方法與待追蹤資料集，未宣稱已取得可重跑題目。

來源：[2026-09-30 arXiv 預印本](https://arxiv.org/abs/2609.39564) · [官方 repository 與釋出狀態](https://github.com/krafton-ai/a2z-gamespec-bench)。重查條件：repo 實際加入 GDD、起始專案、生成 prompt 與不洩漏驗收 contracts；取得後抽查最複雜的 Big tasks 再決定是否列強重跑題。

**S44 再查（2026-10-07）：**官方 repo 目前仍只有 README、文件圖片和授權檔，並註明 code/data will be available soon；未見 100 GDD 或可執行 evaluator/harness。論文／專案頁描述不能替代已釋出的可重跑 corpus；論文 roster 亦未納入 GPT-6.1 Sol、Sonnet 5.5 或 Opus 5.5。詳見 [S44](../search/S-20261007-44-formal-benchmark-artifact-and-roster-audit.md)。
