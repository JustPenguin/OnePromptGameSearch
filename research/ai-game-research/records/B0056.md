## 任務與兩個輸出

[作者 repo](https://github.com/cagrikacmaz/gpt-6-astra-vs-gemini-3-8-flash) 將此報告稱為一次非正式同題 agentic product-build comparison；執行日期 2026-09-05–06。GPT-6 Astra High 使用 ChatGPT build harness，Gemini 3.8 Flash High 使用 Google Antigravity；兩邊從空白起步，收到 repo 內同一份 [PROMPT.md](https://github.com/cagrikacmaz/gpt-6-astra-vs-gemini-3-8-flash/blob/main/PROMPT.md)，目標是可玩的 3D browser-based civilization simulation vertical slice。

任務要求至少三個自動演化的文明、人口／食物／財富／貿易／外交／衝突壓力與歷史記憶、能把事件與底層狀態連起來的「Why Did This Happen?」、Scenario Lab、玩家介入，以及 global orbit／top-down／settlement／cinematic 多種視角；並要求模組化分離 simulation、rendering、UI、content、AI adapter。這是高系統 sandbox／模擬題，不是帶有明確最終通關目標的傳統遊戲。

公開 artifact 主要是 repo 內兩組截圖、[GPT-6 Astra 互動錄影](https://github.com/cagrikacmaz/gpt-6-astra-vs-gemini-3-8-flash/blob/main/media/video/astra-demo.mp4)、[Gemini 互動錄影](https://github.com/cagrikacmaz/gpt-6-astra-vs-gemini-3-8-flash/blob/main/media/video/gemini-demo.mp4)、[methodology](https://github.com/cagrikacmaz/gpt-6-astra-vs-gemini-3-8-flash/blob/main/METHODOLOGY.md)、[findings](https://github.com/cagrikacmaz/gpt-6-astra-vs-gemini-3-8-flash/blob/main/FINDINGS.md) 與 [limitations](https://github.com/cagrikacmaz/gpt-6-astra-vs-gemini-3-8-flash/blob/main/LIMITATIONS.md)。repo 未提供兩個 playable site URL 或遊戲 source，因此現有互動不能直接獨立重跑。

## 作者手動檢查結果

- 作者觀察 Astra build 以 3D 世界為視覺重心、逐步揭示資料面板，且在手動操作中相機 orbit、strategic top-down、close settlement views 有明顯改變。
- Gemini build 提供較多 Scenario Lab 建立方式和比較數據面板，但 manual testing／錄影中相機視角按鈕未有預期的畫面變化；其內部 implementation summary 聲稱有實作，與作者手動觀察相矛盾。
- Gemini 畫面顯示模擬財富增至約 10^15、三文明不平等率都接近 95%；作者指出這可能是複利／數值尺度問題，但沒有 source 或不變量 audit 驗證原因。
- 兩邊有可玩的 browser build 是作者報告；它們沒有被正式檢查 simulation mathematics，也沒有盲評或多次 run。以上不是使用者美術評價，也不是本研究獨立測試。

## 一次委託證據、公平性與定位

作者稱兩系統收到同一 prompt、被要求自主建立 playable vertical slice；但 README 明確承認 ChatGPT build harness 與 Antigravity 不同，compute／token／runtime budget 未正規化。Astra 遇到 plan limits 後續行。沒有對話匯出或 agent/tool trace，無法查使用者是否中途補充、Astra resume 如何執行、兩 build 的停止時狀態和版本 hash。這不是可公平解讀的模型排名，且比 GPT-6.1 Sol／Sonnet 5.5 run 舊。

保留它是因為「同一長規格對照兩個實際互動系統」提供可重用的高難任務和有用的驗收反例：rendered controls 不等於功能，agent self-report 也不等於手動操作證據。若以最新模型重跑，可把相機狀態、文明數值不變量、跨時間運行穩定性、Scenario Lab、玩家介入及玩家可理解的事件因果性納入盲測；保存雙方 source/build、原始 session、相同工具預算和玩家結果。
