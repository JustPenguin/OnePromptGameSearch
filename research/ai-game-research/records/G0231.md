# G0231 · GPT-6 Astra GTA-Style Driving Prototype

**類型：**遊戲／具體題目　**狀態：**排除主測；保留作 strict one-prompt 薄弱結果對照　**最後整理：**2026-10-06

**別名：**GTA-style one-prompt prototype

## 發現與來源

2026 年 9 月由 YouTube 創作者使用 GPT-6 Astra、extra-high 推理設定，在空專案以一段 prompt 產生瀏覽器駕車原型。公開報導記載它有可駕車輛、小地圖、日夜變化、六個檢查點任務與拍照模式；報導也描述三張 build preview。主要可查來源為[測試整理與影片脈絡](https://skalablog.com/p/gpt-6-astra-game-test-can-it-recreate-gta/)。

搜尋批次：[S-20261006-19](../search/S-20261006-19-current-runs-and-benchmark-methods.md)

## 證據與限制

- 報導稱一段 prompt 在空資料夾啟動；作者之後錄下多則 prompt，主要用來告知使用額度重置。原始任務全文未公開，只說可在頻道社群下載 PDF；因此目前無法比較任務規格，也不能確定後續訊息是否改變了遊戲。
- 模型／工具由報導記為 GPT-6 Astra、ChatGPT 桌面端、extra-high；精確日期、完整執行 trace 和 frozen build 均未提供。
- 報導稱 demo 只覆蓋幾個街區，缺少路人及其他交通工具，周邊建築退化成無貼圖方塊，實際瀏覽器畫面幀率低；它證明能造出可操作原型，但離完整遊戲與高美術標準有明顯差距。
- 沒有可獨立進入的公開 playable link；影片畫面是目前可確認的真實成果呈現。

## 判斷與重查條件

不列上限主測：核心仍是小範圍駕車／檢查點原型，沒有完整開放世界的內容量、任務鏈或高品質完成度；原始 prompt 和可玩首版亦不可查。可作為 strict one-prompt 只產生原型時的失敗邊界參照。若作者公開原始 prompt 與 playable build，再重新判斷。來源及查詢見批次 S19。
