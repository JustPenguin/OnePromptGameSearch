# G0265 · IDF v Hamas (GPT-6.1 Sol initial / Opus 5.5 rebuild)

**類型：**遊戲／具體題目　**狀態：**高系統軍事 FPS 任務種子；repo 明示 GPT-6.1 Sol 初版後由 Claude Opus 5.5 重建，沒有保存可辨認的 Sol frozen build，故不作 Sol 成品或 one-shot run　**最後整理：**2026-10-07

**別名：**IDFvHamas、IDF v Hamas

## 發現與來源

repo [rrcatto/IDFvHamas](https://github.com/rrcatto/IDFvHamas) 說明此 browser FPS 初版由 GPT-6.1 Sol xhigh 產生，後以 Claude Opus 5.5 extra high 重建。作者公開 [原始 35.8 KB task spec](https://github.com/rrcatto/IDFvHamas/blob/main/20261004-1154-IDFvHamas-prompt.md)、[v1.00 source](https://github.com/rrcatto/IDFvHamas)、[正式 release](https://github.com/rrcatto/IDFvHamas/releases/tag/v1.00) 及[驗證報告](https://github.com/rrcatto/IDFvHamas/blob/main/VALIDATION.md)。2026-10-06 v1.00 的 Git commit 一次加入最終完整專案；目前 repo 只有 README、test/release 相關 commits，沒有 GPT 初版與 Opus rewrite 之前可用的公開 baseline。

## 任務與最終版本範圍

任務要求 browser Babylon.js 第一人稱 FPS，三個 5 分鐘地圖波次，含可進入多層建築、武器切換、手榴彈、煙霧、爆裂桶、敵人 pathfinding／視線／grenade、敵方狙擊／RPG 等角色、有限補給、得分與重生；需桌機操作、遊戲選單、設定、loading、結果畫面及靜態離線部署。原 spec 要求設計與自測；README 表示所有素材已 bundling、無外部 runtime request。

README／changelog 描述的 v1.00 在功能和美術技術範圍都很大，但不能把最終版本特徵歸給 GPT-6.1 Sol：repo 明確說後來由 Claude Opus 5.5 重建，且沒有保存第一版對應 source/build、commit、session 或兩版差異。不能用最終 v1.00 美術或玩法評估 Sol 的 output，也不能推斷 Sol 自主迭代方式。

## 可查驗證與限制

作者發布的 [VALIDATION.md](https://github.com/rrcatto/IDFvHamas/blob/main/VALIDATION.md) 報告 Opus 重建的 v1.00 通過 strict typecheck、51/51 Vitest、20/20 Chromium gameplay suite、另 8/8 cover、11/11 weapon、Chromium／Firefox real-mouse checks、build 與 production smoke。報告說作者使用 RTX 3060 Laptop／Windows Chrome，High quality 1600×900 約 70 fps median；這些是作者驗證 Opus 最終版本，不是 GPT 初版結果，本研究未獨立執行測試。

該 brief 可作為高系統 FPS 重跑任務，但題材是明確現代軍事／真實政治衝突背景。是否納入主研究的重跑候選可按研究題材選擇；不應將此 repo 作 GPT-6.1 Sol 的最終交件證據。要升級初版 provenance，需原 GPT session、保存下來的初版 source/build/hash 與 Opus 改版 commit/diff；要評現成最終成品，則要明確標模型為 Opus 5.5 並記錄作者後續編輯範圍。
