# G0164 · Turbo Kart Rally

**類型：**遊戲／具體題目　**狀態：**適合賽車副題重跑；有獨立一圈 build 檢查與公開實機畫面，零介入僅作者自述；策展人工截圖評分 9.8/10（非使用者評價）　**最後整理：**2026-10-07

**使用者美術驗收（2026-10-07；[E0008](E0008.md)）：不合格。策展人工 9.8/10 是外部 visual score，不取代使用者判定。**


**別名：**Frontier Games 五Opus子代理

## 現行判斷

**作者公開一則原始 prompt、Claude Opus 5.5、五個平行子代理與可玩的 Three.js build，足以作賽車副題重跑；零追問／零介入仍是作者自述，沒有完整 session trace。**遊戲有 Palm Cove 單一賽道、七名 AI 車手、甩尾加速、八種道具、角色選擇、三種排氣量級、賽果和合成音樂音效。原始 prompt 要求啟動五個 Opus 5.5 子代理、做 AAA 品質的 Mario Kart 類遊戲、過程不提問，完成後回報。新檢視的同版 gameplay screenshot 清楚呈現賽道、HUD、對手和程序式低多邊形環境；AgentsLoop 策展者給此圖人工視覺分 9.8/10。這是策展評分而非使用者審美驗收，研究者觀察也不等於 AAA 品質。

作者也公開架構合約、模組歸屬及各代理的本地測試；UI 與遊戲代理整合後在瀏覽器實際 play-test。第三方 Floating Arcade 保存了其 repo 同版 build，並以鍵盤 script 跑完一圈至賽果，再觀察遊戲 autopilot 約半分鐘；其觀察到一圈與結果畫面正常，當時賽事約 54 FPS。這是可玩性補證，不是模型 run 的獨立 provenance 稽核。

## 證據及適用界線

[原始 prompt、協作與玩法說明](https://github.com/bridge-mind/turbo-kart-rally) · [可玩 build](https://bridge-mind.github.io/turbo-kart-rally/) · [作者原始貼文](https://x.com/bridgemindai/status/2102451997395866021) · [第三方同版 build 與一圈實測](https://tikgame.org/game/turbo-kart-rally/)。候選作品集另外提供[遊戲畫面與遊玩來源索引](https://github.com/theolundqvist/frontier-games)。

- 這款不是「只一句 prompt 生成後零測試」：同一個使用者請求授權並要求五個代理協作，代理測各模組，整合代理試玩；符合使用者允許 AI 自主修正的定義。
- 只包含一條賽道，無多賽道賽季或劇情長流程；與使用者已肯定的 Kart Blitz 題型重疊，保留作賽車副題，不把新增一款賽車當成研究多樣性。
- 美術具有一致、明亮的低多邊形卡丁車風格；來源 repo 有實際比賽截圖，策展者對構圖、環境細節及動作可讀性給 9.8/10。這不是使用者的美術判定，也不能據此宣稱寫實或 3A 級；需由使用者看[比賽實機圖](https://github.com/bridge-mind/turbo-kart-rally/blob/main/docs/screenshots/race.jpg)或 playable build 判斷。
- 第三方測試只跑了一圈，鍵盤程式駕駛撞牆並排第八；測試者明說這反映其 script，不是對遊戲品質的評分。該測試沒覆蓋所有排氣量／圈數、手把或觸控；repo 說明是桌面鍵盤／手把遊戲，手機沒有賽事控制。
