# B0050 · OpenGameEval

**類型：**基準／評測　**狀態：**可重跑的 Roblox 工作階段／除錯補充基準；非完整遊戲生成　**最後整理：**2026-10-07

**別名：**Roblox Studio Assistant LLM Leaderboard

## 來源與目前內容

- [論文：OpenGameEval: Benchmarking Agentic Programming and Exploration in a Stateful Game Engine](https://arxiv.org/abs/2610.02563)；[官方開源 repo](https://github.com/Roblox/open-game-eval)；[官方現行 leaderboard](https://github.com/Roblox/open-game-eval/blob/main/LLM_LEADERBOARD.md)。
- 論文版收錄 84 個核心任務與 29 個除錯任務、13 個模型、每題 16 次嘗試。核心任務中 63 題從已有內容的 Roblox place 開始，21 題從空場景／平坦地形開始。任務要求模型探索並修改場景／腳本，通過場景斷言及模擬遊玩驗收。
- 截至本次檢閱，官方 repo 的 leaderboard 已擴為 87 個 eval；表中最新列有 Claude Fable 5、Opus 4.6、Gemini 3.5 Flash、GPT-5.5 等，沒有 GPT-6 Astra／GPT-6.1 Sol。論文表與現行 repo 數量、roster 不同，應分開引用。
- 任務 Lua、place 檔、評測工具可公開取得；MIT 授權。執行需要 Roblox 帳號、OpenCloud 評估 API key、模型供應商憑證；官方說明稱單次評估通常數分鐘。公開榜以 Pass@1／5、Cons@5、All@5 與工具錯誤率報告。

## 與本研究目標的關係

它能測 AI 在既有遊戲狀態中的探索、腳本修改、場景理解與除錯，是自主代理在遊戲引擎內工作的有用補充；官方工具與題庫也提供可查驗的固定環境。可是大多數任務不是由空白專案生成完整遊戲，評分成功也不代表交出一款完整 playable game。不得把榜單當完整遊戲生成能力排名。

## 證據界線與重查條件

任務及驗收材料比一般 demo 更容易重跑，但測試需要 Roblox 雲端評估 API 與模型 API 憑證；原論文較早模型 roster 不代表現行 frontier model 結果。若官方新增 blank-start 完整遊戲任務或列入更新模型，可重查其是否升為完整遊戲生成基準。此次作方法／引擎操作參考，不更新精選遊戲候選頁。
