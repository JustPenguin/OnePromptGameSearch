# B0048 · WorldCoder-Bench

**類型：**基準／評測　**狀態：**可重跑的 Three.js 互動 3D 世界子題來源；不評完整遊戲交付　**最後整理：**2026-10-07

**別名：**WorldCoder-Bench 3D world generation benchmark、StateProbe

## 公開資料與任務範圍

論文提出 2,026 個自然語言 Three.js 世界生成任務，涵蓋模擬、渲染與應用場景；以 StateProbe 在沙箱瀏覽器檢驗隱藏的狀態／互動合約，並用 mutation-hardened assertions 查錯誤實作。論文報告九個較早期模型中最佳 verification coverage 為 Core 27.8%、Robust 19.9%；這不是目前 frontier 模型榜，也不是完整遊戲通關率。

作者公開的 GitHub rebuttal snapshot 含 **2,004** 個具 `task.json` 與 `icg.json` 的任務，以及 StateProbe evaluator、離線 Three.js runtime、mutation demos，可用 `P107_avocado_slicer` 範例對生成的 HTML 個別執行檢查。Repo 明確說這是 205 個 core + 1,799 個 HF snapshot 合併後的 2,004 unique tasks，不代表論文 canonical 2,026 split 完整 membership；另有幾個任務引用的圖片缺失。評估頁需暴露可見的 `window.__3D_STATE__` 等狀態介面，故比終端使用者黑箱遊玩多了一個接線條件。

- [論文](https://arxiv.org/abs/2606.01869)
- [可重跑任務與 evaluator repo](https://github.com/shuolucs/WorldCoder-Bench)

## 與一次生成完整遊戲的關係

這是可挑選 3D 場景、物理互動及狀態轉換題目的任務庫與 evaluator，不是完整遊戲一次生成資料集：repo 沒有任何模型生成的 HTML、trajectory、截圖、API 回應或模型評測結果。它不能替代具有角色進度、長循環與完整勝敗流程的上限主測；可用來給已交付成品加一組獨立 3D 行為驗收，或挑一個互動密集的技術副題重跑。

## 判斷與重查條件

保留作 **3D 行為測試方法與可重跑子題來源**，不把舊模型成績當作當前模型能力，也不把單個 world task 稱為完整遊戲。若官方公布完整 2,026 split、模型輸出與可比 run protocol，再更新資料集差異與現行模型 roster。
