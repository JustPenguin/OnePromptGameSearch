## 2026-10-07 近期 3D 條目查核（S84）

Hugging Face 的 [2026-10-03 snapshot](https://huggingface.co/datasets/kvickan/games-made-with-ai)列 536 款 AI 編碼遊戲，每筆含 creator/model/tool/engine/genre、可玩 URL、來源證據等欄位。資料源說明 AI/model 資訊由 creator self-report；它是發現索引，不代表每筆已有原始 prompt、session、凍結 build 或獨立評測。S84 另抽查 GamesByAI 上 3 個新近 Three.js 高評分項：

- **JellyBlob：**catalog 列 GPT-6 Astra 與 Claude Opus 5.5、Codex／Claude Code；頁面有實際 multiplayer gameplay screenshots 與 browser build。作者直接聲明「hundreds of iterations from my input and instructions」，最初 Astra 版後又以 Opus 5.5 remake。畫面值得作高品質 stylized 3D 參照，但明確不符合一次委託，不能作 zero-intervention 成績。
- **Rimehold：**creator submission issue #54 列 Claude Opus 5.5、Sonnet 5.5、Claude Code、Three.js、all code by AI；作者說把決策交給 Claude 並參考 Warcraft III maps。遊戲頁說防守 40 waves／4 bosses，有 browser build 和宣傳圖；未見原始 task、session、model assignment、frozen version 或 gameplay capture，不能由此判定一次委託或把宣傳圖當實機美術證據。暫作待查任務／視覺線索，不納 strict 候選。
- **Sumo Boulders：**creator submission issue #94 列 Claude Code／Three.js、all code by AI，但模型欄空白，沒有 prompt 或 session；作者自述八座物理不同的競技場、六種 AI 性格、階梯賽、八顆岩石 Battle、建造器、P2P online 和 gamepad。項目完整度可能值得重跑，然而公開材料不足以核實 agent autonomy 或對照遊玩畫面。

這批 directory/page stars（少量使用者評分）不是標準美術／遊戲評測。查核與排除理由記在 [S84](../search/S-20261007-84-ai-game-catalog-3d-highlights-audit.md)。
