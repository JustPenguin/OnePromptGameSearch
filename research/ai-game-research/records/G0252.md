# G0252 · AGI Soon

**類型：**遊戲／具體題目　**狀態：**高價值流程待核：作者稱 Astra 自主生成並用 bot 執行大量模擬；是否只有一次委託及完整 build 範圍未公開　**最後整理：**2026-10-07

**別名：**agi.dpa.plus；Astra-built deterministic simulation game

## 公開成果與技術特點

[作者展示貼文](https://www.reddit.com/r/codex/comments/1woa554/codex_built_the_game_codex_plays_the_game_codex/)連到可玩的 [AGI Soon](https://agi.dpa.plus/)。作者稱這原是測試 GPT-6 Astra／Codex 和 Blender MCP 的小實驗，最後延伸成 1.5 天完成的完整遊戲；作者沒有手工製作資產。其開發方式先做 headless deterministic simulation，再讓 bots 跑數千局；若發生問題，可 replay 舊局並比較。遊戲亦提供 agent API，作者稱 Codex 自己玩到了排行榜第一。這讓遊戲生成、自動測試與可觀察遊戲表現連在一起，對自主 QA 有特殊研究價值。

## 一次委託證據界線

目前是一手作者貼文加可玩站點；貼文說由 Astra 完成，但沒有逐字任務 prompt、完整 session、程式碼倉庫或可檢查的 run archive。作者明言 onboarding 和 UX 仍需人眼檢查，但沒有交代這是唯一人工介入，亦沒有明確說開發期間只下達一則使用者任務。1.5 天和「entirely with Astra」是作者申報，非獨立核實。

因此不作已驗證 one-shot 成績，也暫不當成可直接複製的強重跑題。比一般成品貼文更值得追查的原因，是其 deterministic engine、bot 批次模擬和 agent API 提供具體自主測試方法。

## 判斷與重查條件

列為高價值流程待核線索。若作者公開初始任務、完整或可稽核 session、source／規則規格及最終 build 的版本對應，可進一步評估它是否是一則任務交代後完全由 AI 自主完成的 run。若只是人類持續規劃／多次補 prompt，保留為自主 QA 方法參考，不列一次委託成績。美術尚未由使用者評價。
