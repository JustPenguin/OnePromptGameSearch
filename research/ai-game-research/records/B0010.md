# B0010 · GameASG-Bench

**類型：**基準／評測　**狀態：**高價值可重跑的 browser-game 基準；官方 runner 可鎖模重跑　**最後整理：**2026-10-07

**別名：**GameASG、areal-project/GameASG-Bench

## 最新查核（2026-10-07）

2026-09-18 論文版記錄 47 個 browser-native 生成任務，涵蓋 12 種主要類型及 2D／3D；每題有可執行檢查和獨立驗證的參考實作。評估以 L1 靜態規格檢查及 L2 真實輸入／執行狀態檢查構成。九種 agent stack 中最高嚴格任務成功率為 26/47（55.3%），雖然最高平均 L2 檢查通過率達 93.2%；這支持同時報告「全部必要檢查皆通過」與分項通過率，避免平均數掩蓋未完成的必要功能。GPT-6 Astra + Codex CLI 是論文中最高嚴格成功率組合。

官方 repo 可取得 47 個任務的 `target.md`、`game-spec.md`、`tdd.md`、L1/L2 checks 及 runner；單次命令從 clean generation container 產出單一 `index.html`，以一個 fresh attempt、3600 秒預設上限完成，之後在隔離評測 container 執行測試。agent 可被設定具名模型與 harness，故可用當前模型重跑固定題庫，並保存 build／trace／generation metadata。本輪逐題重核其中 [Fast Food Tycoon](G0056.md)：3D 餐廳經營閉環、資源守恆、NPC／雇員自動化及長期成長，使它成為遊戲類型較少見的高系統密度重跑題；它是任務推薦，不是已生成的成品或美術通過證據。

**S44 runner／roster 覆查：**官方 README 列出 47 題，32 個 2D、15 個 3D；`target.md` 是 agent 初始請求，agent 從 workspace 讀取額外 gameplay spec 與 TDD interface，生成 container 移除後才由另一 evaluation container 執行 L1 結構／契約測試與 L2 headless Chromium 操作／行為測試。官方可用 `--model` 明確指定模型，預設一次 fresh attempt、3600 秒。這符合可由使用者重跑新模型的 protocol；但必須記錄該 benchmark 預先提供的測試介面，不能描述成只有一段自然語言 prompt。現有論文九種 agent-stack 結果未列 2026-09 的 GPT-6.1 Sol、Sonnet 5.5 或 Opus 5.5。官方來源與本次範圍見 [S44](../search/S-20261007-44-formal-benchmark-artifact-and-roster-audit.md)。

**S45 官方 3D 任務篩選：**逐題比較已標示 3D 的任務後，Astroman 是目前最高廣度的城市英雄壓力題，Grand Theft Astro 是更可控的開放城市 sandbox，Tankor Arena 是範圍收斂的 3D 戰鬥替代題；Fast Food Tycoon 是系統最清楚的 3D 模擬閉環。這些任務有實際行為測試契約，但無公開 AI 完成品可作為美術範本；畫面美術仍待模型重跑後評估。推薦層級與各題差異詳見 [S45](../search/S-20261007-45-benchmark-task-screening.md)、[G0259](G0259.md)、[G0260](G0260.md)、[G0056](G0056.md) 及 [G0072](G0072.md)。

它是強功能與行為驗收基準：完整任務庫可直接重跑，使用者所認可的候選題已另立[G0018](G0018.md) Armor Alley、[G0072](G0072.md) Grand Theft Astro等紀錄。但生成端須遵守單一 HTML 交付及公開 `window.__gameTest` 測試契約；這會考驗可測試性與行為合約，也把模型限制在 browser-native 2D/3D 單頁遊戲形態，不能完全等同自由引擎或高品質商業美術。評測層不評主觀樂趣；模型版本與日期須由重跑者另行凍結記錄。詳細資料及可比成績的限度見[S24](../search/S-20261007-24-academic-generation-benchmarks.md)。
