## 題目規格與成品

任務包含兩個互相連動的部分：先把 AK-47 與 AR-15 的零件做成可隨頁面捲動而組裝的高品質 3D 展示，有材質、照明、鏡頭運動與零件動畫；再把組裝完成的槍與資產接入瀏覽器第一人稱射擊遊戲。玩家在受襲的武器工廠中作戰、拯救同事、維持供電、迎戰外星入侵，並須有清楚開場、可玩戰鬥、遊戲目標、結束／重新開始。Prompt 明確要求組裝展示和 FPS 轉場兩端都能在網頁工作，模型須驗證轉場及戰鬥。

實際成品命名為 **Shift Zero**，公開 playable 網頁可供使用者直接開啟與操作。頁面包含 AR-15／AK-47 選擇與模型檢視、工廠警報／班次開場、撤離 crew、維持電力和三波攻勢；提供 WASD 移動、滑鼠瞄準、射擊、換彈、切換武器及跑步／跳躍控制，結束可暫停或重新開始。作者另連出實際 run 影片。

## 評測價值與限制

- **美術可檢視性高：**不是單張宣傳圖；同一 playable page 可檢查槍械零件、材質、動畫、鏡頭／照明轉場，再實際玩 FPS。使用者已判定美術不合格；畫面仍可用來檢視其遊戲系統與射擊流程。
- **整合難度：**跨越產品式互動展示與第一人稱遊戲；需讓模型資產在兩個場景重用，維持瀏覽器捲動控制與 FPS 操作切換，並實作目標、同伴救援、電力壓力、敵潮、UI、勝敗與 restart。若轉場後 FPS 只是短小射擊場，也須區分展示／完整度，勿光憑 prompt 認定規格全通過。
- **證據限制：**網站列 1 prompt／1 run、模型與 effort；但未提供 agent trajectory、source code 或第三方 playtest。直接 build 可玩，源碼可追溯性及自我 QA 的細節弱於 G0206 Smash Karts。
- **安全範圍：**內容把武器明確限定為虛構遊戲模型／遊戲玩法；測試比較的是瀏覽器展示與遊戲系統整合。
