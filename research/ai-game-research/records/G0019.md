## 2026-09-30 GPT-6.1 Sol run 補證

VitoMind 的同提示測試文章將 Ashen Vigil 列為 GPT-6.1 Sol medium 的四個一請求 demo 之一。作者稱其為黑暗奇幻 boss fight，包含鎖定、輕攻擊連段、跳躍、格擋／反擊、地面重擊、Boss 第二階段地面火焰；約 60,000 字元、5.5 分鐘、作者 API 成本 US$0.21，並稱首次執行無錯誤且為 60 FPS。原文也公開可玩的 [Ashen Vigil build](https://ruocco.it/ai-demos/gpt-6-1-sol/ashen-vigil.html)。

以上仍是作者對 run 與測試的自述；文章公開了實際成品，但沒有逐輪 session trace、凍結檔案 hash 或完整原 prompt。這是一場短 Boss encounter，不含長流程、探索進度、經濟或完整勝敗後重玩循環；可作新模型視覺／近戰操作副測參照，不能代表完整遊戲生成上限。使用者尚未對該 build 美術作獨立判定。
