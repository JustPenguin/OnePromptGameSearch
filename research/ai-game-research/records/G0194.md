# G0194 · NOVA LANCER

**類型：**遊戲／具體題目　**狀態：**強候選　**最後整理：**2026-10-06

**使用者美術驗收（2026-10-07；[E0008](E0008.md)）：不合格。**此項只記錄美術判斷；玩法、系統、可玩程度及重跑價值另行評估。

**別名：**Nova Lancer Opus 5.5、Star Fox-inspired rail shooter

## 現行判斷

**值得列為一次委託的 3D 動作遊戲強候選，尤其適合測首版如何把大方向的創意任務擴成可通關的遊戲；美術仍待使用者看實際 build 判斷。**它的原始委託只有一句：「可以用 Three.js 等工具，做一款像 Star Fox 的遊戲嗎？希望品質盡可能豐富。」Claude Code 搭配 Claude Opus 5.5 MAX 約 1 小時 40 分完成，兩個子代理分別處理音樂／音效和通訊肖像。作者說由設計、程式到演出和測試皆為一次連續作業，且沒有畫面時也以逐幀與自動駕駛 bot 從頭玩到尾。

## 遊戲規模與實測證據

可玩 build 是一款完整單關 3D 軌道射擊遊戲：夕照海岸、紅岩峽谷、霓虹要塞城三種場景接續成同一任務，途中有敵機、救援僚機、地形障礙與能量門；武器包括蓄力鎖定射擊、炸彈與滾轉，另有護盾環、升級和檢查點。最終對抗機械海龍 Boss，並提供難度、成績／勳章／高分保存、遊戲手把及觸控操作。工作量與跨系統整合顯著高於小型射擊展示，但仍是一關、軌道式玩法，並非長流程角色扮演遊戲。

作者提供 9,600 行左右 source、原始一行 prompt、工具／模型／推理等級、API 呼叫和輸出 token 統計，以及 AI 自動遊玩的說明。公開更新紀錄同時顯示，成品發佈後有人修正過未顯示的玩家／敵人子彈及手機 UI 斷行。因此，**它的原始 one-shot run 很有參考價值，但目前線上 build 含發佈後人工修補，不應直接當成未改動的一次交付分數**；模型比較宜重跑原始任務並保留凍結的 AI 最終 build。

## 適用邊界

- **任務規格很短：**只給一個風格與品質方向，能看出模型如何自行拆解設計；若要嚴格跨模型比較，這種開放規格會帶來較大的玩法選擇差異。
- **自主測試證據強但屬作者自述：**公布了自動駕駛和逐幀測試工具，未有第三方重做測試。
- **可玩頁與成品畫面可查看；美術標準由使用者決定：**作者提供原創程序場景與肖像，不使用圖像／音樂檔，但尚未取得使用者的視覺通過。
- 已公開 build 在生成後被作者修過兩項明確 bug。評比時需重跑 prompt 並保存 agent 停止時的原始交件，避免把人工後修混入模型成績。
