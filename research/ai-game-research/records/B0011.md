## 2026-10-07 官方 corpus、執行協定與模型 roster 複查

官方 repo 現列 **140 個 Godot 任務、15 種遊戲家族**。每題提供自然語言規格與 Godot workspace，agent 須交完整可啟動專案及 replayable demonstration traces；外部 verifier 啟動遊戲、重播操作、錄製互動證據，再用 hidden rubric 與多模態 judge 評分。公開任務包括 platformer 19、strategy 17、tycoon 16、open-world 15、roguelike 14、visual novel 11 等。這是從單一 task brief 到完整 playable project 的自治 agent 測試，適合固定環境交給最新模型重跑；實際公平比較須固定 Godot 4.6.2、資產池、agent/harness、模型 effort、時間及工具權限。

已公開的 results 頁截至此查核仍以 2026-07-31 DeepSeek-V4-Flash row 為較新列項，榜首為 Claude Code／Opus 5 xhigh（2026-07-24，68.44）；Codex／GPT-5.6 Sol high（2026-07-09）為 60.50。這些結果證明公開有成套可視 build/評分及任務來源，但對 2026-10 的模型比較已非最新 roster。官方頁另有一處摘要寫「strongest ... 65.70%」，與同頁榜表 Opus 5 的 68.44 不一致；本紀錄以逐列 leaderboard 為準並保留該矛盾，不引用 65.70 作總結。

**上限與評分邊界：**官方範圍是 2D Godot，不包括 3D、多人網路、大規模物理或長期製作流程；評估機制、內容深度、功能視覺與 art/presentation，但不主張自動評分能證明遊戲有趣。bench task 和遊戲操作本身可重跑；公開 leaderboard 成績不可冒充最新 frontier 結果。既有 [Airship Trader](G0014.md) 是本庫已挑選的 open-world 經濟題，不需新開重複遊戲紀錄。

來源及本輪判斷詳見[搜尋批次 S24](../search/S-20261007-24-academic-generation-benchmarks.md)。

**S44 官方 repo／roster 覆查：**目前 repo 明載 140 tasks／15 game families，task 提供 spec＋Godot workspace，agent 交完整專案及 replay traces，由 verifier 實際啟動重播並以 hidden multimodal rubric 評分；因此任務資料和評測協定確實可下載使用，足以讓當前模型現場重跑。官方榜最新一列仍為 2026-07-31 DeepSeek V4 Flash，榜首是 2026-07-24 Opus 5 xhigh；沒有 GPT-6.1 Sol、Sonnet 5.5 或 Opus 5.5。頁面摘要的最高總分 65.70 與表內 68.44 不一致，本紀錄仍以完整表列數據為準。重查與查詢清單見 [S44](../search/S-20261007-44-formal-benchmark-artifact-and-roster-audit.md)。

**S45 任務與成品篩選：**官方 benchmark 網站另公開單題錄影和 playable build。Tycoon Submarine Pressure Rescue 的 GPT-5.5/Codex run 得 overall 68.70（mechanics 90、depth 85、visuals 75、art 41）；Tycoon Garden Ecosystem Keeper 有 Seele02-pro run（80.23；90.63／70.76／80.70／85.04）及 Opus-4.7 run（70.50；100／82／58／51）。其中 Garden 是本輪找到最值得直接查看的相對高美術分數實物，尚待使用者判定；Submarine 則是高系統、低藝術分數分離的參照。GameCraft 的任務題型仍為 2D Godot，因此不可作 3D 上限的替身。項目逐題比較、影片和 playable 連結見 [G0261](G0261.md)、[G0262](G0262.md) 與 [S45](../search/S-20261007-45-benchmark-task-screening.md)。

**S45 任務與成品篩選：**官方 benchmark 網站另公開單題錄影和 playable build。Tycoon Submarine Pressure Rescue 的 GPT-5.5/Codex run 得 overall 68.70（mechanics 90、depth 85、visuals 75、art 41）；Tycoon Garden Ecosystem Keeper 有 Seele02-pro run（80.23；90.63／70.76／80.70／85.04）及 Opus-4.7 run（70.50；100／82／58／51）。其中 Garden 是本輪找到最值得直接查看的相對高美術分數實物，尚待使用者判定；Submarine 則是高系統、低藝術分數分離的參照。GameCraft 的任務題型仍為 2D Godot，因此不可作 3D 上限的替身。項目逐題比較、影片和 playable 連結見 [G0261](G0261.md)、[G0262](G0262.md) 與 [S45](../search/S-20261007-45-benchmark-task-screening.md)。
