# G0288 · Jabberwock Rumble (GPT-6 Astra Danganronpa fighting game)

**類型：**遊戲／具名模型輸出與任務線索　**狀態：**有原始 prompt、source、asset-generation metadata、公開 browser／offline build；首輪任務後又接受使用者要求的多項視覺與介面修改，故不符合研究的 strict one-shot 條件　**最後整理：**2026-10-07

## 原始任務與可查輸出

作者在 repo 稱此作為 GPT-6 Astra 能力測試，並保存[原始初始 prompt](https://github.com/cubres/jabberwock-rumble/blob/main/ORIGINAL_PROMPT.txt)：

> Can you make me a simple, mortal combat-like game between Nekomaru Nidai and Akane Owari from danganronpa? Generate sprites yourself, include a Mechamaru skin for Nekomaru and 2 more skins for Akane, make Nekomaru be an AI, while Akane be controlled by the player, make it be fun to play, the game itself, make it be on Jabberwock island and have Monokuma generate some obstacles or modifiers to the battle itself, I want the gameplay mechanics to be extremely simple but fun.

Repo 提供[source 與測試程式](https://github.com/cubres/jabberwock-rumble)、[目前 browser build](https://cubres.github.io/jabberwock-rumble/)、[single-file offline build](https://github.com/cubres/jabberwock-rumble/raw/refs/heads/main/dist/Jabberwock%20Rumble.html) 和 [ARTWORK.json](https://github.com/cubres/jabberwock-rumble/blob/main/ARTWORK.json)。README 描述一場打兩回合的格鬥遊戲，玩家控制 Akane、Nekomaru 由 AI 控制；有五種 cosmetic skins、生成 pose sprites、Monokuma 隨機戰鬥事件、三種難度、觸控／鍵盤與合成音效。作者 repo 內含 engine／DOM 測試程式；本研究只讀取 source 與說明，未執行這些測試或獨立通關。

## 一次委託判定與版本線

- **模型：**repo 作者歸因 GPT-6 Astra；未提供更精確 snapshot、agent／coding harness 版本或完整 session transcript。
- **任務：**上述 single prompt 要求的是一個簡單格鬥遊戲，功能範圍包含角色、AI 對手、skin、場景及戰鬥 modifiers；它沒有列出後來 README 的 60 poses、五個 skin、五種事件等完整數值規格。
- **作者明載有後續修改：**README 說 published version 還包含後續使用者要求的 character accuracy、summer outfits、additional poses、simpler interface 和 typography refinements。這直接違反使用者任務後不再介入的核心條件；最終版不是該 single prompt 的凍結結果。
- **可追版本：**GitHub 首次 README commit 為 2026-09-30 14:59 UTC；包含完整 source／prompt／test 的 commit 為 15:03；角色 sprite sheets 和場景圖新增 commit 為 15:11；offline edition 在 15:14 加入。這條短 commit history 證明有後續 artifact 變化，但不能將每項改動與使用者要求或模型 session 完整對應。
- **美術：**目前圖像採 2D anime fan-game sprites。ARTWORK.json 列出生成器、reference 與各 skin/pose 的圖像 prompt；不能因此推論所有 art iteration 都自主完成，且其 2D 風格不直接滿足本研究優先尋找的高完成度 3D／3A 藝術軸。尚無使用者美術評價。

## 判斷

**排除 strict one-shot 成績榜，不把 final build 當作一次任務後的交付。**它仍有參考價值：單一初始 prompt 簡短、任務具名且可重跑，repo 保留最終程式、圖像 prompt metadata、測試腳本和後續改版痕跡。適合當 2D 格鬥副題或檢視「作者宣稱 one prompt、但公開版本含 follow-up」時的 provenance 例子；不符合研究的完整遊戲上限與 3A 美術優先方向。來源查核與納入／排除理由見 [S82](../search/S-20261007-82-firsthand-game-prompt-and-session-source-audit.md)。
