# G0143 · Slipstream

**類型：**遊戲／具體題目　**狀態：**近期高價值自主 QA／物理副題；美術待使用者判定　**最後整理：**2026-10-07

**別名：**KJLKurt Sol waterslide、KJLKurt GPT-6.1 Sol waterslide

## 2026-10-07 來源核對

**定位：值得以現行模型重跑的 3D 競速物理／自我測試副題；不取代長流程完整遊戲主測。**作者將這個 GPT-6.1 Sol Extra-high build 稱為「0-shot」。公開原始碼、可玩版、製作進度說明與詳細 Playwright 測試範圍；沒有公開原始 session transcript，故模型與「僅一則使用者任務、途中無人介入」仍屬作者申報，不能當成獨立核實的 zero-follow-up 成績。

### 任務與模型

`progress.md` 將原始任務記為：建立 mobile-first 原創 3D waterslide racing PWA，使用 Three.js/Vite 並可部署 GitHub Pages；包括 path-scoped 離線快取、僅瀏覽器端存檔、13 名人形賽車手、坡道／彎道／跨越缺口捷徑、穩定賽道限制與 raycast 接觸、依人格設定的 NPC AI、觸控與桌面操作、畫質自適應、直橫屏介面、倒數／暫停／賽果。這是作者存檔的 prompt 摘要，不是可逐字稽核的聊天匯出。

- **模型／effort：**GPT-6.1 Sol，Extra-high；作者自述於約 2026-09-30 完成（依 repo 建立日期作新鮮度代理，非確切生成時間）。
- **工具／平台：**Three.js、Vite、PWA；公開 GitHub Pages playable build。
- **工作量：**README 列 51 分 58 秒、49 次 API 呼叫、4,821,662 tokens；兩個 related rollouts 是 main run 加一個 auto-review child。價格是作者以 API 費率推算的約 $1.93，並非直接實付金額。
- **一次委託界線：**作者宣稱 0-shot，`progress.md` 記錄空白起始工作區，另有自動 reviewer child；未見公開人類 follow-up 訊息或完整 trajectory。AI 自我檢查／修正符合本研究容許範圍，但公開證據尚不足以獨立證明全程無人介入。

### 成品與 QA 證據

賽道包含兩個自動起跳坡道、實際缺口捷徑、加速帶、檢查點、終點／賽果；Race 模式摔落即 DNF，Practice 模式可於檢查點重生。賽車包括玩家與 12 名 NPC；AI 按 skill/risk/aggression 產生超車、選捷徑、跳躍與失誤。另有設定、持久化解鎖、觸控／鍵盤、直橫屏適配和離線 PWA 支援。

README 所述測試會建置正式版、在兩個獨立子路徑啟動 Playwright Chromium，覆蓋倒數、鍵盤與觸控操控、坡道／raycast 著陸、摔落與 DNF、暫停、練習模式 checkpoint、捷徑缺口落地與回道、首名完賽、NPC 不同結果、設定持久化、直橫屏、快取／儲存隔離與離線重載。`progress.md` 說明測試抓到並修正手機標題過大、起跑門遮擋、練習重生鏡頭等問題，最後測試通過。這些是 repo 內作者留下的 QA 記錄，未由本研究獨立執行；行動裝置實機效能仍未驗證。

### 分項判斷

- **可玩性／系統：**來源記錄支持這是一款含 Race、Practice、NPC、賽道捷徑與完成狀態的可玩短程競速遊戲，並有較完整的自動回歸測試。遊戲範圍仍集中單一賽道競速，沒有長期生涯、賽事群或角色成長主循環，故列副題。
- **美術：**尚待使用者檢視。策展頁目前沒有收錄任何 Slipstream 截圖；其 8.5/10 分數評的是原始碼完整度、機制、執行方式、測試與模型歸因，頁面明言不是視覺評分或 runtime benchmark。
- **最適合測的差距：**不同模型把三維路面／車體接觸、跳躍與著陸、NPC 對手、手機控制、無障礙離線部署和自主回歸測試整合成可玩的程度。
