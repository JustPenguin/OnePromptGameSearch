# G0033 · Chainmate

**類型：**遊戲／具體題目　**狀態：**排除於嚴格一次輸入候選；實物與玩法值得參考　**最後整理：**2026-10-06

**別名：**sneid1棋類roguelite、sneid1

## 遊戲與直接成品

Claude Opus 5.5 + Claude Code + Godot 4 製作的 3D 西洋棋 roguelite；[作者公開的 itch.io build](https://sneid1.itch.io/chainmate) 可在瀏覽器玩，另提供 Windows 版。作者稱程式、3D 棋子／場景、音訊、測試和 builds 由模型製作，無手寫程式碼。

2026-09-24 原始貼文補充四張 ChatGPT 美術參考圖及少量燈光意見；公開頁面在後續又加長 run、重做選單、調整難度／戰鬥類型、增加 Boss、relic 與跨 run 解鎖。現行公開版包含社群回饋後的更新，不能當作原始首版快照。更多核對見[S19](../search/S-20261006-19-current-runs-and-benchmark-methods.md)。

玩法是 6×6 棋盤上的三幕 roguelite，每次 run 九場戰鬥；分支地圖有商店、休息點和事件，棋子存活後可累積經驗、升級或晉升，並攜帶金幣與最多六件 relic。18 種 relic 會改變規則；Boss 有個別規則，敵方棋 AI 會往前搜尋。其進度、戰術規則、美術資產流程與完整 run 使它比一般一次性 chess demo 更有參考價值。

## 為何不符合嚴格條件

作者明確說最初輸入是「build this game」加四張 ChatGPT 製作的美術參考圖，之後又給過「一些燈光回饋」。即使模型承擔所有程式與資產，也不是使用者只輸入一次後不再介入。作者亦稱目前難度仍主要對 bot 調整，下一步才要做真人遊玩測試；不得將規格或模型自測等同真人平衡已驗收。

## 判斷與重查條件

**保留為 playable 3D 棋類 roguelite 參照；嚴格 one-shot 評測排除。**它證明「無人工程式碼」與「無中途人工指示」是兩個不同條件。若作者公開最初停止時的凍結 build、去除中途燈光回饋的同題 run，或其他模型按同一素材獨立 one-task 重做，再補入新的 run 紀錄，不修改本次介入事實。
