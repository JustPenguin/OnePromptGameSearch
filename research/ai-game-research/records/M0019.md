# M0019 · RSIGame

**類型：**方法／鄰接研究　**狀態：**方法參考　**最後整理：**2026-10-06

**別名：**RSIGame recursive self-improvement game development

## 現行判斷

2026-09-30 公開的研究／框架，不是獨立遊戲候選，但高度貼合使用者允許 AI 在同一委託內自行測試修正的方式。RSIGame 將可執行遊戲交給 agent 真正探索，依日誌、指標與截圖診斷問題，讓修補 agent 針對一個可驗證目標修改，最後由 verifier 重播；外層監看整體分數，保留歷史最佳 build 並在連續無進展時停止，減少越改越壞。這比只要求「自行測試」更能落成可檢查的 QA 流程。

論文報告在 140 個 GameCraft-Bench 任務、兩個 engine、五種 generator 上測試；它也包含針對 30–64 輪迭代的例子。但用到研究框架、GameCraft-Bench 重播器與多代理，不能將其分數解讀為一般模型「一次 prompt 生成」的成績。可借用其評測設計，不把框架內的模型能力和裸模型生成混為一談。

**對本研究的可用方法：**(1) 同一模型 run 中保持一個使用者委託，不追加人類修正；(2) 允許自動 playtest／修正；(3) 每次變更要由獨立回放確認且保留最佳 checkpoint；(4) 設明確預算／停止條件；(5) 最後凍結成品後才由使用者驗收。這不是把模型比賽改成 64 輪上限，而是借用防退步與可追溯原則。

[論文](https://arxiv.org/abs/2609.39045) · [開源框架與可重建設定](https://github.com/WenyiWU0111/RSIGame)。GitHub 說明 base games、run trees、recordings 和 scores 並非都隨程式碼公開；表格所用判分附件另存 Hugging Face，故逐列重現仍須查其完整實驗資料。
