# G0235 · PixelArtGameOpus (Ravenshore project)

**類型：**遊戲／具體題目　**狀態：**排除嚴格一次委託成品；保留視覺／長程工程參照　**最後整理：**2026-10-06

**別名：**The Hourglass City、The Black Sedan、Ravenshore Garden、Odiriuss Pixel Art Game Opus

## 發現與來源

開源 repo 公開三個 Opus 5.5／Claude Code 製作的可玩瀏覽器輸出，並提供 prompt、source、建置方式和 Puppeteer headless tests。`The Hourglass City` 是 1950 年代偵探冒險，含多個場景、線索 notebook 與 deduction；`The Black Sedan` test level 有步行、開車、射擊、不同車輛處理、追逐、敵人找掩體／包抄；`Ravenshore Garden` 是一段夕陽花園裡女子澆花、機器人伴侶和飛車抵達的循環場景。桌面鍵盤滑鼠遊玩。

- [GitHub：實際畫面、source、測試及多個 build](https://github.com/Odiriuss/PixelArtGameOpus)
- [作者公開的三個瀏覽器 build](https://odiriuss.github.io/PixelArtGameOpus/)
- 搜尋批次：[S21](../search/S-20261006-21-artifact-provenance-and-false-positives.md)

## 證據與限制

GitHub README 明確指出只有 `Ravenshore Garden` 始於一則 prompt；作者把它描述成傍晚花園循環場景，而非帶玩法規則／目標／輸贏的完整遊戲。偵探冒險和賽車槍戰 test level 是其後的短追問／follow-up requests，不能把 repo 現存所有玩法和 tests 誤稱成 one-shot 產物。成品的絢麗 pixel-art rendering 與具體玩法適合研究視覺生成和多輪自動化工程；沒有獨立提交時仍不符合「一次交件」。

## 判斷與重查條件

**排除嚴格一次交付候選。**它提供非常有用的對照：真正一 prompt 結果只是循環場景，深度遊戲內容來自後續委託；不應只看 repo 最終版就倒推一次生成。若作者公開一個獨立任務、未經後續提示的凍結 build，重新評估該 run，而非把整個 repo 作為單次成績。
