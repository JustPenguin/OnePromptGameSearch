# G0177 · Yuzzy Itaba PUBG-style browser game

**類型：**遊戲／具體題目　**狀態：**高複雜題型線索（成品連結／原始 prompt 未核實；工具鏈不對稱）　**最後整理：**2026-10-06

## 本輪查證

[作者 LinkedIn 比較貼文](https://www.linkedin.com/posts/yuzzy_opus-55-vs-gpt-6-astra-both-built-a-activity-7508532020268998657-q7Fg) 稱 GPT-6 Astra 與 Claude Opus 5.5 都收到一次相同請求，要製作可玩的 PUBG 風格瀏覽器大逃殺，盡量追求寫實效果。作者宣稱 Astra 不到三小時完成一場 match 和 20 項通過測試；Opus 約十小時，做了 2km 島、八座可進入建築的城鎮、24 個會搜刮／躲掩體／交戰的 bots、30 種動作捕捉動畫及錄製槍聲。這些是貼文作者陳述，尚無第三方驗證。

此題規模／系統密度很高，足以測槍械、AI、生存縮圈、場景與完整對戰。不過本輪不能從可讀貼文取得逐字 prompt、兩份 playable build 的可靠直鏈或 run transcript；貼文媒體未能確認為可互動遊戲。工具明顯不對稱：作者稱 Opus 使用 Scenario MCP、Gemini 3.1 Lite 圖像及 Tripo 3.1 模型產生資產，Astra 使用免費素材。因此它可作**高難度題型與 agent 工具鏈能力線索**，不能作純模型公平比較或已核實一次交付的成果。暫不升格成主要作品候選。
