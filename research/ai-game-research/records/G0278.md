# G0278 · MUTE (Claude Opus 5.5 WebXR co-op horror)

**類型：**遊戲／高系統重跑與 3D 美術流程參照　**狀態：**GitHub Pages 已部署 app；Claude Opus 5.5 有 commit attribution，完整任務／session 未核，不能列為一次輸入成果。**美術待使用者評價。**　**最後整理：**2026-10-07

## 遊戲與原始任務

README 和 `docs/DESIGN.md` 描述 1–4 人合作 VR 恐怖遊戲：玩家在幾乎全黑的廢屋找保險絲、通電後逃離；怪物失明但會聽到腳步、相機閃光和真實麥克風聲音。玩家用閃光相機照亮房間並短暫留下手勢殘像，還要控制閃光次數、噪音與怪物追蹤。支援 Meta Quest WebXR、桌機、單人與 WebRTC 多人。

可核的**原始生成任務文字未公開**；設計文件是專案規格，不得冒充原始 prompt。初始 scaffold commit `cbd6dd0b...` 將工作歸因 Claude Opus 5.5，commit trailer 帶 Claude session URL `https://claude.ai/code/session_01GZkZ8nwdi2mFnDi8yz1YtS`。該 session 網頁回傳通用 app shell；相關 snapshot API 回報 snapshot UUID 格式錯誤，metadata 路徑 404。故無法確認 transcript、首個 user prompt、回合數或人類介入。

## 美術、成品與評估面向

**美術待使用者評價。**公開 art pipeline 說明使用 Blender 5.0.1 Python API 以程式生成全部模型，匯出 GLB 與預覽；方向為低飽和、磨損、略寫實 stylized abandoned-house，含近黑光線可辨識輪廓、相機閃光、PBR 表面、怪物、角色、家具與場景道具。這是可檢閱的建模流程與局部 asset previews，不等於使用者已認可成品美術，也不應稱作 3A 遊戲美術。可看[線上遊戲頁](https://dippy34.github.io/Ai-vr-game/)、[美術圖庫](https://github.com/dippy34/Ai-vr-game/blob/claude/vigilant-gates-rfgepm/art/GALLERY.md)、[預覽目錄](https://github.com/dippy34/Ai-vr-game/tree/claude/vigilant-gates-rfgepm/art/previews)。
