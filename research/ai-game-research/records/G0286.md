# G0286 · Neural Sight (GPT-6 Astra captured-world FPS)

**類型：**遊戲／近期視覺與 playable FPS 參照　**狀態：**約 24 小時 GPT-6 Astra 協作建置的公開瀏覽器作品；沒有原始任務／session 或無人介入證據，不是已核 one-shot。**美術不合格（使用者判定）。**　**最後整理：**2026-10-07

**使用者美術驗收（2026-10-07；[E0008](E0008.md)）：不合格。策展人工 9.7/10 是外部 visual score，不取代使用者判定。**


## 任務、作者陳述與可查成品

作者 README 稱這是約 24 小時以 GPT-6 Astra 建立的「photographic FPS playground」。公開 [source](https://github.com/monstercameron/Neural-Sight)、[GitHub Pages playable build](https://monstercameron.github.io/Neural-Sight/) 及[實驗說明頁](https://monstercameron.github.io/Neural-Sight/experiment.html)。README 表示 GPT-6 Astra 協助玩法、shader、資產處理、音效及瀏覽器測試；repo 最新 commit 為 2026-09-08，作者說明為後續將自訂 SuperSplat URL import 限為 local-only。該網站首次載入約 59 MiB，需桌面瀏覽器 WebGPU。

可玩的內容包括四個 captured scene、第一人稱移動與瞄準／射擊、後座、換彈、蹲跳、球體互動及實驗性殭屍遭遇。README 提供 WASD、滑鼠、R、Space 等操作。研究者直接檢視了 [Nelson Ghost Town 實機截圖](https://github.com/monstercameron/Neural-Sight/blob/main/docs/images/nelson-ghost-town.jpg)：可見近景老卡車、木製水塔、第一人稱武器、清晰日照與沙漠環境。這是作者標為遊戲內 capture、隱藏 HUD 的畫面，不是 concept art。這種寫實視覺主要由 Gaussian-splat captures 保留真實場景光照與表面細節；README 將 Nelson Ghost Town scene 歸於 tosolini 並標示 CC BY 4.0，其他場景也列出外部作者。手與武器則用預先生成的 AI footage 抽影格後合成至畫面。**不能把場景資產整體歸為 GPT-6 Astra 原創美術。**

作品集 [AgentsLoop Neural Sight 條目](https://github.com/AgentsLoop/awesome-gpt-astra-games/blob/main/games/neural-sight/readme.md) 標註 GPT-6 Astra direct model evidence，並給遊戲 9.2/10、最佳截圖 9.7/10；該分數是策展者的來源／系統評估與人工 screenshot visual review，不是本研究的 playtest、AAA 判定或使用者評價。策展頁記錄的 HTTP launcher verification 也不是本研究自行操作遊戲所得。
