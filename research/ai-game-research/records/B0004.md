## 2026-10-07 即時查核

官方 [AutoUE repository](https://github.com/Pluto156/AutoUE)將 AutoUE 描述為生成 20 款 Unreal Engine 5 遊戲 demo 的多代理系統，依賴多種模型服務、資產檢索和專用協作流程。作者連到的 [PlayGen-20 Hugging Face dataset](https://huggingface.co/datasets/Pluto156/AutoUE_DataSet)頁面目前顯示 imagefolder、614 rows、約 19.2 GB；作者 repo 說明資料集含 demos、assets 及實驗材料，但 dataset 頁面可見 metadata 本身不能證明每款都有可重建完整專案、初始 prompt、首版 frozen build 和 run trace。

因此它是值得查閱的 3D 生成成果與系統設計參考，不是現成的任意單一前沿模型比較榜。要升級為 one-shot 重跑題，需逐款拿到完整 brief、工程檔／build 與明確模型配置，並能隔離更換底模而不改動專用 pipeline。詳見 [S25 搜尋批次](../search/S-20261007-25-public-3d-game-demos-and-one-shot-claims.md)。
