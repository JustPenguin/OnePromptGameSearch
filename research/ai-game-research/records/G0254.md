# G0254 · Muse Spark 1.3 Crossy Road 單次生成配方

**類型：**遊戲／具體題目　**狀態：**官方可重現一次生成案例；中階遊戲範圍，作視覺／流程參照，不是上限主測　**最後整理：**2026-10-07

**別名：**Meta official one-shot game dev cookbook；Crossy Road one-shot

## 實際任務與成品

Meta 的 [Muse Spark 1.3 官方 cookbook](https://dev.meta.ai/docs/cookbook/one-shot-game-dev)展示以 OpenCode、Muse Spark 1.3、最高 reasoning effort（high／xhigh）完成 3D Crossy Road。頁面明說圖片來自一次實際 run，並提供[遊戲畫面](https://dev.meta.ai/docs-assets/one-shot-game-dev/02_gameplay.png)與[開始選角畫面](https://dev.meta.ai/docs-assets/one-shot-game-dev/01_start_screen.png)。最終為單一 index.html，透過 HTTP server 開啟遊玩；角色有六種可選造型與 best-score 保存，路線包含草地、車道、可乘木頭的水域和警示後高速通過的列車。

任務的可驗收核心是格線跳躍與鏡頭、車輛碰撞、水中搭乘／漂移／落水、列車警告與通過、分數遞增、音效、粒子、死亡重開及觸控操作。模型使用 Kenney Cube Pets、Car Kit、Train Kit 的 CC0 資產，因此是有實際角色／載具素材的 build，而非只靠幾何方塊充當全部美術。

## 流程與證據界線

這是模型供應商的一手配方與畫面來源。官方明確稱一個結構化 prompt、一個 generation、沒有 build-and-fix loop，並指出結果具非決定性。開始前則另外準備短版 `AGENTS.md`、OpenCode provider 設定與三包外部素材；因此它符合「只交一次使用者任務、AI 自行產出」的互動形狀，但不等於裸空白環境裡只有一句自然語言且沒有預置規格／素材。官方頁有接受標準與完整 prompt，支援重跑。

Meta 於 2026-09-02 發布 Muse Spark 1.3。這份 cookbook 未公開輸出 HTML、逐 token session 或獨立執行紀錄；FPS、資產完整載入及一次生成都是官方作者報告，結果仍應以指定模型版本重跑驗證。這個任務可看畫面與體驗短閉環，但玩法類型和進度深度不夠，不能單獨代表遊戲開發上限。使用者尚未評價此作品的美術；圖片只作實物供檢視，不先判定合格。

## 判斷

保留作高品質視覺與一次生成方法參照，並可作較容易的校準題；主測請優先考慮 [DUNGEONFALL](G0255.md)、開放世界生存題 [G0257](G0257.md) 或既有高系統長流程題。重跑時記錄所有預置檔案與資產、模型 ID、reasoning effort、使用者 prompt 次數、AI 自主測試修正過程及最後凍結版。
