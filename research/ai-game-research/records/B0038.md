# B0038 · SWE-Game

## 歷史盤點摘要

41 款可執行 Godot 遊戲、247 任務；包括 brief-to-game，提供可執行行為檢查與視覺評分。另記最新 GameDevBench 公開榜供校準。

## 2026-10-06 即時重查：新論文與榜單更新

**SWE-Game** 論文日期為 2026-09-27。摘要列出 41 款參考 Godot 遊戲、13 類玩法、247 任務，涵蓋 brief-to-game、GDD-to-game、骨架補完、83 個注入故障修復案例、Godot-to-Unity 移植。評測結合引擎狀態檢查、認證輸入路徑重播、模型自錄功能展示，以及另行的視覺 rubric。六款模型中 Opus5 總分最高；三種建置任務最高分均低於 60/100，brief-to-game 最高 50.38。研究指出，人工標註的 100 款代理生成遊戲上，執行檢查的 balanced accuracy 為 92.59%，高於影片 VLM judge 的 78.41%；視覺 rubric 對 200 段 clip 的人評 Spearman 相關為 0.829。來源：[論文摘要及全文入口](https://arxiv.org/abs/2609.33678)。

這對本研究最可用的是評分設計：用可重播輸入／狀態斷言驗「玩法確實運作」，再獨立評畫面；單看截圖、compile 成功或作者宣稱通關都不夠。該基準是研究者定義的重建／修復任務，不是使用者自由描述後交付任意完整遊戲的 showcase，不能直接拿論文排名代表模型的一次委託上限。

**GameDevBench 榜單即時更新**：官方專案頁（2026-10-01 更新）現列 333 個 Godot 任務，最佳多模態回饋配置、各模型各自最佳 harness 的 pass@1；GPT-6.1 Sol xhigh 為 69.97% ±4.9，GPT-6 Astra high 為 68.8% ±5.0，Claude Fable 5 xhigh 為 67.3% ±5.0。頁面明言 Astra 一項 run 為 229/333，使用 runtime-video 與 strict confinement。這是工具／harness／視覺回饋組合成績，不是裸模型排行，也不是一個複雜遊戲單 prompt 成品分數；它主要提醒正式比試要固定 harness、代理權限、視覺回饋和時間預算。來源：[GameDevBench 官方榜單與協定摘要](https://waynechi.com/gamedevbench/)。

## 2026-10-07 即時重查：brief-to-game 與 3D 任務可用性

[SWE-Game 論文](https://arxiv.org/abs/2609.33678)於 2026-09-27 發布。它有 41 個 Brief-to-Game、41 個 GDD-to-Game、41 個 Skeleton Completion、83 個 Bug Repair 與 41 個 Godot-to-Unity 任務，總計 247；參考集含 24 款 2D、17 款 3D Godot 遊戲。Brief-to-Game 是本研究中特別重要的一支：agent 收到簡短需求、素材和可用的參考影片（若有），自行寫 GDD，交付完整 Godot 專案及功能展示；公開的 interface contract 供評測用，不是使用者中途補充指示。它比純修 bug 更貼近一次委託，但仍有 benchmark 提供的素材／參考影片與明確評測介面，不能完全等同空白環境的任意開放委託。

論文中三種建置任務最佳結果均未達 60/100；Brief-to-Game 表中 Opus 5 為 50.38、GPT-5.6 Luna 為 34.18、Grok 4.6 為 39.01。每款模型使用不同 agent framework／工具組合，故結果混合了模型與執行系統能力，不能視為純模型排名。Beacon Relay 例題有三關、11 個 energy cells、三種敵人角色、七類裝置與約 6–9 分鐘完整流程；DOGWALK、Terraforge 等則顯示其參考集包含較重的 3D 系統。上述是論文中的任務及複雜度證據，並非本紀錄確認已取得那些任務完整素材包或個別 AI 輸出 build。

以 `SWE-Game github 2609.33678 benchmark`、`SWE-Game 247 tasks official project data download Godot`、`SWE-Game benchmark 41 executable reference Godot games dataset repo`、`site:huggingface.co SWE-Game 247 game benchmark` 查找，並查閱摘要、全文及附錄；本輪未找到官方 task/data repository 或可直接重跑的完整 task package。這代表「當前搜尋未找到」，不代表確定不存在。資料包、reference assets/video 或逐題 build 之後公開時，應優先核對 Beacon Relay 等 3D brief 是否能重建成同條件的一次委託。詳見 [S25 搜尋批次](../search/S-20261007-25-public-3d-game-demos-and-one-shot-claims.md)。
