# E0004 · One Shot Challenge

**類型：**活動　**狀態：**嚴格首輪輸出方法參考（不含 agent 自主迭代）　**最後整理：**2026-10-06

**別名：**1shotchallenge、Round01

## 本輪再次核對：適合嚴格對照組，不等同使用者測法

[Round 01 得獎作品／畫廊](https://1shotchallenge.ai/winners) · [活動基準說明](https://1shotchallenge.ai/benchmark)

Round 01 在 **2026-07-13 至 2026-07-18** 舉行；公開資料報告 200 次模型呼叫、25 個模型，141 件參賽作品，參賽輸出以雜湊封存並提供可玩的作品與 prompt。規則是一次 prompt／一次 API call，不准重試、編輯或交互式工作；得獎作品經盲評 jury 選出，另有社群票選。這比作者自述「one-shot」有更完整的首輪證據鏈。

限制也很明確：禁止 agent 在單一任務內反覆執行、遊玩和修正，測的是一次呼叫的 first-pass，而不是你定義的「只有使用者一次委託、AI 可在內部自行修正」。個別項目也屬自由提交，非所有模型同一固定高複雜度遊戲 prompt。可作嚴格 baseline／競賽留證方法，不應優先當主測作品或要求候選必須有既存模型比較。
