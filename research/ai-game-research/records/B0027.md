## 最新查核（2026-10-06）

目前公開 README 指出 live one-shot challenge 仍是 v17；v21 列在 planned，而不是已完成的新評測。基準設計和使用者的委託定義高度相合：同一份一次性 brief、開放玩法與視覺方向、長工作階段中自測／迭代、封存交付物，再由盲評人類評審檢視原創、可玩、完成度、視覺企圖和玩家感受，另以自動檢查確認可啟動與輸入有效。

限制是 GitHub 上的 round logs 顯示很多迭代仍屬作者操作者的非正式場測；新版是否實際執行要以 battle log 而非 planned prompt 判斷。也不能把它的結果當成最新模型的正式排行榜。可借它「功能 smoke test + 盲評成品」的分軌方法。來源與版本核對詳見[S19](../search/S-20261006-19-current-runs-and-benchmark-methods.md)。
