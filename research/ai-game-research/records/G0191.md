## 現行判斷

## 原始任務與成品證據

作者將它列在 Fable Arcade「one-shot」作品庫；該單作 README 明列 Claude Fable 5.1、2026-09-03 生成、`claude -p` non-interactive single turn/no follow-up、54 turns／約 72 分鐘，並註記檔案未修改、附 SHA-256。這支持「一次使用者輸入，AI 可長時間操作工具」的協定；作者沒有提供獨立稽核，因此來源仍屬作者公開的 run 紀錄。

原 prompt 要求 voxel 城市中的單一暗殺任務：可漫遊街區、不同店面與地標、遵守車道的交通、受槍聲驚嚇的行人；步行時可用三種槍與換彈、劫車與駕駛、手煞車與碰撞；犯案累積通緝星、警察追捕、受傷／死亡／醫院重生；另有任務 briefing、路線小地圖、護衛、現金獎勵和完整 HUD。限制是所有內容程序生成，單一 HTML、只可外載 Three.js，並要求數百建物、數十車與行人保持 30+ fps。

## 限制與後續判斷

- **美術待使用者檢閱：**原 prompt 指定 blocky voxel 風格；這是可辨識的完整視覺方向，但是否達到使用者想測的高美術上限必須看真實 build，不以玩法或作者標籤代替判斷。
- README 證明單次 prompt 與未修改輸出，但沒有清楚記載自主遊玩測試／修 bug 的具體證據；不要把「54 turns」直接當作已證明完整 QA。
- 場景是單一任務與程序城市，不是多章節劇情長流程；若評測要比 Ruinseed 一類長流程，兩者測量面向不同。
- 對當前模型重跑時可保留原 prompt 作为固定 brief，讓模型自行跑測試與修正；凍結最終 build 後統一驗收。
