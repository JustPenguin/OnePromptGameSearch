# G0238 · DRIFTWING V1

**類型：**遊戲／具體題目　**狀態：**高價值 3D 飛行技術副題；原 run 有兩次人工 continue，不符合嚴格零介入　**最後整理：**2026-10-07

**別名：**DRIFTWING、Claude Opus 5.5 infinite flight game、KyleBuildsAI driftwing

## 發現與任務

KyleBuildsAI 將 V1 標為大型開放式單 prompt 試作：Claude Opus 5.5 在 Claude Code 裡交出單檔 `index.html`，由模型自行規劃架構、查 Three.js WebGPU/TSL API、使用平行 subagent、檢閱和修正，並在 headless Chrome 驗證 WebGPU 與 WebGL2。作者說無人撰寫或編輯 V1 程式碼；但用量上限兩度中斷後，作者各輸入一次「continue」。因此它有一則初始任務、AI 自主工程與測試，但不符合本研究「此後不再由使用者介入」的嚴格門檻。

原始 prompt 與 V1 frozen file 見[原始 repo](https://github.com/KyleBuildsAI/driftwing)及[release v1.0.0](https://github.com/KyleBuildsAI/driftwing/releases/tag/v1.0.0)。任務要求：單一自包含 HTML、Three.js WebGPU 並 WebGL fallback；低多邊形滑翔翼在無限種子程序世界飛行；含可控飛行模型、軟失速、觸控操作、分塊高度地形、五種 biome、Web Worker、LOD 裂縫處理、地標探索日誌、日夜／極光／雲／水面／鳥群、合成音訊、AI 副駕 WREN、路線與 ring course、60fps 目標及零 placeholder。完整逐項 prompt 保留在 repo「original v1 prompt」章節，不在此重複全文。

- **模型與工具：**Claude Opus 5.5／Claude Code；使用多個 subagent。確切 effort、run 日期及原 session trace 未公開。
- **run／版本：**`v1.0.0` 在 2026-09-26 發布；這是版本發布日，原生成日未知。V1 frozen byte-for-byte，須用 [`?v=1` 進入 V1](https://kylebuildsai.github.io/driftwing/?v=1)；一般首頁預設可能開 V2，不可混看。
- **成品與 QA：**V1 可在瀏覽器玩，另有原始碼和可執行 smoke／flight harness；作者報告在兩種 renderer 驗證。這證明可檢查的驗收工具存在，不等於本研究已獨立重跑其測試。
- **可玩性／系統：**實際飛行、探索、地標、copilot 指令與 ring course 可操作；但無失敗狀態、燃料、敵人或長流程勝負閉環。工程與視覺負荷高，完整遊戲系統範圍仍低於撤離 FPS／長流程 RPG。
- **美術：**尚未取得使用者判定；不把作者的 low-poly 風格描述當作通過。

## 判斷與重查條件

適合作 3D 程序地形、飛行操控、WebGPU fallback、效能與自主 QA 的技術副題；若重跑，要沿用公開 prompt，但明確記錄用量中斷時由平台自動續跑或人工送出指令，避免把「兩次 continue」算成零介入原 run。它不列完整遊戲上限主測，原因是核心玩法為無失敗狀態的無盡飛行，且已確認原作者兩度人工續跑。若作者公開自動續跑原始 trace 或證明平台在中斷後自行恢復，才重評介入分類。
