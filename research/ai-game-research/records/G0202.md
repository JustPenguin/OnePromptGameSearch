# G0202 · Fusedown: 50-Player Browser Battle Royale

## 發現與來源

2026-10-06 由 Reddit 貼文及作者自述找到。作者稱 Claude Fable 5.1 依長 prompt 做成 50 人瀏覽器大逃殺：真人不足時以 bot 補位、玩家搜集炸彈箱取得強化、競逐縮小迷宮／安全區，四分鐘一局，支援鍵盤與觸控；亦稱自行處理伺服器、商店、美術、教學及法律頁面。原始任務全文、repo、模型操作紀錄未找到。

[作者貼文與留言](https://www.reddit.com/r/ClaudeAI/comments/1w9t33d/asked_claude_fable_51_to_build_a_whole/) · [作者所稱可玩版](https://fusedown.io/)。搜尋到一張貼文封面預覽，但不是可驗證的實際遊玩錄影；貼文作者稱曾上線。

## 證據與限制

貼文中作者自己回報首版後還有玩家回饋與多輪修改：bot「像羊群」、部分敵人感覺無敵、商店旗標不明顯，作者稱在 rounds 中修正。因此公開 run 不符合「一次輸入後不再由使用者介入」的嚴格條件。使用者訊息完整紀錄、首版凍結 build、最終 playable 檔及程式碼均未取得。2026-10-06 直接開啟 fusedown.io 曾回 521 Web Server Down；暫時無法檢查當前可玩性，這不證明永久下線。

## 判斷與重查條件

**判斷：**不計為已驗證 one-shot 成績，但可將其「50 人 bot 補位、物資／強化、縮圈、四分鐘回合」改寫成固定測題。這題同時壓即時戰鬥、AI 行為、網路／多人狀態、回合閉環與觸控適配，系統題型有價值；美術品質尚無可直接檢視證據，不因作者列功能或封面圖而判定通過。

**重查條件：**原始 prompt／repo／全程 message trace 公開，或站點恢復後取得可玩的成品錄影；若重做同題，需凍結一則委託及最後 build，明確規定同樣是 bot 模擬還是真多人伺服器。
