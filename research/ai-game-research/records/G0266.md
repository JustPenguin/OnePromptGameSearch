# G0266 · Itsy Bitsy Spider V3 — GPT-6 Astra run

## 凍結任務、模型與成品

[Game Bench 凍結 prompt（V3）](https://game-bench.piccini.app/frozen-prompt.md)要求在全新工作階段、無前文的情況下，交付《Itsy Bitsy Spider》靜態 browser game。核心循環是蜘蛛沿無盡牆面爬升、移動耗耐力、吃飛蟲補充、在暴雨警告後趕到避難洞；雨淋會墜落死亡，分數依高度累積。還要求逐步加難、桌機 WASD 與真手機觸控、可見 HUD、程序生成聲效與靜音、開始／遊玩／game-over／重開狀態，以及由模型親自在瀏覽器從頭玩到 game over、看畫面與音效、檢查效能、修 bug 再交付。模型應按任務作合理假設，不向使用者提問。

任務要求的 subsystem 數量不少，但原 prompt 明言 small game，整體仍是一條無盡生存循環，而非多關卡或長程內容型完整遊戲。故可測自主 QA、mobile input、聲畫回饋與系統整合，不能只因要求很長或作者給高分，就當成完整大型遊戲上限題。

作者現行榜將 run 標為 GPT-6 Astra、high effort、2026-09-24，16m06s、1.84M tokens、$4.95（成本資料說以 33 筆 OpenRouter bill 交叉加總）。[可玩成品](https://game-bench.piccini.app/games/gpt-6-astra-20260924/)的 HTML 與 `game.js`、`style.css`、`audio.js` 靜態 assets 可直接取得，畫面包括開始頁、操作／教學、存活中 HUD、降雨避難、死後統計與重開。頁面未連到原始 source repo／frozen archive，也沒有 build hash、trajectory 或可下載 package；由 hosted JS/CSS 可檢視現行交付，但無法保證它與建置停止當刻逐位元一致。

## 評分與證據強度

Game Bench 公開 25 款 playable builds、四軸 weighted score：Gameplay 45%、Adherence 15%、Engineering 25%、Art 15%。Astra 列為 Gameplay 92.6、Adherence 99.8、Engineering 96.2、Art 98.5，overall 95.5。網站說 9 月其餘八款 run 的分項採作者檢視後接受 Athena 詳細評分；此 Astra 四軸則由 Luiz 本人直接提供，並說記在其 sheet。本次未找到 score sheet 直達連結，故精確分數是作者公布資料，不是本研究重測。

另外作者網站的 [anonymous blind-test flow](https://game-bench.piccini.app/blind-tests/)現提供 25 款 build；表單指示玩家先在不看模型名時遊玩到了解循環、至少死亡／重開一次，再評 Game Design、Fun、Adherence、Onboarding、Cross-Platform、Engineering、QA、Audio、Overall 及再玩意願。這確實把視覺／玩法／工程和作者身分分離設計出來，但沒有找到實際玩家 response、樣本數、平均分或分析報告。因此它是可使用的方法介面，不是已有盲評結果。作者個人 Art 98.5 與使用者尚待評價也分開記。

## 收錄定位與待查

保留此項是因為它提供 2026-09-24 前沿 GPT-6 Astra 成品、完整可復用原題、含強制自主 playtest 的明確規格與可玩結果，足以補足近期真實生成樣本和 player-facing rubric 研究。按使用者要求不以小型／短循環遊戲湊上限候選，這只列作**自主 QA／mobile／audio／單循環完成度副測**與 Game Bench 方法案例，不升級成核心高系統候選。不能以總分替代實玩品質，也不能把作者評分當使用者畫面判定。

重查條件：作者公開 Astra run 的 canary／attempt report、score sheet、完整 source snapshot/hash、agent trace，或匿名盲測的實際彙總；亦可在新模型出現可重現的 frozen-task run 時更新比較。詳見 [S54](../search/S-20261007-54-player-facing-evaluation-coverage.md) 與基準總紀錄 [B0009](B0009.md)。
