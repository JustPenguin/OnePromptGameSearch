# B0031 · PlayGen-20

**類型：**基準／評測　**狀態：**公開 20 題 UE5 生成成果參考；完整一次委託資料及單模型可比條件未確認　**最後整理：**2026-10-07

**別名：**AutoUE dataset

## 歷史盤點摘要

20个UE5題hard可借，LLM judge非新模型裸跑

與 [AutoUE](B0004.md) 是同一系統與相關發佈資料的不同入口。官方公開 20 款 UE5 demo 的主張及一份大型 imagefolder 資料集；本輪未能由公開 dataset metadata 確認完整題目 brief、逐款 source/build、初始輸入和逐 run 模型 trace。固定多代理／資產檢索 pipeline 不等同把單一模型放入相同空白專案的一次委託測試。詳細核查見 [S25 搜尋批次](../search/S-20261007-25-public-3d-game-demos-and-one-shot-claims.md)。
