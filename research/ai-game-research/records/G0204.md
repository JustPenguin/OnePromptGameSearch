## 任務與公開交付

作者公開的單句中文原始要求：「盡可能真實地還原 QQ 飛車中的遊戲地圖。我需要一個真實的 QQ 飛車遊戲，包括遊戲的各種鍵位以及漂移玩法,生成一個3D 页面，尽可能发挥你的所有能力。做完之后上传到 CDN 上把链接发给我」。作者稱 Claude Opus 5.5 在 Claude Code 一次 session 建置並部署；同 repo 公布源碼和可玩的成品。

成品包含四條風格不同的 3D 賽道：夜間城市連續彎、愛琴海海岸坡道、金字塔高速跳台、雪地八字立體交叉；漂移蓄力與回正 mini-boost、連續 boost、氮氣、重置、AI 車手及不同地圖。source 有 15 個 JS 模組，單檔包約 700 KB。作者還稱用俯視 2D 預覽檢查賽道幾何和彎角，再組成 3D 場景；QA 流程包含 headless 操作、320 秒 soak test 和子代理 review。
