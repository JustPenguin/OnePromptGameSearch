# G0195 · FALL LINE

**使用者美術驗收（2026-10-07；[E0008](E0008.md)）：不合格。**此項只記錄美術判斷；玩法、系統、可玩程度及重跑價值另行評估。

## 現行判斷

**這是目前找到最有力的「長時自主建置＋反覆自測修正」遊戲題之一。**Claude Opus 5.5 xhigh 在 Claude Code headless 新工作階段收到一份完整 brief，預算六小時；作者表示沒有人回覆模型問題，也沒有人改動程式碼，模型在 339 分鐘後自行停止，留下 111 次 commit。prompt、工具限制、最終 build 和可玩頁都公開。這很接近使用者定義的一次委託流程，能重跑測現代 agent 的長時間自主完成能力。

## 任務涵蓋的遊戲系統

題目要求完整的自由滑雪／單板山域遊戲，而非只有下坡動畫：一座可連續滑行的大型阿爾卑斯山、九個自由落點、雪板與雙板兩種差異化操作、不同雪面物理、轉彎與抓板／旋轉技巧、跳躍與著地判定、摔倒和重生、軌跡與雪霧；另有競速／技巧／自由滑雪活動、銅銀金目標、成績儲存、多種鏡頭、天候與時間、控制器支援。作者 README 另外列出八個活動、個人紀錄與自動 demo rider。

原始 brief 把可觀察的物理、美術和效能細節拆得很清楚，並要求模型反覆用 Playwright 開遊戲、在固定時點截圖錄影、檢查 console／FPS／物理數值，寫下最弱處、修正再測。它也規定頁面載入後自動示範完整滑行、提供可由瀏覽器自動化呼叫的遊戲 API，讓使用者可以客觀驗收最後產品。它因此很適合測 AI 是否能在長時間無人介入時維持工作記憶、建構完整迴圈、整合複雜控制與運動物理，並實際檢查自身產物。

## 適用邊界

- brief 將 Ubisoft《Steep》作為玩法參照並要求盡量貼近，含非常多指定功能與嚴格驗收清單；這測的是在高度規格化上限任務下的執行力，不是只靠一句模糊創意自己設計整款遊戲。
- 六小時預算、headless Claude Code、xhigh、無網路、固定本機 toolbox 和 AI 自行截圖／修正，是任務結果的重要條件。重跑模型時要把時間、工具、網路、資產／影像生成權限和自動 QA 能力公平對齊。
- 作者聲稱的 339 分鐘、111 commits 及無人工介入，仍是專案作者的公開紀錄，尚無獨立 run 稽核。模型自己的 README 所列九個落點和八個活動也是作者輸出描述，不能僅憑文字視為每項都已實際驗收。
- 可玩頁已確認可載入標題／山域，但這次未完成操控遊玩與獨立視覺品質檢查；尤其美術是否符合使用者標準，尚待使用者查看原始 build。
