# E0007 · profiq Summer Coding Challenge 2026

**類型：**活動　**狀態：**一次委託／自主 QA／同 prompt 重跑的方法參考；迷你遊戲範圍與 60 分鐘限制，不適合完整遊戲上限主測　**最後整理：**2026-10-07

**別名：**profiq coding contest

## 官方規則與評分方法

[官方競賽說明](https://www.pracujprosiliconvalley.cz/summer-coding-challenge-2026/)要求參賽者準備一份最多 10,000 字元的遊戲 prompt；生成開始後不能再有人類追問或手改，coding agent 可在同一 run 裡規劃、測試與修正，最多 60 分鐘。交件需包括 prompt 原文、agent／model／tooling 版本與設定，以及未手改的單檔 `index.html`。網頁須在乾淨瀏覽器直接啟動、沒有其他檔案依賴。這點吻合「使用者只交辦一次、模型可自修」的流程形狀。

主辦方流程不止看參賽者上傳成品：評審會以乾淨瀏覽器檢查功能，並由主辦方把相同 prompt 再跑一次，要求核心功能仍可重現。五個加權面向為主題遵循／可執行 25%、原創性 25%、UX／設計／易用性 20%、prompt 品質 20%、重跑再現性 10%。此法將「作品品質」和「題目／prompt 寫得好不好」混在同一總分中；若用來比較底模能力，應保留前者並另報 prompt 品質與重跑穩定性，不合併成單一模型分數。

## 公開成品與適用範圍

[參賽作品畫廊](https://profiq.github.io/)目前公開多款可玩單檔 HTML，包括 APEX // QUALIFY（圈速、分段差值、ghost lap、路面物理）、BRICKSMITH（3D 參照模型拼裝與自由建造）、TELEMARK（滑雪跳台）、REMNANT（十關死亡殘影解謎平台）、以及 DEAD ZONE（小城區第一人稱搜刮射擊、殭屍／掠奪者）。它展示了單 prompt 可落地為多種遊戲閉環，畫廊可玩版也適合做行為／操作參照。

比賽正式主題為 minigame，60 分鐘 hard cap，單檔交付；不要求長流程角色成長、跨章節內容、大型經濟或完整商業遊戲範圍。因此即使 DEAD ZONE 和 VESPER 比常見小遊戲複雜，也不能只憑畫廊描述判作完整上限測題。畫廊未對每個公開 build 一併列出原 prompt、模型版本／工具設定、完整 trace、正式分數或對應的重跑結果；目前無法重建每一款的模型比較，也不把成品宣傳圖當使用者美術驗收。

**判斷：**保留為嚴格一次委託、允許 agent 自主 QA、同 prompt 重跑及分開評分的**方法參考**；不升為完整遊戲上限主候選。若把其賽制改為多小時預算並改成多章節／長流程任務，便已是新的 benchmark 設計，而非這場活動原成績。此次規則／畫廊現況重查見 [S43](../search/S-20261007-43-public-one-prompt-game-challenge-rules.md)。
