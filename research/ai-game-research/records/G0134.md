# G0134 · Ruinseed

**類型：**遊戲／具體題目　**狀態：**推薦　**最後整理：**2026-10-06

**別名：**8-Bit AI Arena、Ruinseed: The Shattered World

## 歷史盤點摘要

518行冒險規格、程序世界與地城Boss閉環；最新澄清後主測優先

主要候選比较基準，详料前段

## 目前候選資料

- **玩法與難點：**程序生成連通世界、森林／濕地／峽谷等區域、三座地城、戰鬥、符印、最終 Boss 與結局；要求多 seed 可達性及約 10–15 分鐘通關閉環。
- **為何優先：**同時測世界生成、關卡可達、敵人、戰鬥、進度與長流程完成，不會只靠漂亮標題畫面過關。
- **證據／限制：**518 行 prompt；有多個模型可玩 build。Astra 曾有一次 continue，重跑應統一工具與時間條件。
- **來源：**[任務 prompt](https://github.com/FrostSource/8bit-ai-arena/blob/master/PROMPT.md) · [成品集合](https://frostsource.github.io/8bit-ai-arena/) · [Opus build](https://frostsource.github.io/8bit-ai-arena/play.html?game=opus)

## 2026-10-06：同題四模型的新執行資料

作者 README 記錄 **2026-09-24** 在空白資料夾把同一份 518 行 prompt 給四個模型，並提供 source 與四個 browser builds。名單／作者自述時間：Claude Opus 5.5（1 小時 50 分、約 60% 五小時額度）、GPT-6 Astra（42 分鐘後用盡額度，另收到一則 `continue`，再 1 分鐘／6%）、GPT-6 Sol（35 分鐘／約 20%）、GPT-6 Luna（41 分鐘／約 10%）。GPT build 使用 Extra High，Claude 使用 Max。Prompt 由作者事前以 GPT-5.6 Luna 經幾輪整理，這是共同測試規格的準備，不代表四個被測 run 間有提示往返。

**協定符合度：**Opus、Sol、Luna 作者稱只用共同 prompt；Astra 明確有一次額外 `continue`，所以 Astra build 不符合嚴格「使用者中途不再輸入」條件。所有流程資料是作者 README／Reddit 自述，沒有可逐輪稽核的 transcript 或凍結 hash；仍以公開 playable build 和 prompt 本身作為可複驗的輸出對照。

[四款 playable 與來源集合](https://frostsource.github.io/8bit-ai-arena/) · [repo README 的模型／時間／continue 紀錄](https://github.com/FrostSource/8bit-ai-arena) · [共同完整 prompt](https://github.com/FrostSource/8bit-ai-arena/blob/master/PROMPT.md) · [作者發帖與成品描述](https://www.reddit.com/r/aigamedev/comments/1wpokkj/testing_a_game_prompt_with_opus_55_and/)。用戶已於 2026-10-06 判定此日期檢閱頁上 Ruinseed 候選美術不合格；不影響其玩法／長流程重跑題價值。
