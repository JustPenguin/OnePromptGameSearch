## 2026-10-07：官方 repo run 時間線核對

SummerEngine 的公開 repo 標示作者使用 **Claude Opus 5.5**，約五小時以一個 prompt 生成首版，包含 cel-shaded low-poly 風格、兩張拉力賽地圖、自訂車輛物理與合成引擎音訊，另有可在 Summer Engine 或 Godot 4.7 開啟的遊戲專案。repo 也公開 controls、來源碼及第三方模型資產。

但相同 README 清楚記錄：其後作者依自己的 playtest notes 開第二輪，加入 campaign、兩張地圖間可駕駛道路、第二部車、車庫並重做物理；下一輪又改碰撞寬容度、道路場景及飛越鏡頭；第三輪再將兩賽段接成無載入的一個世界並加入其他系統。當前遊戲是多輪人類回饋後版本，不能作使用者只輸入一次後的成果。原始起始 prompt 逐字內容、首輪凍結 build 和完整 session trace 未見於 repo。

- **成品／範圍：**兩季節相連賽段、車輛物理、手排檔位、自由駕駛／AI ghost／賽事錄影與合成聲音；repo 說明有多輪人工 playtest。
- **藝術判定：**尚無使用者評價，不從 cel-shaded 風格或宣傳畫面推定合格。
- **建議定位：**排除嚴格一次委託成績；可作賽車視覺方向與物理整合參照。若要重跑，從公開 build 提煉任務並明訂一次任務、不收人類 playtest feedback，不能直接拿更新後 project 當作 one-shot。

來源：[官方 repo 與逐輪變更說明](https://github.com/SummerEngine/sakura-rally)。詳見 [S27 搜尋批次](../search/S-20261007-27-repo-history-and-curated-gallery-provenance.md)。
