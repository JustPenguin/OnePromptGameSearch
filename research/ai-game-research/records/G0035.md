## 2026-10-06 流程補證

作者後續方法文章明確補述：Claude Code 收到一個 prompt 後放手工作多小時，呼叫大量子代理，寫約 55,000 行程式，並以程式生成材質、模型、動畫與音效；公開原始 prompt 與 source。作者也明說成品沒有超越 Call of Duty，且描述的 Gauntlet Loop 以參考圖反覆比較／修正為核心。這補強「一次 user kickoff、agent 長程工作」的作者自述，但不是完整獨立 session log；若你的 benchmark 接受 agent 自行修正可用作系統深度參照，不能把 AAA 目標字眼當成實際美術已達 AAA。見[方法文章](https://somethingbig.ai/gauntlet-loop)。
