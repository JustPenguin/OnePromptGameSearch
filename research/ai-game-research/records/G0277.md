# G0277 · Torchboy (Claude Code 27-prompt game)

**美術：待使用者評價。**repo 中的 gameplay GIF 展示暗色等角洞穴、火把照明、低多邊形小男孩與程序生成洞穴；作者說參考 Kenney 風格但沒有實際採用 Kenney 資產。這是 stylized 3D，不是寫實 3A；使用者可以直接看以下 [實玩截圖／GIF](https://github.com/apshoemaker/torchboy/blob/main/docs/media/discovery.gif)、[關卡出口](https://github.com/apshoemaker/torchboy/blob/main/docs/media/gate.gif)、[結局](https://github.com/apshoemaker/torchboy/blob/main/docs/media/ending.gif) 再給評價。

## 原始任務與遊戲系統

首個 prompt 原文見[逐字稿第 1 章](https://github.com/apshoemaker/torchboy/blob/main/docs/transcript/01-i-want-you-to-help-me.md)：

> I want you to help me create a game that is isometric in nature in a cavern that is dimly lit and has secret passage ways that are only revealed when you are close enough. The character that you are playing as is a small boy with a giant head whose only light source is a torch that must be refueled regularly. I want you to create the isometric and character artifacts in blender, but the game needs to be usable from a browser using three.js. I like this vibe here https://threejs.org/examples/#webgl_animation_keyframes and like the multi level approach, so let's explore that vibe.

後續 prompt 加入移動／動畫、環境與音樂、近火把揭露暗道、動態故事、多層洞穴與程序生成、收集所有暗道才出現樓梯、結尾及重新開始。repo 說最終為三層 procedural cavern，生成藝術、音樂及依玩家路徑而寫的故事；README 和錄影展示可玩片段與結局。這個完整任務應視為 27 prompt 的共同產物，不可把初始 prompt 單獨當成規格已涵蓋全部系統。

## 執行與實證

- 作者稱 Claude Code 於約 25 小時、分兩天、27 個 human prompts 及 793 次工具呼叫完成；沒有手寫程式碼。逐章逐 prompt transcript 公開，與 AI 建置過程的可回溯性相當高。
- 工具自述統計：Bash 418、Playwright MCP 286、Blender MCP 23、Read 29、ToolSearch 9、WebFetch／WebSearch 5；Playwright 內含 128 次 browser evaluate、81 navigate、53 screenshots、24 unsafe code calls。角色與道具先透過 live Blender session，後移到 headless Python scripts。
- 第 8 prompt 的 `Sonnet 5` 指遊戲內生成故事所用 API 模型；不能據此斷定 Claude Code coding-agent 的基礎模型／版本。repo 沒有 coding-session model ID、agent snapshot、commit 與 prompt 的精確 freeze 關係，遊戲生成日也未精確記錄。
- 作者記錄程序測試：roll 900 個洞穴檢查可完成性、測量腳滑比例、實際 playthrough 驗證結局；README 也列舉角色骨架權重等視覺缺陷是透過量測和真實瀏覽器遊玩查出。這些是作者保存的測試方法與結果，尚未由本研究獨立重跑。
- GitHub repo 提供 source、package scripts、文件與 GIF。研究者檢查 `https://apshoemaker.github.io/torchboy/` 回 404，因此沒有可核的 live hosted game URL；作者說可 `npm install && npm run dev` 本機執行。本批未安裝並遊玩 repo，將可玩性標為作者證據支持／本研究未重跑。
