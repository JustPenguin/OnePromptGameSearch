## 遊戲與可查證成品

[itch 作者頁](https://theblazehen.itch.io/candle-keepers-parchment)提供 HTML5 遊戲入口和操控說明。故事是玩家操縱紙飛機穿越同一城堡的六個年代，從遺跡回到火災前；頁面稱包含花園序章、六個關卡、故事書開場與結尾影片。觸控方式是手機直向點擊／按住畫面兩側轉向與拍翼，桌面可用 A/D 或方向鍵。本研究已核對頁面和作者的內容說明，未實際通關，也未取得 source archive 或 frozen build。

**美術待使用者評價。**作者稱 Claude 經 oh-my-pi 製作 shaders、procedural art、effects、Blender/Godot scripting；遊戲被 itch 標為 Godot、Low-poly。頁面現存[可見封面](https://img.itch.zone/aW1nLzMwNDA3NTE5LnBuZw==/original/p9GIxO.png)呈現夕照、雪地城堡、河面反光和發光紙飛機，但作者明確把它列為 OpenAI image generation 封面。封面不是 runtime 截圖，不可據此判定遊戲內畫面品質。研究者沒有可核的 gameplay screenshot 或錄影可供判美術；須直接進入 HTML5 build 檢視。

## 任務、模型與流程證據

作者將作品標為 Slapjam 2026 submission；活動規則要求 48 小時內製作，提交手機直向 HTML5 遊戲，並允許使用 AI 工具。遊戲頁的 attribution 原文指出：Claude（Anthropic）由 oh-my-pi coding agent 驅動，負責 game code、level/route design、shaders、procedural art/effects、cutscenes、story text 及 Blender/Godot scripting；Suno 用於音樂，OpenAI image generation 用於封面。作者同時說明 Solo Developer 負責 creative direction、final selection/integration of assets、testing、balancing、final assembly/submission。

沒有模型精確版本、初始任務文字、連續對話／工具 trace、首版與最終版差異、提交時 frozen build hash 或獨立評分。Jam 允許自主 agent 建作，但參賽資格和 AI disclosure 都不能證明特定作品由單一使用者任務自主交付。作者列出 six stages 不等於獨立確認完整度或品質。
