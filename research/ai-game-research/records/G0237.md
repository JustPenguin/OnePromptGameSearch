## 發現與可看成品

2026-07-28 的作者 Reddit 貼文稱，以一則起始 brief 啟動 Tesana 新推出的 LOOP 模式，讓系統自行運作約九小時後得到首個 build；作者稱自己沒有上傳參考圖，之後才公開成品連結。任務描述的玩法是類 Cuphead 2D boss-rush shooter，含三位 Boss、三階段戰鬥、跳躍／dash／八向射擊、粉紅彈反與超級攻擊、三種武器及雙人合作；作者估計熟手打完三 Boss 約兩小時。官方頁面把它描述成逐線即時繪製的 1930s 橡皮管動畫風格，實際 build 可在 Tesana 遊玩。

作者在留言公開的起始 prompt 為：

> Build a 2D platformer-inspired boss-rush shooter utilizing state-of-the-art procedural graphics, completely skipping run-and-gun levels to focus exclusively on intense, skill-based boss fights. It should be visually stunning, mechanically razor-sharp, and crafted at AAA quality—featuring 1930s rubber-hose style procedurally generated animations, multi-stage boss phases, frame-perfect hitboxes, fluid parry mechanics, procedural ink-and-paint textures, and authentic vintage jazz audio integration.

這段是可重跑的原始起始文字；三 Boss、雙人合作、約兩小時流程及約九小時生成時間來自作者貼文／留言，不全在這段 prompt 內。官方遊戲頁現有內容可玩，但無法獨立證明它與作者 run 的凍結首版完全相同；原始 run 的完整版本歷史、trace、每次自動 QA 與輸出 hash 未公開。

## 證據與限制

- **使用者輸入／介入：**作者稱一則 base prompt 啟動 LOOP，之後約九小時自行運作，無使用者 follow-up；沒有 session log 可獨立核對。Tesana 官方文件確認 LOOP 可在預設額度下 unattended 運作、拆成區域並由 critic/playtest 反覆修建；但文件也明載使用者可在執行中留 note，故重跑需記錄實際是否用過此功能。
- **模型：**作者留言指出使用專用 game model／engine；同串後續提到 Atomos。Tesana 官方現行文件稱平台為每次執行選模型，並在 2026-07-01 將 Atomos 列為新作品預設。可合理將 Atomos 視為高度可能模型，但未找到該 run 的 usage ledger，因此**此 run 的精確 model/version 未核實**。
- **自主修正：**作者稱 LOOP 讓 AI 以首 prompt 長程建置；官方說明其流程包含多區並行、critic、playtest 和多輪修建。平台方法是工具／模型／遊戲專用編排的組合，不能將成品能力單獨歸因於 Atomos。
- **成品與畫面：**官方 playable page 公開，原 Reddit 貼文含 run 畫面／影片；目前 live page 可能歷經更新，與初次 final build 的版本一致性未證實。使用者尚未評價此作品美術，不將官方美術形容視為美術通過。
- **重跑限制：**Tesana 自選模型且 LOOP 是封閉平台模式，無法在該平台把底層模型鎖定為使用者任選模型。因此原生成績只能作平台特定案例；公開 brief 可轉交不同 agent/model 在同一工具、預算與自主 QA harness 下重跑。此 prompt 是高創作自由／視覺風格／Boss combat 題，不是細規格系統整合題。
