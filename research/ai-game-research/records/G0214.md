# G0214 · SUNBREAK — Downhill Club

**類型：**遊戲／具體題目　**狀態：**備選（視覺／物理副測；一次委託流程待查）　**最後整理：**2026-10-06

**使用者美術驗收（2026-10-07；[E0008](E0008.md)）：不合格。**此項只記錄美術判斷；玩法、系統、可玩程度及重跑價值另行評估。

## 發現與來源

來源 repo 是 GPT-6 Astra 製作的程序 cel-shaded BMX 下坡競賽。完成的一趟 2.3 公里賽道包含四名車手、三名 AI 對手、彎道與跳台、甩尾／預壓跳躍／七種空中技巧、碰撞與跌倒、天候、checkpoint、計分、ghost 與 cinematic replay。場景、車手、車輛、音效及畫面特效以程式生成。repo 公布可執行 source、10 項瀏覽器遊戲／特效檢查；README 稱 production build 和 checks 通過，但同時明示 60 fps 目標未核實。

作者的 X 貼文直接將作品歸給 GPT-6 Astra，模型證據比純策展列表強；但原始 prompt、完整對話、時間／工具條件及 no-follow-up 證據未找到。第三方策展站把一張來源 repo 的遊戲截圖手動評為 8.9/10，僅是該策展者的視覺判斷。repo 本身沒有官方託管版；[tikgame 的可玩複本](https://tikgame.org/game/sunbreak/)是第三方用開源碼建置的非官方副本，不是作者發布的 build。

## 證據與限制

- 原始 source、作者模型歸因、實際遊戲畫面及玩法程式碼可查；一整趟賽事有完整開始、競爭、計分與結束循環。
- 沒有原 prompt 或 agent transcript，所以不能聲稱這是一次 user task、一次 prompt 或零介入成果。來源 repo 亦未封存各開發里程碑的歷史 build。
- 視覺手法及物理系統很深，但題型集中在單一競速模式，不涵蓋長程角色成長、探索／任務或多種玩法。它適合測視覺、物理與 3D 整合，不該取代長流程主測。
- 第三方評分不是使用者評分；遊玩鏡像是非官方版本，請把 repo 與 mirror 的來源分開看。

## 判斷與重查條件

**保留為值得使用者檢視的視覺／物理副測與重跑 brief，不稱已驗證的一次交付實測。**在已查到的新視覺方向中，它有 3D 地形、動態效果、車手動畫、物理、AI 對手和完整終點流程，差異於普通短賽車 demo。是否達到使用者的美術門檻仍未確認。若作者補出 prompt／session 或官方可玩版，再更新嚴格資格與交付證據。
