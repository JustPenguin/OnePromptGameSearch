# G0198 · Browser Flight Simulator with a Complete Flight Loop

**類型：**遊戲／具體題目　**狀態：**待核實；可重用 brief，實際 build 未確認　**最後整理：**2026-10-06

**別名：**Tater's Flight Sim prompt

## 發現與來源

GPT-6 Astra 作者 aditya 於 2026-09-05 發布一份 browser flight sim prompt，要求玩家從機場加速、起飛、繞場、進場、降落、計分再重玩；包含節流、俯仰、滾轉、偏航、煞車、基本飛行物理、儀表回饋、墜毀判斷與重新開始。任務本身要求模型在瀏覽器內試完整個循環，找錯後修復。原帖與逐字 prompt 的保存副本見 [X 原帖](https://x.com/adxtyahq/status/2096236137266512181)及[策展 repo](https://github.com/yangzhou-chaofan/awesome-gpt6-astra-game-prompts)。

## 證據與限制

- **題目價值：**比單純飛機場景高一級，因為要求真實控制量、起飛與著陸兩個相反狀態轉換，並以安全落地和重玩作結。適合測 3D 輸入、物理、鏡頭／儀表與成功／失敗狀態整合。
- **範圍界線：**它仍是一個小型飛行挑戰循環，不含成長、敵人、關卡群或長流程；相較 Diablo ARPG、Ruinseed、Fable Cities，不適合單獨代表整體遊戲上限。
- **成品證據：**原始社群紀錄的 `live_demo` 欄位空白，只有靜態預覽與作者貼文；後續 prompt 索引頁雖出現可玩標示，但未能確認其所指 build 是否為這則 Astra 原帖的 AI 停止時產物，或是後續平台生成／重跑結果。因此不列為已核實一次生成成品。
- **流程證據：**「自動試飛並修復」是 prompt 的明文要求；沒有 run log 證明作者的模型實際完成測試，也沒有無人介入時間線。

## 判斷與重查條件

保留為有自我測試閉環的高品質飛行任務 brief，不納入嚴格成品候選。若找到作者 build、原始工作階段或可核對 live demo 來源，再評估其是否能成為飛行物理副題。
