# M0032 · Genie 3／Project Genie 即時互動世界生成

**類型：**方法／鄰接技術參照　**狀態：**官方高擬真互動世界模型；與 coding agent 從一次任務交付完整遊戲不同，不列遊戲生成候選或美術通過案例　**最後整理：**2026-10-07

## 官方能力與可查描述

[Google DeepMind Genie 3 頁面](https://deepmind.google/models/genie/)將 Genie 3 稱為 world model，宣稱能以 20–24 FPS 即時互動，並以 720p 產生 photorealistic worlds。該頁案例提示描述環境與角色，例如海浪與衝浪者、雪地與登山者、瀑布與飛機、雨林與鸚鵡。這些是世界生成示例，不是含有完整玩法系統的遊戲交件，也不是使用者按本研究標準作出的美術驗收。

[Google 官方 Project Genie 公告](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/project-genie/)日期為 2026-01-29。公告稱美國 Google AI Ultra 訂戶可試用一項實驗性 research prototype：用文字與圖片構想環境、選擇角色並即時探索，之後可 remix 世界並下載探索影片。官方明列若干限制，包括畫面／物理未必貼合 prompt、角色控制不穩，以及生成片段限制為 60 秒；公告另說部分 Genie 3 功能當時尚未進入 prototype。

## 與研究目標的界線

Project Genie 是可玩的互動世界體驗，畫面可作為即時生成環境的技術參照。但公開材料沒有證明它由 coding agent 依一份任務自行寫出規則、目標、關卡／進度、UI、存檔、勝負及完整遊戲循環，也沒有獨立 source/build 可交付驗收。因此即使環境視覺達高擬真，仍不能把環境 fidelity 當作完整遊戲美術、玩法或系統完整度，也不能評為符合一次委託條件。

## 收錄與重查條件

保留為官方世界模型的視覺與互動能力參照；不是遊戲案例，不在使用者美術通過／不通過統計中。若未來 Google 發布可下載、可辨識版本的長篇遊戲任務成果，並交代 prompt、生成規則／系統、操作閉環、凍結 build 與人類介入，再另行查核是否建立新 G 紀錄。
