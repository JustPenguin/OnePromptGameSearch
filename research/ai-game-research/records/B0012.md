# B0012 · GameDevBench

**類型：**基準／評測　**狀態：**最新模型方法參考；任務是既有 Godot 專案開發，非空白完整遊戲生成　**最後整理：**2026-10-07

**別名：**waynchi/gamedevbench

## 歷史盤點摘要

333既有Godot任务，best多模態harness非從零

## 2026-10-07 官方 leaderboard 更新

官方專案頁目前在 333 題榜列 GPT-6.1 Sol xhigh／Codex **69.97% ±4.9**、GPT-6 Astra high／Codex **68.8% ±5.0**，標示 pass@1、95% 信賴區間，採各模型最佳多模態回饋設定及最佳 harness。官方 repo 可下載題目、以 Godot 4.4.1 執行、設 strict confinement，並記錄 agent、model、effort 與是否提供 runtime video。這些新成績可追蹤最新遊戲開發 agent 的局部視覺／玩法程式能力。

- [官方榜單](https://waynechi.com/gamedevbench/)
- [官方任務集與 runner](https://github.com/waynchi/gamedevbench)
- [論文](https://arxiv.org/abs/2602.11103)

**適用邊界：**333 題源自教學，要求在既有 Godot 專案內修改圖形、動畫、UI 或玩法，平均參考解改 4.7 個檔案／114 行。它是可重跑、可自動驗收的 game-development benchmark，不是從空專案以一則任務交付完整遊戲；榜單分數不可直接代表本研究的「完整遊戲一次生成」能力。官方頁顯示排行榜是每模型最佳配置，不等同同工具、同 effort 的嚴格單變項對照。

詳見 [S26 搜尋批次](../search/S-20261007-26-current-game-showcases-and-benchmark-updates.md)。
