## 一次委託證據與限制

- repo README 稱每個遊戲各由一份 copy-ready prompt 建立，並提供七份任務原文及其 source。這比只有宣傳影片更可重建，且涵蓋當前模型的實際成品線索；模型名稱只公開為「GPT-6.1 Sol light」，provider/tool/environment details、reasoning 設定、每題時間、成本、單輪或是否追問均沒有獨立 artifact。
- README 的 prompt-pack 說明稱 `original-prompts.txt` byte-for-byte 保留「original pasted file」，但 repo commit 歷史顯示七款 source 先公開、prompt pack 約四分鐘後才加入。該時間線不推翻作者說法，卻無法單靠 Git 證明任務先於生成、原文未事後整理或 build 只由該 prompt 產生。
- 「讓 assistant 實作，然後按執行指示」是 prompt pack 的建議再用流程；不能當成原 run 的開發過程紀錄。任務要求通常不含明確的自主測試／修正規則，僅部分 source README 描述檢查腳本。
- 美術、玩法可玩性、系統／內容完成度、一次輸入條件及來源證據強度須逐項分開評。本筆尚未直接啟動七款，也沒有使用者美術評價。
