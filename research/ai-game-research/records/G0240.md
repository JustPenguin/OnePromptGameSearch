# G0240 · Long Wind

**類型：**遊戲／具體題目　**狀態：**排除嚴格一次委託；保留高系統武俠成品／視覺參照　**最後整理：**2026-10-07

**別名：**長風、jbang2004 wuxia action game

## 成品與開發時間線

作者公開 Claude Opus 5.5／Claude Code 製作的 three.js 武俠動作遊戲，第一版約 28 小時 wall-clock（約 19 小時模型實際工作）。公開 [GitHub 原始碼與 README](https://github.com/jbang2004/long-wind)、[瀏覽器 build](https://jbang2004.github.io/long-wind/) 和作者 [Bilibili 開源說明影片](https://www.bilibili.com/video/BV1FTaa66EPM/)。Repo 公開 151 個 source files、30 項 headless gameplay tests，並稱一版後持續更新。

作者記錄起始提示是：「用 three.js 參考這個網站的視覺效果，實現一個劍客在草原上戰鬥的遊戲，要求極致的逼真，極致的美學設計。」這只是最初方向，並非目前完整作品的單一任務規格。時間線記錄人類後續試玩並提出意見、提供動作參考影片、登入 Tripo AI／Mixamo 供 agent 使用；模型在多個平行 subagent 間分工，整合後再測試及返工。角色模型有 Tripo AI 生成資產，動作使用 Mixamo 捕捉並由 AI 重定向／修正；後續章節、手機控制及外觀打磨均不是只靠原始一則輸入完成。

首版內容已有三章旅程、草原／雨夜竹林／燈火古鎮，敵人與三個 Boss；戰鬥含輕重連擊、格擋／完美彈反、閃避無敵幀、架勢崩潰、處決、劍氣、鎖定和多種敵人。這是高系統密度且有可玩 build 的長程結果；作者也列出角色材質閃白、打鬥卡頓和槍兵武器插地等由 AI 排查的問題。此處是作者的開發紀錄，未獨立執行 repo 測試。

**美術判定：**使用者尚未評價；本紀錄不依作者的「逼真／美學」目標或作品集截圖推定通過。
