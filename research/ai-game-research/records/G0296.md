# G0296 · MoxRide

**類型：**遊戲／風格化 3D 畫面與任務參照　**狀態：**創作者將開發歸因 GPT-6 Astra，稱曾三次要求提升畫面；有 creator-provided gameplay screenshot 與 browser build。明確多輪人工引導，排除為 one-shot 成績；**美術待使用者評價**　**最後整理：**2026-10-07

## 發現與來源

由 [awesome-gpt-6-astra 提交 #114](https://github.com/MartinDelophy/awesome-gpt-6-astra/issues/114) 發現，curator 記錄作者 Moxazza 將作品提交至 Action & arcade，並提供 [MoxRide 官方頁](https://www.moxride.com/)及一張 706×402 圖。官方頁連到 [itch.io MoxRide project page](https://moxazza.itch.io/moxride)，該頁當前公開 HTML5 game embed、YouTube trailer 和三張 image gallery captures（原始解析度 1002×862、715×412、712×415）。圖中分別可見滑板 rail trick、一般下坡遊戲畫面和 pause/help 面板；這是比 curator 單圖更完整的場景／UI 檢閱材料，仍沒有標明各張截圖的 capture date／build hash。curator 的 [留言](https://github.com/MartinDelophy/awesome-gpt-6-astra/issues/114#issuecomment-5996080543) 確認條目於 2026-10-05 合併，平台欄標 desktop。

## 遊戲與可見畫面

作品是下坡滑板／街機遊戲：作者介紹 rails/grinds、跳躍技巧、連段計分、換裝及排行榜。提交截圖可見第三人稱角色、街道、低多邊形建築、速度與分數 HUD；畫面採柔霧光照和簡化城市幾何，整體呈 stylized 3D 街頭路線。此處只描述圖中可見設計；美術是否達到使用者的門檻由使用者判定。截圖文字和場景細節受 706×402 解析度限制，不能據此確認完整遊戲呈現品質。

## 任務與生成流程

- **模型／工具：**作者投稿標示 GPT-6 Astra；未公開精確模型 snapshot、agent、程式碼來源或 session。作品集資料稱模型歸因依創作者提交，不是獨立 transcript 稽核。
- **原始任務：**未見逐字 prompt。作者說自己要它重製舊 Flash 滑板遊戲 Street Sesh，並指定「像 GTA: Vice City」的視覺方向。
- **使用者介入：**作者明確說他「三次」要求提升 graphics。故即使後續某個 build 可能由一次生成產生，公開敘述已證實整體開發歷程包含反覆指示，不符合本研究零 follow-up 條件。
- **工程與測試：**作者 Moxazza 的 GitHub public repo API 清單為空；官方／itch page 的 HTML5 embed 可公開載入，但沒有可檢視 source repo、run transcript、固定 build hash、獨立 gameplay QA 或原始 task。作品集 basic launch check 不代表本研究已通關。

## 分項判斷

| 面向 | 判斷 |
|---|---|

| 可玩性 | 有公開 browser URL 與一張被標作實機畫面的截圖；本研究未獨立完成賽局／檢查手機支援。 |
| 系統／內容 | 可見速度競賽、滑板技巧／rail、連段計分與多套裝扮等作者描述；完整模式、賽程、狀態保存及排行榜運作未核。 |

## 收錄定位與重查條件

保留作為近期模型在風格化 3D 街道／滑板題型中的畫面與反覆 art-direction 參照，**不列 one-shot 強候選**。若作者釋出最終 build 對應的畫面影片、source 或逐輪 session，可補充視覺變化與工具 provenance；不得把三次後續提示省略成單次生成。
