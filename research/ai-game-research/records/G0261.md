# G0261 · Tycoon Submarine Pressure Rescue

**類型：**一次生成遊戲案例／正式基準 run　**狀態：**GPT-5.5/Codex 官方輸出可玩；系統分數高、官方 art 分數低；美術待使用者評價　**最後整理：**2026-10-07

## 官方任務與輸出

GameCraft-Bench 任務把潛艇的艙室水位、壓力、氧氣、損壞、船員和系統操作綁在同一個救援模擬循環；玩家必須處理多種緊急事件，作出有代價的修復／調度選擇，並完成有升級風險的目標。官方 demo 展示 **GPT-5.5（Codex）**生成的 Godot 成品，附 playable Web build 與遊戲錄影。

| 官方評分項目 | 分數 |
|---|---:|
| 整體 | 68.70 |
| 核心機制 | 90.00 |
| 內容深度 | 85.00 |
| 功能視覺 | 75.00 |
| Art and Presentation | 41.00 |

這組分項呈現明顯落差：該 run 的系統／深度／狀態呈現分數高，但官方藝術與呈現分數偏低。該數字是 GameCraft-Bench rubric 結果，不是使用者判定。**美術尚待使用者直接驗收**；任務系統測試價值與美術合格與否分開記錄。

## 一次輸入與證據界線

基準讓 agent 接受一份任務規格，在固定 workspace 中自主實作並產生完整 Godot 專案及 replay traces，再以生成後的遊戲互動影片評分，符合「一則任務後由 AI 自行做至交件」的測試形狀。原 task 是工作區工程 brief 而非原始聊天逐字紀錄；公開頁提供模型名稱、可玩成品、影片及分項分數，但這個單題頁未標示精確生成時間／完整 session transcript，故不要補推 one-shot 的聊天軌跡細節。

GameCraft-Bench 專注 2D Godot 遊戲，不是 3D 上限題；此案例的可玩實物和分項評分適合作系統耦合與展示品質的校準參照，或讓新模型重跑後看它能否提升藝術表現。長流程任務的 deterministic traces 每段最多 20 秒，需由多個 scenario traces 拼接可觀察證據。
