# G0209 · DASH / DINNER

**類型：**遊戲／具體題目　**狀態：**待核實　**最後整理：**2026-10-06

**使用者美術驗收（2026-10-07；[E0008](E0008.md)）：不合格。**此項只記錄美術判斷；玩法、系統、可玩程度及重跑價值另行評估。

**別名：**尚無

## 發現與來源

2026-10-06 在近期 GPT-6 Astra 遊戲目錄中找到，由 [AgentGames 的作者頁](https://agentgames.dev/play/dash-dinner)提供任務原文和 [browser build](https://play.agentgames.dev/g/g_Gkna3a8DsdOR3NCL/index.html)。頁面明示 GPT-6 Astra、Codex、JavaScript、自製 WebGL renderer、Node.js tests，且描述 prompt 產生此作品；沒有公開 agent 對話、原始碼或明確「單次 prompt、沒有追問」的 run 逐筆證明。repo 的[遊玩截圖來源紀錄](https://github.com/MartinDelophy/awesome-gpt-6-astra/blob/main/assets/screenshots/dash-dinner/SOURCE.md)說明其研究者於 2026-09-21 開啟第一人稱踏板車場景及一則實際外送任務；他只查到接單和騎乘，沒有完成取餐／送達。

## 任務與遊戲系統

AgentGames 頁公開任務原文，要求在第一人稱步行／駕駛的 3D 城市做一款帶喜劇感的外送遊戲，涵蓋限時訂單、超速獎金、門禁碼記憶懲罰、踏板車到汽車的升級、疲勞與宿舍休息。原文也指定可見車輛座艙和開始按鈕；完整原句可在[作者頁](https://agentgames.dev/play/dash-dinner)查看。

實際建置遊戲還描述街道、公園、公寓區路線；在餐廳取餐、記住門禁碼、計時送貨、食物完整度與小費、疲勞限制接單、回宿舍睡到隔日、累積金錢買車與升級並保存進度。這是一個由移動操控、路線、倒數、記憶、食物狀態和跨日成長構成的 delivery sim，不只是短 arcade 單循環。

## 證據與限制

- **可直接檢視：**頁面可玩；瀏覽器抽取文字顯示在啟動後 WebGL 不可用時切換為 2D 相容畫面，因此實際 3D 外觀應在一般支援 WebGL 的桌面瀏覽器確認。其頁有控制提示與遊戲 HUD。
- **模型條件：**平台標 GPT-6 Astra / Codex；Node.js 測試由平台頁列出，具體測試內容及通過結果沒有公開。
- **流程條件：**公開 prompt 很完整，但目前沒看到原始 session transcript、是否有 user follow-up、run 日期／耗時、首版凍結 build 或影片。不要假設只執行過一次。
- **美術證據：**社群目錄留有實玩截圖，其來源是研究員實際進入遊戲時截圖，而非作者渲染宣傳圖；使用者尚未直接評判該畫面是否達標。
- **完成度：**現有公開檢查只做到接單和進入踏板車視角，未完成送貨閉環或長期升級，故不宣稱此循環已獨立實測通過。

## 判斷與重查條件

**保留為重跑系統題備選，不列為已證實的一次生成成績。**優勢是原始任務全文和可玩的 3D 作品都公開，任務範圍具備足以測整合的多種相依系統，且不是冒充當前最新模型的舊展示。用它做跨模型重跑時可直接凍結相同 prompt，再讓 AI 無人介入地自主測試及修正。

升為更強「既有一次委託樣本」之前，需確認作者 session 無途中人類追加、取得 run 日期／時長或 transcript，並完成實際配送循環及 WebGL 畫面檢視；有原始碼或自動測試報告更佳。若新模型另有高品質 one-shot 同 prompt 成品，可替換模型而保留此題型。
