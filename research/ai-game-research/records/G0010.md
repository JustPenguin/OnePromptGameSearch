# G0010 · AI Fire Browser OS

**類型：**遊戲／具體題目　**狀態：**保留參考（one-shot 跨系統任務；非遊戲專題）　**最後整理：**2026-10-06

## 一次委託、任務範圍及成品證據

[AI Fire 的 2026-10-01 原始測試文章](https://aiagentsflows.com/2026/10/01/🔥-i-tested-gpt-6-1-sol-inside-codex-on-3-hard-tasks-can-this-beat-claude-sonnet-5-5/)明確提供一段完整 prompt，稱 GPT-6.1 Sol 在 Codex 中以一次委託約 33 分 42 秒做成同一 HTML 檔的瀏覽器 OS。規格要求桌面、可拖曳縮放 app 視窗、launchpad、至少五個會互動的 app、一款 GTA-style 城市沙盒（汽車／警察追逐／小型開放城市）、一款 3D checkpoint 飛行遊戲，以及跨 app 的原創連結功能；須自行跑起來檢查主要互動並修正明顯錯誤。

文章展示整個 OS、城市駕車場景與飛行遊戲的實際畫面，並報告城市配送／交通及飛行遊戲的遊玩結果。作者稱遊戲進度會在 Journal／Mail 顯示，作為跨 app 整合。視覺上作者稱介面可用但不特別精緻，較早的 Sonnet 5.5 對照更 polished。圖片是作者文章所示成品畫面，不是逐款美術驗收。

## 證據限制與用途判斷

模型、工具、prompt、時間與文章成品圖片有公開說明；但沒有公開可操作輸出、source、Codex session log 或自動化測試結果，故模型執行及測試都只屬作者報告。主要交付是 Browser OS，兩款遊戲是其中的 app，無法獨立重玩、檢查完整關卡、物理或遊戲存檔。

**此項值得保留為「一次交辦下跨系統整合」的重跑 brief 參考，不是本研究的遊戲生成主測或已驗證 playable 成品。**若專門測遊戲能力，prompt 只覆蓋各遊戲的概要需求，OS 卻佔主要任務；它不如單一深遊戲規格精準。若未來要測 agent 能否一次交付整套互動產品，可用完整規格重跑並要求凍結 HTML build、操作錄影及跨 app／遊戲驗收結果。
