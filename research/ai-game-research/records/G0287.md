# G0287 · Wayforge: Frontier Reclamation (GameGoCoder 3.8)

**類型：**遊戲／benchmark playable output 與美術參照　**狀態：**GameGoCoder 3.8 selected evaluation set 中公開的成功 build，有 source tar 和瀏覽器版；原始 query／session 未公開，非已核 zero-human one-shot。**美術不合格（使用者判定）。**　**最後整理：**2026-10-07

**使用者美術驗收（2026-10-07；[E0008](E0008.md)）：不合格。研究者先前對手繪式 diorama 的描述不代表使用者認可。**


## 任務與成品

GameGo repo 的 `games/manifest.json` 將此款列為 rank 7，名稱 **Wayforge: Frontier Reclamation**，model **GameGoCoder 3.8**，description 為「A hand-painted 2.5D diorama game with bridges, stairs, and frontier reclamation.」GameGoCoder 3.8 是 Qwen3.8-27B fine-tuned checkpoint。作者 repo 稱 12 款是 13-case selected evaluation set 的成功輸出；故本案是明確具名的研究 benchmark artifact，但不是 124 任務全集中隨機抽樣，也不能推算成功率。

公開 [live browser build](https://haoyue-yang.github.io/GameGo/games/41340/index.html)、[source tar](https://github.com/Haoyue-Yang/GameGo/blob/main/games/41340/source.tar)、[preview image](https://haoyue-yang.github.io/GameGo/games/41340/preview.png)。畫面是固定等距視角 diorama，玩家以 pointer 操作三名 worker 收集／清除材料並修補 routes、build bridges/stairs、reclaim frontier；manifest 簡述為 frontier reclamation。開場教學圖列出 Clear 3 obstacles、Repair 2 routes、Raise the Grain Mill、Raise the Terrace Farm、Set foot on Highwatch 等 objective。這些是 build/UI 可見目標，不是完整原始 prompt 或全任務規格。

公開 preview 是帶教學卡片的遊戲開場畫面，背景為柔焦小型 3D 環境；論文 Appendix A 的 Qwen/GameGoCoder 3.8 capture 可另外檢視正在運作的立體島嶼／建造場景。畫面顯示一致的手繪式、羊皮紙 UI 和低多邊形 diorama 語彙，細節及角色／材質表現遠低於寫實 3A；這是研究者觀察，**美術不合格（使用者判定）**。沒有聲稱為 AI 自創貼圖或模型完整資產來源。
