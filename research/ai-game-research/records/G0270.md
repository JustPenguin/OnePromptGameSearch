# G0270 · MathBombs

**類型：**遊戲／具體作品　**狀態：**Bolt Hackathon One-Shot bonus-prize entry with live single-page offline math-defense game; only one recurring arithmetic-defense loop and no higher system/content depth, exclude from upper-limit shortlist　**最後整理：**2026-10-07

**美術：待使用者評價。**未代使用者判定作品畫面。

[Devpost 原提交](https://devpost.com/software/mathbombs)以「Math game you can't win」為題；Hackathon badge 將它列在 Winner Bonus Prizes | One-Shot Competition。專案頁說玩家替村莊擊落炸彈：輸入炸彈顯示的算式正確答案，在炸彈落地前消除；三次生命耗盡即結束。主選單有姓名、Easy／Medium／Hard 和炸彈速度選項。作者稱使用 Vite、React、Tailwind 製作本機離線網頁遊戲；[live site](https://mathbombs.netlify.app/)可直接開啟。作者頁另自述難度平衡與動畫挑戰，評論者回報 Hard mode 很難，作者回覆自己在最低速也無法遊玩；這不是正式 playtest。

官方 [One-Shot 規則](https://worldslargesthackathon.devpost.com/rules)允許首 prompt 後修正錯誤、不允許改功能；其 one-shot 身分由平台 badge 支持，但沒有公開 prompt、Bolt 對話、模型／版本、run transcript 或凍結 build provenance。可玩網址能支持遊戲存在，但本研究未獨立通關或評分。
