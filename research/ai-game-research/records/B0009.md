# B0009 · Game Bench

## 歷史盤點摘要

固定題目／權重、允許模型自主規劃測試修正；單一短循環題，作評分方法參考而非上限題

## 2026-10-07 即時重查：固定題 one-shot builder 評測與新增 run

S54 直接讀取[作者專案頁](https://piccini.app/projects/game-bench/)、[現行評測榜／protocol](https://game-bench.piccini.app/)、[匿名試玩頁](https://game-bench.piccini.app/blind-tests/)、[凍結任務](https://game-bench.piccini.app/frozen-prompt.md)與 [GPT-6 Astra 2026-09-24 build](https://game-bench.piccini.app/games/gpt-6-astra-20260924/)。評測頁目前顯示 25 個 playable builds；匿名頁也已列 25 款（專案頁的文字仍說 9 條，屬內容不同步）。題目 V3 要求從空工作區做一款完整 browser game、禁止人工回饋，並要求模型自己在瀏覽器完整遊玩、找錯、修正，兼顧桌機／真手機、程序音效及多種互動系統。四軸是 Gameplay、Adherence、Engineering、Art，權重 45/15/25/15。

新近可玩 run 登錄於 [G0266](G0266.md)：GPT-6 Astra high、2026-09-24、表列 16m06s／1.84M tokens／$4.95，作者榜分為 95.5（Gameplay 92.6、Adherence 99.8、Engineering 96.2、Art 98.5）。author site 說 Astra 四軸分由 Luiz 本人提供並記於其 sheet；我未找到該 sheet 的公開直達連結。更重要的是 run data 將它標為 `processStatus: review`，註明「Third attempt passed process and play; VM-host containment canary remains unresolved」。這與首頁通用 one-shot protocol 並列存在，令該特定 Astra run 的重試／隔離狀態尚不能獨立判清；不得把該分數當作已完全核實的 strict one-shot 結果。可玩的 artifact 與凍結 prompt 可直接查閱；輸出 source JS/CSS/audio 可由 hosted build 載入，但未找到 frozen source archive、hash 或完整 trajectory。

匿名頁讓參與者先玩、記錄 impressions，並要求玩到理解循環、至少死一次／重開，評 Game Design、Fun、Adherence、Onboarding、Cross-Platform、Engineering、QA、Audio、Overall 與是否願意再玩；但頁面只提供 rating flow，沒有發現已發布的盲測原始評分／彙總，因此不得把它說成已有獨立盲測結果。榜頁對 Astra 的作者評分與無身分 blind-test 機制也須分開。



作者頁目前列出 25 個可玩的模型 build；協定聲稱每個模型取得同一份凍結 prompt、乾淨工作區、無記憶或舊 build，模型可自行規劃、建置、測試及交付，不接受人工途中引導。評分分 Gameplay、Adherence、Engineering、Art 四軸，加權為 45/15/25/15。頁面可直接開啟 GPT-6 Astra（2026-09-24）版本，現有可查頁面顯示模型名、effort、日期、時間、token、成本及分軸分數；該 run 的總分 95.5，成本頁列 $4.95。

本次直接讀到的凍結題目是 **Itsy Bitsy Spider V3**：單一無盡爬牆循環，但規格詳細要求耐力／蒼蠅／暴雨／避難洞、逐步難度、程序音效、行動版控制、四種狀態，以及必須用瀏覽器完整玩到 game over、檢查各項功能、修 bug 再交付。這可作為「固定題、一次交辦、自主 QA、最終成品分軸評分」的流程範例；公開 build 是 [GPT-6 Astra 可玩版](https://game-bench.piccini.app/games/gpt-6-astra-20260924/)，凍結規格見[完整 prompt](https://game-bench.piccini.app/frozen-prompt.md)。

**S54 取捨：**任務 subsystem 多，但原 prompt 明稱 small game 且只有一條無盡生存循環；按使用者不以小遊戲湊完整遊戲上限候選的條件，將 GPT-6 Astra output 登錄為短循環／自主 QA／mobile／audio 副測，不推薦作上限主測。它是實際可玩的最新樣本和評量方法補證；但該 row 的 process review 尚未解決，作者 Art 98.5 不是使用者美術判定。細節見 [G0266](G0266.md) 與 [S54](../search/S-20261007-54-player-facing-evaluation-coverage.md)。

**本研究的取捨：**這個評測協定很貼近使用者的一次委託條件，應借鑑其零途中回饋、公開題目、逐 run build、行為／工程／美術分項的做法。但題目本身刻意是 small game，玩法集中在單一爬牆生存循環；所以 build 的視覺品質和分數不能證明它有足夠上限深度，也不列入主測候選。其分數由個人作者評閱；頁面說明 2026 年 9 月八款 run 的分項採用 Athena 的詳細評分，Astra 的分數由作者提供並記錄於其 sheet。不可將作者自評寫成盲測或獨立審核。

2026-10-07 本次確認榜頁目前列 25 runs，最高分依舊為 GPT-6 Astra（2026-09-24）；S54 新增該 run 的四軸分數、process review 註記及目前 25 款 blind-play flow。這改善了近期成品／rubric 可查性，但不能解除 run 的 process-status 疑問或單循環題目範圍限制。
