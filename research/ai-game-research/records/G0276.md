# G0276 · Playco GPT-6 Astra three game prototypes

**類型：**遊戲／近期模型結果與重跑方法參考　**狀態：**OpenAI／Playco 官方案例自述 GPT-6 Astra 從灰盒原型製作三款 themed playable prototypes，另稱多數首輪可用、手動修正減少 50%；開發流程包含數次 gameplay／creative iterations，未公開任務文字、build、repo 或可檢視遊戲畫面，非已核 one-shot 成績　**最後整理：**2026-10-07

**美術：無法判定／待實際 gameplay 畫面。**官方案例聲稱改善 reference-image recreation、空間配置與遊戲引擎內 responsive UI，但沒有提供三款 prototypes 的可評畫面或使用者評價；不得把能力自述換算成美術分數，也不能據此稱 3A。

## 任務、模型與工具

- OpenAI 於 2026-09-03 發布[Playco 案例](https://openai.com/index/playco-game-prototyping-with-astra/)，標示模型為 GPT-6 Astra。Playco 的 Playbot 是面向專業遊戲開發者的 AI IDE，文章稱可連 Unity／Godot，由模型編輯場景、遊玩測試、驗證修改並平行工作。
- 文章說團隊先以簡單 primitive 建立無主題 grey-box prototype，再對玩法與創意細節做「a few iterations」，接著從共用基礎做出三個 themed prototypes。Playco 說 GPT-6 Astra「produced all three in one go」。這不是完整原始 user task，也沒有說三個主題的精確 prompt、何人輸入、是否每款各一個 prompt，或灰盒與 themed builds 的 frozen revision。
- Playco Lead Product Engineer Joao Vieira 表示多數 prototype 第一版已強，所需改動是依 gameplay preferences；一款 cyberpunk prototype 另需 performance fix，其他款稱無額外 iteration。此段是作者／客戶自述，未有外部版本歷史核對。
- 未見模型 API snapshot／參數、agent trace、repo、可玩 URL、build hash、生成日期、工程工時或成本資料。文章隨附 67 秒 OpenAI/Vimeo 影片，但未公開 playable artifacts；影片嵌入與版名可查，不能代替逐款評估。

## 評量與證據界線

- 官方聲稱相較先前模型「50% fewer manual fixes」，但未公布樣本數、手動修正定義、前代模型名稱／版本、盲測或計算方式；只保留為官方比較自述，不作可重現量化評分。
- 文章指出 spatial reasoning、reference image recreation、Unity responsive UI、game feel 與自行 play/test／找 bug 等面向。這些使它成為與本研究美術軸和自主 QA 軸高度相關的近期方法／重跑線索。
- 三款遊戲的題材、機制、完整度、真實畫面與實際 playability 無法從文章核對；作品不能進主要候選或「美術合格」名單。
