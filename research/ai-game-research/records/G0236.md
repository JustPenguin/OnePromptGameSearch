# G0236 · Dead Signal: Exclusion Zone (Sonnet 5.5 build)

**類型：**遊戲／具體題目　**狀態：**有力 one-shot 成品線索；作者流程自述、原始 prompt／trace 缺失　**最後整理：**2026-10-07

**別名：**Sonnet 5.5 Zombies Game、BridgeMind Sonnet 5.5 Dead Signal、49-minute zombie FPS

## 發現與可查驗成品

BridgeMind 於 2026-09-28 公開此 Claude Sonnet 5.5 build。GitHub README 歸因給 Sonnet 5.5 在 Claude Code 內、使用 subagents、以 single prompt 建置；技術為 Three.js、TypeScript、Vite，模型／貼圖／聲音由程式即時生成，沒有下載資產或後端。source、操作方式、unit tests、可選 headless-Chrome QA helpers 均公開，可用 `pnpm install` 後在本機 Chrome/WebGL 2 啟動。**目前沒有作者 hosted playable link**，故這是可重建的 source build，非一鍵線上 demo。

任務／玩法含 8–10 分鐘撤離循環、三個威脅區、守點 relay、拆除 Warden 頭盔後爆頭、單次獎勵、武器／護甲／補給升級、7:30 污染擴散、12:00 封鎖、呼叫直升機並登機，死亡／超時失敗。這是跨射擊、導航、經濟、任務狀態和結局的實際 FPS，比短波次射擊 demo 深。

- [Reddit 轉載影片／作者 X 貼文來源及社群討論](https://www.reddit.com/r/singularity/comments/1wswpv6/claude_sonnet_55_is_one_day_old_and_already/)

## 證據與限制

作者與 repo 自述 single prompt、Claude Code、subagents；Reddit/X 流傳資料稱 49 分鐘、約 US$177。沒有原始 prompt、可逐輪核對的 session trace、停止時 commit/hash、建置 log 或獨立 QA 結果；49 分鐘與費用是未經獨立核實的作者數字。repo 提供可建置成品和測試工具，但有工具並不證明本 run 確實跑了完整測試或通關。Reddit 貼文是轉載者轉貼原 X 連結，討論中也有讀者指出影片看不出任務、成長系統與完整深度；以 source／重跑規格核對，不以留言票數作品質分數。

此 Sonnet build 與 BridgeMind 的 Opus 5.5 同名 repo 相似，但**未證明使用同一 prompt**；也未證明它使用了 BridgeBench 上 2026-09-04 發布的 438 行社群任務。因此將它當「同系列、較新模型的真實 build 證據」，不當成原作或 BridgeBench 規格的已驗證模型結果。

## 2026-09-29 同類任務獨立重跑補證

Zuki 另將「同一份 3D zombie game prompt」各交給 Sonnet 5 high、Sonnet 5.5 high、Sonnet 5.5 medium 一次，作者稱全程沒有介入；時間分別為 27:15、35:06、19:41。模型自行操作遊戲作錄影與自我修正。作者描述舊 Sonnet 首版自動遊玩會撞牆並耗盡子彈；Sonnet 5.5 high 的版本另有靜音與暫停等 polish；medium 成品也有公開遊玩連結。作者後續另以第 2–4 次提示製作 Blender 人形殭屍，這些改進版不屬於一次提示輸出。

## 判斷與重查條件

**值得列為高價值重跑題與較新成品參照，但 run provenance 仍有缺口。**Sonnet 5.5 source build 可本機建置，另一作者也有三個首輪 zombie FPS playable 輸出；兩個來源都不足以證明其使用同一個明確任務或 438 行 BridgeBench brief。Dead Signal 的強項是可另行重跑的完整系統規格，不是目前既有 build 已經通過該規格。向 BridgeMind 取得原 prompt／完整 session trace，並取得 Zuki 的 prompt／首版檔案，可再升級成可互相對照的實測。使用者未評價上述新增 build 的美術。
