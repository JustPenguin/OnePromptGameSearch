# G0208 · Survive the Sprint

**類型：**遊戲／具體題目　**狀態：**待核實　**最後整理：**2026-10-06

**別名：**尚無

## 發現與來源

2026-10-06 搜尋近期 Claude Opus 5.5 one-shot 成品時，找到 [endjin 官方介紹文](https://endjin.com/blog/introducing-survive-the-sprint)與[目前可玩的遊戲](https://endjin.com/survive-the-sprint)。作者稱以 Claude Opus 5.5 Max、一段 prompt 產生大部分首版，單一 HTML、無 build step／外部美術音訊素材，依公司團隊介紹頁創作人物。首版被描述為可玩，不過文章沒有公開 prompt 原文、初始 build、原始碼或 run transcript。

成品是 pixel-art survivor-like：玩家從 11 名工程師角色選擇一位，在三個 sprint 關卡中打 bugs、flaky tests 和 merge conflicts；每段有 boss，包含升級、perk、武器演化、同伴 synergy、成就與手機操作。作者頁內提供角色圖、玩法 GIF 和 promo video，也有 hosted playable build。它有真實 AI 作品圖像可直看，玩法範圍比簡單單循環更廣，但仍是單畫面大量敵人的 survivor-like，不因此推定達到使用者偏好的視覺水準。

## 證據與限制

作者明確說明，最初可玩版本之後有「fair bit of back and forth」：新增所有角色 perk／special、更多內容、平衡及角色潤飾、效能改善、bug 修正和自動測試。文章現連的 build 是迭代後的交付版，不能當成一次委託原樣首版評分；其中後加功能不應歸功於原始 prompt。沒有公開首版檔案 hash 或完整模型訊息，所以目前無法分離單 prompt 首版和人工後續工作的實際成果。正式任務提示也只被轉述，沒有逐字原文。

模型、effort、單 prompt 產生多數首版、沒有 build step 和外部素材均為作者陳述；首版過程未獨立核實。可視覺查驗的是更新後成品，不是 frozen one-shot build。

## 判斷與重查條件

**保留為待核實的視覺／題材線索，不列為嚴格一次委託候選。**一則 prompt 產生可玩首版的作者敘述有價值，但公開供看的最終 build 經多輪人類介入，且沒有首版可供驗收；這不符合使用者設定的「AI 可自行修正、使用者不介入，僅驗收 AI 最後交件」。

只有作者公開原始 prompt、首版 frozen build／影片並說明首次輸入後人類未再引導，才重評為一次委託候選。若找不到首版，只保留作 survivor-like 題型和視覺參考，不要將目前成品列為 Opus 5.5 的 one-shot 成績。搜尋過程見[S11](../search/S-20261006-11-new-one-shot-game-leads.md)。
