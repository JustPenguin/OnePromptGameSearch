# G0192 · Raccoon Heist (Claude Fable 5)

**類型：**遊戲／具體題目　**狀態：**方法參考　**最後整理：**2026-10-06

**別名：**3D Raccoon Heist、Simon Willison Raccoon Heist

## 現行判斷

**不是上限主測候選，保留作一次委託與視覺／QA校準。**作者公開原 prompt、兩張概念參考圖、可玩成果與 Playwright 自動測試過程，明確希望 AI 不再向他索取設計決策。成品有收集、負重、分夜升級難度、巡邏守衛、警車、嗅跡獵犬、回巢存分等玩法，但作者自評玩法普通、偏淺；因此不足以單獨測出高上限。

## 單次委託與自動修正證據

Claude Fable 5 在 Claude Code web 工作。初始 prompt 要求瀏覽器 3D 遊戲、手機觸控、可使用 GPT Image 2 生成材質、獨立完成、不再詢問設計決定，並持續提交以便作者預覽。作者說明目標是測 AI 能否在沒有額外輸入下交付完整可玩遊戲。實作中以 Playwright 對桌機、直向手機、橫向手機跑自動遊玩並留截圖；加上守衛犬追蹤後也自動驗證 wander→track→caught。這是清楚的「一次人類指示、AI 自主修正」例子，但包含兩張參考圖及外部影像模型，不能當純文字／單模型比較。

作者評語提到風格一致、支援 3D 與手機，但遊玩本身偏淺。真實成品、截圖與作者的誠實檢討可從[文章](https://simonwillison.net/2026/Aug/5/raccoon-heist/)查看；[可玩版](https://simonw.github.io/raccoon-heist/) · [source](https://github.com/simonw/raccoon-heist)。

## 使用範圍與重查條件

可作視覺完成度／自主測試流程參照，或供更強模型擴寫玩法後測試；不應以原任務當唯一上限題。若要採用，需保留參考圖和 GPT Image 2 條件，或全部移除並將 prompt 固定，不能把兩種 protocol 混排名。
