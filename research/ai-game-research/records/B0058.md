# B0058 · GameGoBench: 124-query game-development benchmark

**類型：**基準／遊戲生成及 artifact 評估　**狀態：**高價值高系統遊戲生成 benchmark。paper 有 124 held-out tasks、三軸自動評分與六位專家盲玩比較；附 10 models × 12 tasks 圖像。GitHub 提供 12 款 GameGoCoder 3.8 playable/source samples 及模型權重；匿名 HF GameGoBench dataset API 回 401，原始 124 prompts／full trajectory 暫無法下載驗證。美術畫面待使用者評價。　**最後整理：**2026-10-07

## 任務、模型與評測方法

Kwon et al., [GAMEGO: Training Game-Dev Agents with Synthetic Trajectories Anchored in Real-World Assets](https://arxiv.org/abs/2610.06910), arXiv v1 於 2026-10-02 提交。方法先把真實遊戲 seed 展開成較完整 PRD，再壓縮為 task-adaptive execution query，讓 coding agent 在 browser game sandbox 內多輪使用工具完成遊戲。GameGoData 稱有 55,060 development trajectories；GameGoBench 為依難度分層的 124 個 held-out game-development tasks，含 47 個 2D、22 個 2.5D、55 個 3D。此 benchmark 的一則 execution query 由 agent 執行，不是限制 agent 只能有一輪模型呼叫；允許規劃、工具使用與 build／verification 互動，符合本研究允許 AI 自主修正的作法。paper 沒有提供完整 query、session 或人類介入逐案紀錄供本研究稽核。

主要量化表比較六個 frontier models（Claude Opus 5、GPT-5.6、DeepSeek-V4-Pro、GLM-5.3、Qwen3.8-Max、Kimi-K3）及 Qwen3.5-27B／Qwen3.8-27B 與各自 GameGoCoder finetune。GameGoBench 每項報 Exec、Req、Quality、Overall，並以 Claude Sonnet 4.6 verifier 評價。表列 Claude Opus 5 61.84 Overall、GPT-5.6 52.78、GameGoCoder 3.5 51.85、GameGoCoder 3.8 55.29。**Quality 為 verifier 對遊戲品質的分數，不能直接等同使用者美術評價。**

研究另做盲玩 pairwise evaluation：六位受聘獨立專家在可用的生成 artifact 上逐款由開始玩至體驗結束，匿名比較兩個作品，分別判斷 fidelity、playability、overall quality。各 study 的 paired artifacts 數量與可玩配對條件不同；在任務表示 ablation，task-adaptive query 相對 full PRD 獲 85.7% preference，相對 direct query 獲 86.6%；這是 pooled reviewer judgments，不是 AAA art score。作者報告 reviewer agreement 81.7%（task representation）、82.5%（models）、84.7%（MoE）。這是目前研究庫中較接近使用者所重視「評最後的可玩成品」的專家方法證據。

## 可查成品、畫面與 release 狀態

paper Appendix A Figure 9／10 公開 12 項同題比較、10 模型的畫面 mosaics：[Part I](https://arxiv.org/html/2610.06910v1/figure/figure_1_6games.png) · [Part II](https://arxiv.org/html/2610.06910v1/figure/figure_2_6games.png)。題型包括 slingshot puzzle、run-and-gun、dress-up studio、pixel horror、open-water sandbox、isometric puzzle、cozy open-world、3D arena shooter、kart racer、dungeon crawl、brawler 與 lane battle。圖片由論文列為 qualitative comparisons；畫面是生成 build captures，不是 key art。本研究直接檢視兩張 mosaic：結果涵蓋簡化低多邊形、2D pixel、stylized/isometric 和寫實光照場景，不能只憑縮圖判定 3A 資產細節，所有新畫面仍待使用者評價。

GitHub repo `Haoyue-Yang/GameGo` 於 2026-10-02 更新；含論文圖、manifest、12 個 HTML playable builds、12 個 source tar 和 preview images，對應 GameGoCoder 3.8 在選出的 13-case showcase set 中 12 個成功案例。其 [線上遊戲圖廊](https://haoyue-yang.github.io/GameGo/games/) 可直接進入 build；例如 [Wayforge: Frontier Reclamation](https://haoyue-yang.github.io/GameGo/games/41340/index.html) 是 hand-painted 2.5D diorama build，另有[預覽圖](https://haoyue-yang.github.io/GameGo/games/41340/preview.png)與[source tar](https://github.com/Haoyue-Yang/GameGo/blob/main/games/41340/source.tar)。這些是成功案例子集，不能當作 124 題全量結果或成功率；repo 也明示失敗的第 13 案未放入畫廊。

README 連結至 [HF GameGoBench dataset](https://huggingface.co/datasets/Y36521478Y/GameGo) 及 [GameGoCoder 3.5／3.8 models](https://huggingface.co/Y36521478Y/GameGoCoder3_8)。本次匿名直接 API 查詢：model repo 可讀且含 12 safetensors shards；dataset API/tree 未授權（HTTP 401）。GitHub README 表示 55,060-trajectory corpus 和 training code 不在該 repo。故模型及 12 sample artifacts 可取得，但原始 124 task query、完整 benchmark data、trajectory 和訓練資料未確認可公開重現。repository 沒有 release tags。

## 適用界線

| 面向 | 判斷 |
|---|---|
| 美術 | 有 120 張論文比較畫面與 12 款 GameGoCoder 3.8 samples；涵蓋 stylized 2D／3D 與多種 UI。有可供使用者看圖／開遊戲的材料，但目前沒有專項獨立 art rubric；Quality 與其他模型的 blind pairwise overall 不能代替使用者美術評分。 |
| 可玩性 | GitHub Pages 提供 12 個 interactive builds，paper 人類評審逐款從開始玩到 playable experience 結束。這補強評測可信度，但沒有本研究逐案獨立通關。 |
| 系統／內容 | 124 task held-out set 有多題型及 2D 至 3D 任務；精確 requirements 和完整 query 下載狀態尚未驗證。 |
| 一次委託 | benchmark 把一個 execution query 交 coding agent autonomously tool-use，但未提供可核逐案原始 user task／session／人類零介入 trace。可作 one-task agent generation 的重要方法與評估參照，不作已稽核 one-shot 結果。 |
| 證據強度 | 高（存在性、aggregate results、評估方法、論文示例圖及 12 build artifacts）；中低（124 原始任務資料、session／trajectory 及完整重現）。 |

**定位：**現階段應列正式 benchmark 高價值追蹤項，優先於只有靜態功能打分的短小 benchmark：任務具 3D 占比、允許 agent 自我修正，並有從頭玩到結束的獨立專家盲評。可先直接檢視 GameGoCoder 3.8 的 12 款公開 build，尤其 [Wayforge](https://haoyue-yang.github.io/GameGo/games/41340/index.html) 的 2.5D hand-painted diorama；它是研究團隊微調模型輸出，不是當前 frontier 代表。要當固定題庫跨模型重跑，仍需 HF dataset 匿名可下載並取得 124 task texts、verifier／runtime requirements 與完整 artifact mapping。搜尋批次：[S79](../search/S-20261007-79-gamego-benchmark-outputs-and-release-audit.md)。
