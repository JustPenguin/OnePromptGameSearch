# G0271 · CosmicTacToe (RulebookGPT & CosmicTacToe submission)

**類型：**遊戲／具體作品　**狀態：**Bolt Hackathon One-Shot entry: stylized tic-tac-toe; publicly linked playable domain and Bolt session but only a classic tic-tac-toe loop, outside high-ceiling scope　**最後整理：**2026-10-07

**美術：待使用者評價。**未代使用者判定作品畫面。

[Hackathon submission](https://worldslargesthackathon.devpost.com/submissions/726974-rulebookgpt-cosmictictactoe)是雙作品展示：RulebookGPT 可上傳桌遊規則 PDF 並用自然語言提問；另有獨立的 CosmicTacToe。作者稱它是「stylized one-shot tic-tac-toe」，並列 [可玩網址](https://cosmictactoe.xyz/)及 Bolt session。頁面說整體 UI 由 Bolt.new 產生，後端另外用 Netlify functions 做 Mistral OCR 及 ElevenLabs voice；這些整體 app 功能不可錯歸給 CosmicTacToe。公開 Bolt session URL 現在導向登入，未能查 prompt／timeline。

Hackathon 官方 [One-Shot 規則](https://worldslargesthackathon.devpost.com/rules)容許修 bug、不容許首 prompt 後增加功能；submission 在 One-Shot Competition badge 下列出。這支持賽制脈絡，不足以獨立證明 CosmicTacToe 專屬的單次 run 或 model version。
