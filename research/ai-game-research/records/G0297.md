## 發現與原始證據

由 [awesome-gpt-6-astra 待審條目 #110](https://github.com/MartinDelophy/awesome-gpt-6-astra/issues/110) 發現，後來因作者在同一條目補充模型歸屬而收錄。作者 [2026-09-29 公開留言](https://github.com/MartinDelophy/awesome-gpt-6-astra/issues/110#issuecomment-5893086419) 稱，他核對了本作 2026-09-27 的本地開發紀錄：10 條輪次 context 的模型欄均記為 `gpt-6-astra`，經 Codex 完成多輪實作、修改、整合和除錯。此為創作者自述及其對本地記錄的摘要，**完整 session／逐字對話並未公開**。

作者提供 [可玩 browser build](https://ihca.cn/midway/)與 2026-09-29 擷取的[遊戲內截圖](https://github.com/user-attachments/assets/421ae870-9583-47c1-8e02-cedd5e12f2da)：從戰機後方望向雲海與海面，畫面含友敵飛機、雷達、距離標記、炸彈落點、生命／速度與操作 HUD。它是作者標示從線上 build 取得的實機畫面，不是封面；本研究未獨立操作完整任務。S90 於 2026-10-07 另下載 live HTML 和 boot/style files；頁面以 `?v=c29d912b0c8c` query tag 載入 current static modules，boot.js 指出 online mode 動態 import `./js/main.js`。這只標識本次查看的 current live assets，不足以證明它與 9/29 screenshot 是同一 build，也沒有找到 source map 或作者的 MIDWAY GitHub repository。

## 遊戲與任務範圍

玩家駕駛戰機與僚機迎擊攔截機、突破航母艦隊防空、俯衝投彈並返航再出擊；作者描述炸彈繼承飛機速度並受重力影響，HUD 顯示預計落點。這是有空戰、編隊、彈道與目標循環的 3D 單關街機遊戲，不是完整飛行模擬。原始逐字 prompt 未公開。

## 資產來源與美術界線

作者確認第三方 Tidewater 頻譜海面程式及飛機／艦船 GLB 模型參與整合；投稿列出 Waroxed、ThomasBeerens、philano、fabirbige、Renafox 等署名，部分飛機模型採 CC BY-NC 4.0，另有 CC BY 4.0 素材。模型能協助整合、修正載入、方向和縮放，但不能據此說這些模型或整體高完成度畫面是 Astra 原創生成。使用者已判定整體美術不合格；第三方資產歸屬與玩法系統另行評估。
