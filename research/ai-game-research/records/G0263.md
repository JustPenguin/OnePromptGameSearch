# G0263 · Fusepoint

**類型：**自主長程遊戲生成實例　**狀態：**單一初始 PRD 後超過 70 輪自主建置；流程高度符合「使用者不再介入、AI 自行修正」；公開成品影片與 source 可看，該輪凍結版及原始 PRD 尚未取得；美術合格（使用者判定）　**最後整理：**2026-10-07

**使用者美術驗收（2026-10-07；[E0008](E0008.md)）：合格。這是使用者對 Fusepoint 成品畫面的評價；自主流程及 QA 缺口另行評估。**


## 成品與任務

[官方專案頁](https://flesymeb.github.io/HarnessOfHarness/) · [arXiv 論文](https://arxiv.org/abs/2609.01481) · [真實遊戲畫面影片](https://flesymeb.github.io/HarnessOfHarness/assets/video/fusepoint-real-gameplay-preview.mp4) · [遊戲 source repository](https://github.com/Flesymeb/fusepoint) · [官方遊戲下載資料夾](https://drive.google.com/drive/folders/1gch3D5HKa3n3gxM0LNrzubcJxlFFLaXy?usp=sharing)

Fusepoint 是敘事型單人第一人稱射擊遊戲。論文所述的使用者任務，是一個五分鐘拆彈任務：依序控制兩個據點、到終點完成三階段拆彈；三個遭遇區固定配置 3、5、10 名敵人，並包含成功與炸彈引爆兩種結局。它需要把 3D 場景、外部資產、射擊、敵人、任務進度、介面回饋、音訊及執行穩定性整合起來。

論文只提供上述 PRD 要點摘要，**完整原始 PRD 本文未在已檢視的公開材料中找到**。官方影片可直接檢視遊戲內 FPS 畫面與玩法；官方 Drive 提供遊戲下載入口，GitHub repository 提供源碼和迭代材料。影片和研究團隊的「polished visuals」描述可作成品參照；使用者後續已明確判定 Fusepoint 美術合格。

## 一次委託與自主修正證據

| 欄位 | 目前可核實資料 |
|---|---|
| 底層模型 | GPT-5.6-Sol；高 reasoning effort |
| Coding agent | Codex CLI；論文未列出此 70 輪 run 所用 CLI 精確版本 |
| 引擎／工具 | Godot 4.7、Godot MCP；另用圖像／3D／影片資產生成工具及 UI/UX、測試 skills |
| 起始輸入 | 空工作區中只放一份使用者提供 PRD；公開論文概述任務，但全文未找到 |
| 自主歷程 | 研究團隊記錄 70 個規劃—實作—測試循環；人類只在網路或 API 中斷時恢復服務，未參與規劃、實作、除錯、測試或驗收 |
| 時間與日期 | 論文 v1 發表日 2026-09-01；70 輪完成時間被描述為 multi-day，未見精確耗時。後續公開 repo 截至 2026-09-22 已更新到 Loop 96，不能把目前主分支誤當成 Loop 70 凍結成品 |
| 評測方式 | 沒有 Fusepoint 專屬數字 benchmark 分數。QA 追加檢查即時鍵盤操作及遊戲反應、音訊、3D 資產整合；材料另有 commit、issue、evidence packet 和遊戲影片 |

這裡的「一次」是**使用者只提交一次 PRD，之後 agent 自主長期迭代**，正符合本研究把 AI 自我測試和修正納入同一委託的定義；它不是 one-shot 單次模型呼叫，也沒有證據支持「零工具、零外部素材」。團隊在內部 protocol 設計了 Planner、Developer、QA Tester 三種職責；QA 角色只讀檢查，不直接替產物打補丁。外部資產使用允許再利用的授權，並保留來源與標示。

## 產品完成度與證據界線

論文在 Loop 70 報告 81 個 issue 中 65 個關閉、16 個未解決，17 個曾在關閉後因回歸重開。這是長程自主建置及修補的直接價值，也代表論文截止點的最終版本仍有可見未解事項，不能只憑「human-playable」稱為無缺陷交付。

公開 source repo 後續已發展至 Loop 96，README 顯示 101 個 issue 中 94 個已關閉、7 個仍開啟；最近循環的 QA 仍列出戰鬥輸入、動畫、視覺可讀性和完整效能驗證等缺口，product completion 仍是 in progress。這是較晚的 evolving branch，不保證與論文 Loop 70 或影片所用 build 完全相同；本次未找到不可變的 Loop 70 release/tag，因此**不能將最新主分支當作論文成績的精確 frozen build**。

這些問題不抹去其長程自主流程價值，但實測時應保存被測模型停止時的 build，照 PRD 自行驗收任務循環、戰鬥、勝敗分支、執行穩定性與畫面；最終以那次凍結交付評分。使用者後續判定 Fusepoint 美術合格；此結果不影響對 QA 缺口及 frozen build 不足的評估。

## 納入理由與定位

這是目前查到最貼近「輸入後不再干預、等待 AI 自行交出一款可玩的完整遊戲」的高證據案例之一：不只有成品畫面，也公開任務輪廓、模型、工具、隔離的人類介入範圍、長程迭代記錄與可檢查 source。它適合當**自主長時程能力與任務題型的強參照**，並可把 PRD 摘要補成新模型重跑 brief。

模型為 GPT-5.6-Sol；截至 2026-10-07 它不是本研究可比較的最新前沿型號。因此它證明的是這種任務與 harness 形狀值得測，不是當前最新模型的能力排名。另見方法紀錄 [M0028 Harness-of-Harness](M0028.md) 及搜尋批次 [S46](../search/S-20261007-46-long-horizon-autonomous-game-runs.md)。
