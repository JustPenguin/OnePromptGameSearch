# G0244 · Montanha: Zero Day

**類型：**遊戲／具體題目　**狀態：**高價值動作平台遊戲重跑 brief／多輪迭代參照；排除最終成品作嚴格一次交付證據　**最後整理：**2026-10-07

## 已公開的成品與原始 kickoff prompt

作者公開 [Opus 5.5／Claude Code 建置文章](https://dev.to/tiagovilasboas/i-built-a-full-pwa-game-in-one-day-with-claude-opus-55-and-claude-code-here-is-the-real-token-41p7)、[source repo](https://github.com/tiagovilasboas/montanha-zero-day) 和[可玩 PWA](https://tiagovilasboas.github.io/montanha-zero-day/)。初始 prompt 只有三句左右，要求用純 JavaScript／Canvas 做 cyberpunk Mega Man X 風格平台動作遊戲，交代主角／女主角／最終 boss，並要求手機與桌面離線 PWA。成品有三階段、cutscene、boss 和結局，作者稱架構有 24 個 ES module；文章公開 Playwright／bot 感測器、session 使用量與幾個被測試找出的 bug。

## 嚴格一次交付判斷

**目前 repo 最終版不能當作「使用者輸入後完全未再干預」的證據。**文章明確記載：作者回饋女主角的移動手感比主角流暢；又要求把第三階段 boss 前的關卡由 7 段擴為 12 段。最終 build 是這些人類回饋及多輪修正後版本，且修正前發現 boss 復活、擊退陷阱和無敵穿雷射等實際 bug。文章稱單日完成，不能取代每輪是否收到人類指示的稽核。

其價值在於可從公開 kickoff prompt 重跑一款多階段動作平台遊戲，測試短 brief 下的創作、角色操控、關卡、敵人／boss、PWA 和自我 QA；應交最新模型重跑並只保留一則 user brief。現有 repo 可供任務參考與了解作者如何構建 QA harness，不應將最終輸出放入已驗證 one-shot 成績表。使用者尚未對其美術作作品級驗收，也未由本研究者獨立完成遊玩。
