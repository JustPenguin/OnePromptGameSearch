## 公開 prompt、實際 build 與系統

頁面標示 Fable 5.1 生成、可在瀏覽器實際遊玩，並公開原始 prompt；任務是日本湖區 3D 開放世界甩尾遊戲：火山湖環道、5.6 公里 11 彎山路、城市三區、海岸道路、日夜循環和夜間車流；乾淨完成甩尾才賺錢，撞車扣掉累積分數，再把收入用於汽車及八階性能／外觀改裝。包括道路、地形、城市、車輛、聲音程序生成。

[實際遊玩、公開 prompt 與遊戲說明](https://agentgames.dev/play/touge)。頁面記錄 44,455,720 tokens、5,592 分鐘 build 時間及 $453.10 成本（平台／創作者回報）。長時間 build 可能是自主 agent 執行，但該頁沒有說明期間有沒有多輪人類指示；畫面與 build 亦會持續更新。
