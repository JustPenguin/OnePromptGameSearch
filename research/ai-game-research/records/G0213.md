# G0213 · Sunward

**類型：**遊戲／具體題目　**狀態：**排除（嚴格一次交付）　**最後整理：**2026-10-06

## 發現與來源

GPT-6 Astra 名義發布的 Unity 開放世界街機賽車。GitHub v0.1.0 發布於 2026-09-14 UTC。作者稱大部分初始遊戲約一小時完成；公開版含 10.34 公里海岸道路、三個檢查點賽事、AI 對手、60 輛交通車、四台車、車漆／調校／甩尾／boost、收集與存檔。原創道路與車輛網格由程式生成。作者列出三條賽事、車庫交易、存檔重載及 37 次電台、50 次 Photo Mode 檢查。

可看作者提交的[駕駛畫面](https://github.com/yjrocks712/Sunward-by-GPT-6-Astra/blob/main/docs/images/driving.png)、[Photo Mode 畫面](https://github.com/yjrocks712/Sunward-by-GPT-6-Astra/blob/main/docs/images/photo-mode.png)及[Apple Silicon macOS 版本](https://github.com/yjrocks712/Sunward-by-GPT-6-Astra/releases/tag/v0.1.0)。Windows 沒有可執行檔；有完整 Unity source 可自行建置。社群策展者的手動截圖評分為 7.8/10，評語是畫面可讀但細節普通；這不是使用者的美術判定。

- 模型歸因為作者自述；沒有更精確的模型快照、reasoning effort、原始 prompt 或 session transcript。
- README 明確稱透過「interactive Codex development session」製作，沒有證明過程中未有人類追加指示。
- 作者說 radio、Photo Mode、testing 與 release packaging 是初始一小時後再做；現行 v0.1.0 不能全數算成最初的單次任務交件。
- 沒有凍結首版 build 或功能時間線，因此不能拆清哪些系統屬於一小時初版。公開成品可用性高，但目前 Mac binary 只支援 Apple Silicon，作者未驗證其他電腦。
- README 自己將遊戲稱為 basic／limited polish，並列 graphics、collision、traffic、handling 為待改善處。
