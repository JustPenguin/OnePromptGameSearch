## 歷史盤點摘要

作者公開 Claude Opus 5.5／Claude Code 一次 session 的單句原始要求、原始碼、可玩 build 和生產流程說明；宣稱無人工改碼、無外部圖片／音訊素材。原 prompt 是「生成一个鹈鹕骑自行车的 3D 页面，尽可能把你所有的能力全部都用上. 然后上传到 CDN 上, 把访问链接给我」。

成品是海岸公路騎行：鵜鶘騎單車追魚，含程式化布料圍巾物理、動態海面、日夜光照、五種鏡頭、14 個成就、節奏隨踩踏速度變化的合成配樂、觸控與自動巡航。repo 列 11 個 JavaScript 模組與約 800 KB 單檔 HTML。作者稱模型還做無頭瀏覽器操作、320 秒 soak test，並修過邊界錯誤。

[可玩版](https://claude-opus-5-5.riba2534.cn/) · [原始碼、prompt 與作者流程紀錄](https://github.com/chandan0000001/by_opus)。

## 後續更新

**用途：**適合測開放式短 prompt 下，模型自行補出有辨識度的主題與多系統 3D 體驗，以及程序模型／光照／動畫／音效和自動 QA 的整合。題目偏體驗展示，不是有明確勝負或長流程的重系統題；不同模型自行定義遊戲範圍會降低逐項比較的公平性。作者自述的模型執行細節尚未由 session log／第三方重現驗證；目前有 playable link，且使用者已明確判定美術合格。
