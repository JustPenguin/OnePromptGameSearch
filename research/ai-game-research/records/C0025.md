# C0025 · VeltosGames

**類型：**作品庫／平台　**狀態：**可玩生成作品庫；作品的生成模型、原始 prompt 與人工介入均未公開，不能由平台行銷宣稱推定為 one-shot　**最後整理：**2026-10-07

## 發現與來源

官方首頁將 Veltos 描述為 prompt-to-game／3D world 產品，宣稱可由文字 prompt 產生可玩的遊戲、互動環境與遊戲資產；[公開作品庫](https://games.veltos.ai/)可直接瀏覽多個有名稱的 HTML5 build。作品頁伺服器初始 HTML 內含實際 iframe build URL，而非只有圖片卡片。S66 直接檢視 Sky Isles、Flow Front、Evolve 三個頁面與其中的 build 入口，作為 3D／高美術方向的近期平台作品庫線索。

## 證據界線

- 官方產品能力敘述只證明平台提供 prompt-to-game 流程；不能證明某一件入庫作品是由單一使用者任務、無追問／無人類後編輯產生。
- 作品卡片可見遊戲名稱、部分類型、建立／更新時間、裝置方向與 playable page；沒看見模型 ID、原始任務、工具 trace、AI 介入紀錄或可凍結 build hash。
- Sky Isles 的 page metadata 將作品標作 `Pro_Game`、`bite` variant、portrait/mobile，公開 iframe 指向可載入的 HTML5 頁；此頁標題為 “Sky Isles — Tiny War Strategy”，其 import map 使用 Three.js 0.160。研究者只核到伺服器可提供頁面與程式，不代表已完成互動遊玩或檢查所有執行時行為。
- 目錄 thumbnail 顯示明亮低多邊形浮空島、城堡、角色與炮火的 3D 戰略畫面；該圖是平台作品縮圖，不足以證明是遊戲執行時截圖。實際 gameplay 美術仍待使用者評價。
